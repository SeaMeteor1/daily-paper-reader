## 摘要
大多数视觉-语言-动作（VLA）模型以视觉-语言模型（VLM）为骨干，通过附加动作模块并联合优化完整策略来构建。这种设计从VLM继承了强大的视觉与语言先验，但使动作模块几乎从零开始学习物理运动。因此，策略缺乏显式的运动先验，迫使早期优化同时发现时序动作动态与跨模态对齐，这一挑战在跨具身设置中进一步放大。在本工作中，我们提出在跨模态VLA对齐之前，用运动先验预训练动作模块。具体而言，我们引入一个两阶段训练框架，在VLA训练开始之前使动作模块具备跨具身的时序运动结构。在第一阶段，一个轻量级的基于流匹配的编码器-解码器动作模块仅从无条件动作轨迹中高效学习时序运动结构，不处理视觉或语言token。在第二阶段，通过解码器复用和早期潜在蒸馏，将学习到的先验迁移到VLA训练中，使视觉-语言特征与动作嵌入空间对齐，同时仍允许端到端策略优化。此外，训练后的编码器可作为紧凑的历史压缩器，将状态-动作历史总结为单个时序上下文token，以可忽略的成本实现历史感知建模。在仿真和真实世界平台上跨13个多样化跨具身任务的大量实验验证了我们方法的有效性。与没有动作先验的VLA训练相比，我们的模型收敛更快、成功率更高，并在数据稀缺的真实世界任务上取得显著更强的性能。此外，扩大第一阶段中的动作数据可获得更具泛化性的动作先验，并直接提升下游VLA性能。

## Abstract
Most Vision-Language-Action (VLA) models build on a Vision-Language Model (VLM) backbone by attaching an action module and optimizing the full policy jointly. This design inherits strong visual and linguistic priors from the VLM, but leaves the action module to learn physical motion almost from scratch. As a result, the policy lacks an explicit motion prior, forcing early optimization to simultaneously discover temporal action dynamics and cross-modal alignment, a challenge further amplified in cross-embodiment settings. In this work, we propose to pretrain the action module with motion priors before cross-modal VLA alignment. Specifically, we introduce a two-stage training framework that equips the action module with cross-embodiment temporal motion structure before VLA training begins. In Stage~1, a lightweight flow-matching-based encoder-decoder action module efficiently learns temporal motion structure solely from unconditioned action trajectories, without processing visual or language tokens. In Stage~2, this learned prior is transferred to VLA training through decoder reuse and early-stage latent distillation, aligning visual-language features with the action embedding space while still allowing end-to-end policy refinement. In addition, the trained encoder serves as a compact history compressor, summarizing state-action histories into a single temporal context token for history-aware modeling at negligible cost. Extensive experiments across 13 diverse cross-embodiment tasks on both simulated and real-world platforms validate the effectiveness of our approach. Compared with VLA training without action priors, our model achieves faster convergence, higher success rates, and substantially stronger performance on data-scarce real-world tasks. Moreover, scaling up the action data in Stage~1 yields a more generalizable action prior that directly improves downstream VLA performance.

## 2. 方法论

### 2.1 核心思想
两阶段训练框架：
- **Stage 1**：仅用无条件的动作轨迹（不含视觉、语言）预训练一个流匹配编码器-解码器动作模块，获得跨具身的时序运动结构先验；
- **Stage 2**：将该先验通过**解码器复用 + 早期潜在蒸馏 + 历史压缩**三种方式迁移到 VLA 训练中。

### 2.2 Stage 1：动作先验学习
- **动作先验定义**（两个维度）：
  1. **分布建模**：拟合连续动作分布；
  2. **结构抽象**：将时序动作块压缩为有意义的潜在嵌入。
- **输入构造**：将本体状态 $s$ 与动作 $a$ 交错为序列 $\tau = [s_t, a_t, s_{t+1}, a_{t+1}, \dots]$，前置可学习数据集嵌入 $p_k$（区分具身）与 summary token `cls`。
- **编码器**：Transformer，输出 `cls` 的 $\ell_2$ 归一化特征作为潜在动作嵌入：
  $$z = E_{\phi_{enc}}(\text{cls}, p_k, \tau)$$
- **解码器（流匹配）**：以 $z$ 为条件重建动作块。定义噪声到真实动作的线性插值路径：
  $$x_r = r a + (1-r)\epsilon,\quad v_r = a - \epsilon$$
  训练目标为速度场预测：
  $$\mathcal{L}_{recon} = \|D_{\phi_{dec}}(x_r, r, z) - v_r\|^2$$
  时间步 $r$ 通过投影调制注入归一化层（借鉴 π0.5）。
- 整体优化：$\phi^* = \arg\min_\phi \mathbb{E}_{(\tau,a)\sim D}[\mathcal{L}_{recon}]$。

### 2.3 Stage 2：带动作先验蒸馏的 VLA 训练
- **VLA 架构**：VLM 主干 $f_\theta$ 接收数据集 token $p_k$、图像 $o_t$、指令 $l_t$、可学习 query token $q$，输出预测潜在嵌入：
  $$z' = f_\theta(p_k, o_t, l_t, q)$$
- **三种先验迁移机制**：
  1. **解码器复用**：Stage 1 解码器直接初始化为 VLA 动作头，主预测损失
     $$\mathcal{L}_{pred} = \|D_{\phi_{dec}}(x_r, r, z') - v_r\|^2$$
  2. **潜在对齐蒸馏**：编码器对真实轨迹产生 $z$ 作为教师目标（stop-gradient）：
     $$\mathcal{L}_{align} = \|z' - \text{sg}(z)\|^2$$
     同时保留 $\mathcal{L}_{recon}$ 以维持潜在几何结构。
  3. **早期步蒸馏策略**：引入单调衰减权重
     $$\lambda(k) = \max\left(0, 1 - \frac{k}{N_{decay}}\right)$$
     总损失：
     $$\mathcal{L} = \mathcal{L}_{pred} + \lambda(k)(\mathcal{L}_{align} + \mathcal{L}_{recon})$$
     超过 $N_{decay}$ 后退化为标准端到端 VLA 优化。

### 2.4 历史压缩（Temporal Context Compression）
- 复用训练好的编码器将历史状态-动作序列 $\tau_{hist}$ 压缩为单个 token：
  $$z_{hist} = E_{\phi_{enc}}(\text{cls}, p_k, \tau_{hist})$$
- 注入 VLM 输入：$z' = f_\theta(p_k, o_t, l_t, z_{hist}, q)$
- **双模式训练**：同时计算有/无历史两种条件的目标并平均：
  $$\mathcal{L}_{total} = \frac{\mathcal{L}(z_{hist}) + \mathcal{L}(\varnothing)}{2}$$
  以避免对历史 token 的过度依赖。

### 2.5 统一动作-状态空间
- 统一动作空间 **37 维**、状态空间 **74 维**，按槽位（slot）映射各具身原生向量，未用维度零填充；配合数据集 token $p_k$ 进一步消歧。

## 6. 主要结论与发现

1. **动作先验显著提升整体性能**：总体平均成功率从 55.3%（No Action Prior）提升至 64.9%（Action-State Prior），加历史后达 **68.0%**；仿真平均从 64.3% → 66.5% → 68.8%；真实 Franka 从 35.0% → 61.3% → 66.3%，明显优于 GR00T（48.6%）与 π0.5（53.8%）。
2. **长尾真实任务受益最大**：Grasp Coke 从 5% → 35%，Stack Cups 从 25% → 75%（加历史后 80%）；π0.5 仿真强但真实任务崩溃（Stack Cups 全失败）。
3. **训练动态显著改善**：初始预测损失降低约 **8×**（~7.1 → ~0.9），初始梯度范数降低约 **16×**（~1400 → ~90），验证 MAE 更早收敛。
4. **历史压缩提供互补增益**：编码器压缩历史优于朴素 MLP（71.5% vs 68.4%），在 LIBERO Long、B2C、Pm2B、C2B 等时序任务上提升明显，可消除抓取前的犹豫。
5. **蒸馏时长存在权衡**：$N_{decay}=5k$ 最佳；过长蒸馏（全程）反而降至 63.1%，低于无先验基线。
6. **动作数据可扩展**：Stage 1 数据从 565k 扩至 2.3M，早期 5k 步成功率 32.2% → 35.4%，最终 68.8%；Stage 1 的 2 小时开销约 8 小时即被摊销。
7. **本体状态有益**：动作+状态优于仅动作（65.4% → 68.3%），在 GR1 高维状态空间上增益最大（Pl2B +20、C2B +12）。

## 7. 优点

- **问题识别清晰**：准确指出 VLA 训练中"动作模块缺乏运动先验"这一结构性失衡，并用梯度稳定性、收敛曲线等定量证据支撑。
- **设计解耦且轻量**：Stage 1 不处理图像/语言 token，batch 可放大 8×，仅 5k 步、约 2 小时，成本占比约 10%，性价比高。
- **一模块三用**：同一编码器-解码器同时承担解码器初始化、潜在蒸馏教师、历史压缩器三重角色，架构复用度高。
- **蒸馏调度合理**：早期锚定 + 后期释放（$\lambda(k)$ 衰减）兼顾先验引导与端到端微调灵活性。
- **跨具身验证充分**：统一 37-D 动作 / 74-D 状态槽位设计 + 数据集 token，覆盖仿真与真实、桌面臂与人形。
- **实验控制严格**：统一代码库、统一数据、统一超参重训所有基线，对比公平性较好。
- **包含真实机器人实验与定性分析**，并给出失败模式的行为学解释（如遥操作中的"对齐停顿"被短时序窗口误读）。

## 8. 不足与局限

- **真实世界样本量小**：每任务仅 10 trials、单一 Franka 平台，成功率差异的统计显著性与跨平台泛化性存疑。
- **Stage 1 数据规模仍有限**：仅扩至约 2.3M 转移，未验证更大规模动作数据集（如 Open X-Embodiment 级别）下的 scaling 行为，作者亦自认语料"modest"。
- **统一动作空间依赖人工槽位设计**：37-D/74-D 的映射与零填充需针对新具身手工配置，扩展到任意具身时可能不够自动化。
- **蒸馏时长敏感**：$N_{decay}$ 需调参，过长会限制 VLM 表征灵活性（全程蒸馏反而低于基线），缺少自适应调度机制。
- **未与视觉/视频先验方法直接对比**：如 LAPA、Moto、VLA-JEPA 等基于视觉轨迹的潜在动作方法未纳入实验对比，仅停留在相关工作讨论。
- **缺少方差报告**：主表与消融未给出多次运行的均值±方差或置信区间，结果稳健性难以量化评估。
- **计算资源门槛**：8×H200、50k 步训练，复现成本较高；未讨论低资源场景下的可行性。
- **潜在偏差风险**：真实任务数量（4 个）与类型（均为 pick-and-place）较窄，长尾结论可能受任务选择影响。
