## 摘要
我们提出连续动作世界模型（CoAWM），一个用于学习跨具身时空动力学先验的框架，支持跨具身与执行频率的机器人动作生成。其核心是一个共享的隐函数空间，用于捕捉机器人动作的空间与时间结构。我们通过两个阶段学习该空间。首先，函数预训练将来自不同具身和采样频率的轨迹带入统一表示，并通过动作重建以及跨时间采样视图的一致性来学习共享动力学先验。通过容纳异构机器人轨迹，该阶段拓宽了可用于预训练的数据来源范围，并有助于扩展到更大、更多样的数据集。其次，我们将预训练的函数空间连接到世界模型骨干，使观测、语言指令和当前机器人状态能够条件化潜在动作函数的预测。单一解码器接收任意查询时间并返回相应的末端执行器动作。通过将共享动力学先验与任务条件化的动作选择和时间采样分离，我们的方法为跨具身和控制频率迁移机器人经验提供了统一基础。

## Abstract
We introduce Continuous-Action World Models (CoAWM), a framework for learning cross-embodiment spatiotemporal dynamics priors that support robot action generation across embodiments and execution frequencies. At its core is a shared latent function space that captures the spatial and temporal structure of robot actions. We learn this space through two stages. First, function pretraining brings trajectories from different embodiments and sampling frequencies into a common representation, learning shared dynamics priors through action reconstruction and consistency across temporal sampling views. By accommodating heterogeneous robot trajectories, this stage broadens the range of data sources available for pretraining and facilitates scaling to larger and more diverse datasets. Second, we connect the pretrained function space to a world-model backbone, enabling observations, language instructions, and the current robot state to condition the prediction of a latent action function. A single decoder takes any query time and returns the corresponding end-effector action. By separating shared dynamics priors from task-conditioned action selection and temporal sampling, our approach provides a unified foundation for transferring robot experience across embodiments and control frequencies.

## 1. 核心问题与研究背景

- **背景**：不同形态的机器人可以完成相似任务，但其经验通过**不同的动作接口**（末端位姿、关节、夹爪指令等）和**不同的控制频率**被记录。同一条轨迹在不同机器人上对应不同的指令序列。
- **核心问题**：机器人世界模型如何利用**跨具身收集的经验**，学习可共享的**时空动力学先验**，并用它指导动作生成？
- **难点不止是“把更多轨迹拼在一起”**：
  - 数据在“动作表示什么、如何与机器人状态绑定、指令何时发出”三方面均不同；
  - 相同的序列索引可能对应不同的**物理时刻**；数值相近的指令在不同接口下含义不同；
  - 仅统一存储格式无法消除上述差异。
- **需求**：需要一个既能刻画可复用的空间/时间结构、又保留“在特定机器人上解释与执行动作”所需信息的表示；同时该表示还要能把共享经验连接到**当前场景与任务条件下的动作选择**。
- **关键洞察**：把动作的演化建模为**函数**，而不是把采样出的指令当作表示的基本对象——隐动作函数编码运动如何在时空上展开，具体指令通过对该函数**查询时间**获得。由此可把两个学习问题解耦：
  1. 从异构轨迹中获取动力学先验（可用数据源更广）；
  2. 依据当前交互上下文选择动作（连接世界模型的观测条件化能力）。

## 2. 方法论

### 2.1 总体框架（两阶段）

- **Stage A：函数预训练**——用跨具身、跨采样频率的带时间戳轨迹学习共享隐函数空间（编码器 + 解码器），损失为动作重建 + 跨时间采样视图一致性。
- **Stage B：与世界模型对接**——将预训练函数空间接到世界模型骨干上，由视觉观测、语言指令、当前机器人状态条件化预测一个隐动作函数；解码器按任意查询时间输出末端执行器动作。
- **推理**：观测编码 → 视觉世界预测 → 隐函数预测 → 时间查询解码；执行频率由查询时间点决定。

### 2.2 连续动作函数表示

- 动作序列表示为带时间戳的观测集合 A = {(τᵢ, aᵢ, mᵢ)}，aᵢ 为末端指令，mᵢ 为有效分量掩码；τ = 0 表示当前观测。
- 编码/解码：
  - Z = E_φ(A, c)，a(τ) = D_ψ(Z, τ, c)；
  - **隐变量尺寸固定，观测/查询时间戳可变**。
- 实现上用外部时间坐标 u 与物理时钟相差 Δt（当前观测到首个动作目标的延迟）：τ = u + Δt，解码器内部按 τ − Δt 计算；执行段为 1.2 s 物理时间。

### 2.3 MoT（Mixture-of-Transformers）编码器

- 三条**类型化动作流**：位置 XYZ（双臂 6 维）、朝向 Q（四元数 8 维）、夹爪 G（2 维）；输入 token 含时间戳与有效性掩码，避免把缺失观测当作有效指令。
- 先用类型化 Perceiver 块把轨迹 token 聚合为学习到的隐查询；再用 Latent MoT 块在三条流之间交换信息：**每流独立的 Q/K/V/输出投影、归一化与 FFN，但注意力在所有流上联合计算**（既建模各分量特性，又捕捉时间协调）。
- 瓶颈：**96 个 token × 宽 256，每模态 32 个 token**。

### 2.4 独立时间查询解码器

- 查询由“请求的物理时间 + 傅里叶特征 + 模态嵌入 + 已知执行信息”构成，经类型化交叉注意力读取隐记忆，输出 XYZ/Q/G。
- 每个时间戳通过**各自的 query-to-memory 注意力**独立求值 → 某时刻动作不依赖其他请求时间点的数量与顺序，因此**同一隐函数可按不同频率产出动作序列**。

### 2.5 锚定式几何读出

- 位置：p(τ) = p₀ + e_p(τ) − e_p(0)（以当前位姿 p₀ 为锚）；
- 朝向：q(τ) = normalize(q₀ ⊗ r(0)⁻¹ ⊗ r(τ))；
- 二者在 τ = 0 处**严格恢复当前观测位姿**（硬锚定）。
- 夹爪采用**时间索引的 knot 读出**（在原生 knot 上预测、查询取最近 knot），以适配离散夹爪切换。

### 2.6 Stage A 损失（跨频率一致性）

- 每条轨迹构造两种采样率的视图 A⁽¹⁾、A⁽²⁾（同一物理时钟），得 Z⁽¹⁾、Z⁽²⁾。
- 每个视图在**源时间戳**与**额外查询网格**（u ∈ [0, 1.2] s 上 73 点、60 Hz）上受重建监督。
- 单视图重建误差（按掩码求均值）：E = mean[ ‖Δp‖²/6 + (θ_L² + θ_R²)/2 + (Δg_L² + Δg_R²)/2 ]，其中 θ 为 SO(3) 测地角，位置单位为米，三项按原生尺度；源项与网格项分别归约后**等权**。
- 总目标：L_A = ½ Σ_{v=1,2} (E_source⁽ᵛ⁾ + E_grid⁽ᵛ⁾) + 0.1 · MSE(Z⁽¹⁾, Z⁽²⁾)。
- 重建教会解码器“运动如何随时间演化”，一致性对齐不同观测频率的表示。
- **可扩展轨迹接口**：Stage A 只需时间戳末端轨迹 + 分量有效性 + 已知执行信息，**不需要配对语言指令或相机观测**，从而拓宽预训练数据来源。

### 2.7 Stage B：接入世界模型（基于 LaWAM）

- 头部 + 双腕 RGB 与语言指令经 VLM 得 h_vlm 及原 latent-action 预测 â_latent；当前图像得 LAM 视觉 token h_t；冻结的世界解码器预测未来视觉 token：ĥ_{t+1} = LAMDecoder(h_t, â_latent)。
- 预测头交叉注意力记忆：M = concat(P_v h_vlm, P_f ĥ_{t+1}, P_s s)，s 为本体状态。
- 输出：Ẑ = W_out H + W_res · Attn(H, P_c h_t, P_c h_t)，H 为 LayerNorm 后的隐 token；**W_res 零初始化**（当前视觉信息以残差方式注入）。
- 监督：目标隐变量 Z* = sg[E_φ(A*, c)]（停梯度）；隐空间用**余弦相似度损失**（按样本展平后 1 − cos）；动作侧用带尺度 s_p = 0.01 m、s_q = 0.05 rad、s_g = 0.05 的归一化位置/旋转角/夹爪误差 L_phys；总损失 L_B = L_latent + 0.1·L_phys。
- **编码器与解码器冻结**，梯度经解码器回传以训练隐预测通路与骨干适配器；世界预测分支冻结。

### 2.8 时间查询执行

- 每个重规划步用当前观测预测**一个**隐函数，并把位姿读出锚定到当前状态。
- 对频率 f：τ_k = (k+1)/f，u_k = (k+1)/f − Δt，a_k = D_ψ(Ẑ, τ_k, c)，k = 0…f·T_exec − 1；原生执行 30 Hz。

- **具体实验组**：

## 6. 主要结论与发现

- 函数自编码器能以毫米/零点几度级精度重建真实动作轨迹，说明**隐函数空间具备足够表示能力**，为与世界模型对齐提供基础。
- 在**运动速度基本不变**（速度 RMS 0.338 vs 0.332）的前提下，连续动作函数显著降低初始执行阶段的平移与旋转 jerk（−36.7% / −54.2%），即改善“起步抖动”。
- **同一隐函数**可通过改变查询时间在 10–60 Hz 多种频率下执行，且在执行段与重规划周期固定的条件下保持 73–81% 的成功率。
- 双臂多任务操作可达 86–94% 成功率；基于 PD 力矩估计的正机械功平均降低 22.6%。
- 分离“共享动力学先验”“任务条件化动作选择”“时间采样”三者，可为跨具身、跨控制频率的经验迁移提供统一基础。
- 作者同时承认：更长执行窗口上仍存在明显的 **jerk 长尾**，持续执行与重规划下的动作稳定性尚待解决。

## 7. 优点

- **表示层面思路清晰**：把动作建模为“可查询的函数”而非离散指令块，天然统一了不同采样率/执行频率，且**时间查询相互独立**（不依赖查询点数量与顺序），实现“一个隐变量、多种频率”。
- **问题解耦合理**：Stage A 只需时间戳轨迹 + 有效性掩码 + 执行上下文，无需语言与图像配对，**显著拓宽预训练数据来源**，具备向大规模异构数据扩展的接口设计。
- **类型化结构设计细致**：MoT 分 XYZ/Q/G 三流独立参数 + 联合注意力；时间戳与掩码入 token；夹爪单独用 knot 读出以适配离散切换；硬锚定保证 τ = 0 与观测一致（利于闭环）。
- **训练策略稳健**：Stage B 冻结函数编码器/解码器，仅训练隐预测通路与适配器，保护预训练函数空间；目标隐变量 stop-gradient；视觉残差零初始化，训练初期不破坏主通路。
- **评估维度超出常规**：除成功率外，引入 jerk、速度、基于 PD 力矩估计的机械功，关注“动作质量”而非仅“是否成功”，并用配对试验控制混杂。
- **诚实披露局限**：明确标注为初步验证、说明评估队列不同、指出 jerk 长尾问题。

## 8. 不足与局限

- **实验覆盖不足**：无消融、无跨具身迁移定量验证、单基线（LaWAM）、无真实硬件能耗测量（仅 PD 力矩估计）。
- **“跨具身”证据薄弱**：实现细节高度绑定双臂 6+8+2 维的类型化接口，异构性主要靠“同一接口 + 掩码 + 上下文”吸收；对维度/语义差异更大的具身（单臂、关节空间、移动底盘）如何适配未讨论。
- **时间尺度受限**：执行段固定 1.2 s、原生 30 Hz；长时执行、重规划一致性与 jerk 长尾未解决。
- **表示约束**：位置/朝向的硬锚定使预测必须以当前位姿为起点，可能限制需要大范围重定位或非连续运动的场景；夹爪“最近 knot”读出限制了夹爪连续/高频变化。
- **评估统计问题**：不同结论使用不同队列与分母；部分成功率对比缺少基线的同批数值；50 任务 × 3 试样本量偏小；能耗只统计双方均成功的场景。
- **可复现性与算力信息缺失**：训练数据构成、规模、超参、算力均未报告，难以评估可扩展性主张的实际成本。
- **应用限制**：依赖 VLM + 世界模型骨干（LaWAM）与多相机设置，推理链路包含观测编码、视觉世界预测、隐函数预测、时间查询解码多阶段，实时性与部署成本未评估。
