## 摘要
由于不同末端执行器之间的动作空间异构，从多具身数据集中学习大规模视觉-语言-动作（VLA）模型仍然具有挑战性。尽管潜在动作模型（LAM）能够从多样化的视频数据中学习与具身无关的动作表示，但现有的基于图像的 LAM 往往无法捕捉细粒度的末端执行器关节运动，尤其是人类手和灵巧机器人手中的手指级几何变化。为解决这一局限，我们提出 GALA，一个几何感知的潜在动作建模框架，用三维末端执行器几何运动增强基于图像的潜在动作。然而，朴素地引入点云会产生共享语义有限的细粒度动作表示，阻碍跨具身预训练。为解决该问题，我们引入统一末端执行器运动表示（UEMR），其在保留细粒度运动信息的同时提升潜在动作的跨具身泛化能力。基于 UEMR，GALA 将捕捉场景级动态的视觉潜在动作与捕捉共享细粒度末端执行器关节运动的几何潜在动作相结合，为利用多具身数据（包括无动作的第一人称人类视频）进行 VLA 预训练提供有效监督。在细粒度运动探测、跨具身检索和下游 VLA 评估上的实验表明，GALA 在跨具身建模可泛化细粒度运动方面有效，在 RoboCasa-GR1 上达到 68.3% 成功率，在真实世界中达到 75.5% 成功率。代码、附录和演示见 https://puzhenyuan.github.io/GALA-website/。

## Abstract
Learning large-scale vision-language-action (VLA) models from multi-embodiment datasets remains challenging due to heterogeneous action spaces across end effectors. Although latent action models (LAMs) can learn embodiment-agnostic action representations from diverse video data, existing image-based LAMs often fail to capture fine-grained end-effector articulation, particularly finger-level geometric changes in human and dexterous robot hands. To address this limitation, we propose GALA, a Geometry-Aware Latent-Action modeling framework that augments image-based latent actions with 3D end-effector geometric motion. However, naively incorporating point clouds yields fine-grained action representations with limited shared semantics, hindering cross-embodiment pretraining. To address this issue, we introduce the Unified End-effector Motion Representation (UEMR), which preserves fine-grained motion information while improving the cross-embodiment generalizability of latent actions. Building upon UEMR, GALA combines visual latent actions that capture scene-level dynamics with geometric latent actions that capture shared fine-grained end-effector articulation, providing effective supervision for VLA pretraining from multi-embodiment data, including action-free ego-centric human videos. Experiments on fine-grained motion probing, cross-embodiment retrieval, and downstream VLA evaluation demonstrate GALA's effectiveness in modeling generalizable fine-grained motions across embodiments, achieving 68.3% RoboCasa-GR1 success rate and 75.5% real-world success rate. Code, appendix, and demos are available at https://puzhenyuan.github.io/GALA-website/.

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型（OpenVLA、π0、GR00T 等）依赖大规模操作数据，但真实机器人示教采集成本高；第一人称人类视频是廉价且动作丰富的补充数据源。
- **核心障碍**：不同具身（人手、灵巧手、二指夹爪、人形机器人）在运动学、自由度、控制参数化上差异巨大，原生动作空间无法直接共享，通常需要重定向或具身特定对齐。
- **现有方案及其局限**：潜在动作模型（LAM，如 LAPA、UniVLA、Villa-X、HARP-VLA）从视觉转移中推断动作表示，可绕开动作标签。但**基于图像的 LAM 主要刻画场景级末端位移**，在手指运动幅度小、被遮挡、视角变化时难以捕捉细粒度关节（articulation），即"知道末端往哪走，却不知道如何操作物体"。
- **朴素引入几何的新问题**：直接把点云引入 LAM 虽能获得细粒度信息，但点云会编码**形态学与坐标系特定线索**（形状、尺度、绝对位姿），导致潜码在不同手/夹爪间缺乏共享语义，反而损害跨具身预训练。
- **整体含义**：论文主张用**"视觉潜在动作（场景级）+ 几何潜在动作（关节级）"互补监督**，在不需要点/关节/运动学对应关系的前提下，实现跨具身、可利用无动作人类视频的 VLA 预训练。

## 二、方法论

### 2.1 总体框架（两阶段）

1. **阶段一：几何感知潜在动作学习**——在统一格式下将人手/机器人末端表示为以腕部或根部为中心的局部点云，从 RGB 与点云转移中联合学习视觉与几何离散潜码。
2. **阶段二：几何感知 VLA 联合训练**——冻结阶段一的 LAM，用视觉/几何潜码通过专用 bridge token 监督 VLM；共享 flow-matching 动作专家 + 具身特定动作头输出各自原生动作。

### 2.2 阶段一：几何感知潜在动作模型

- **点云生成**：
  - 统一表示 $P^{e,h}_t=\{p^{e,h}_{t,i}\}_{i=1}^{N}\in\mathbb{R}^{N\times3}$，$N=1024$，均在腕/根中心局部系、统一轴向下采样。
  - **人手**：用 WiLoR 从每帧 RGB 估计左右 MANO 网格与关键点，变换到掌对齐局部系后采样表面点。
  - **机器人**：由 URDF/MJCF 模型 + 正运动学，将末端连杆表面采样点变换到当前位姿后聚合重采样；灵巧手与二指夹爪共用同一流程。
- **视觉与几何动作编码**：输入起止 RGB $(I_s,I_g)$、语言指令 $\ell$、左右手点云对 $(P^{L}_s,P^{L}_g),(P^{R}_s,P^{R}_g)$；起止点云用**共享中心与尺度**归一化以抑制跨数据集尺度差异，缺失手用有效性掩码排除。冻结 DINOv2 + SigLIP 编码图像、冻结 PTv3 编码点云，经共享时空 Transformer 融合语言条件，输出两类潜码：视觉 token（场景动态）与几何 token（双臂 3D 几何转移）。几何 token 用**共享 EMA-VQ 码本**量化（最近邻查表 $k_j=\arg\min_k\|z^G_j-e_k\|_2^2$），码本在人手、灵巧手、夹爪间共用。

### 2.3 UEMR：统一末端执行器运动表示（三项核心设计）

- **① 统一双臂运动潜码**：几何潜码整体表示**双臂**几何转移，而非左右手各一套；单臂夹爪数据把同一份点云输入两个分支。解码时共享解码器以各手初始几何为条件分别重建目标点云：
  $\hat P^R_g=D_G(P^R_s,Q(Z^G))$，$\hat P^L_g=D_G(P^L_s,Q(Z^G))$，用 Chamfer Distance 加掩码监督。以初始几何为条件可迫使潜码编码**转移**而非静态形态。
- **② 成对一致的几何增广**：对每个起止点云对施加**同一个**随机 3D 变换 $A(P)=aRP+t$（起点与终点同步变换），保持相对几何运动不变、扰动绝对坐标系，抑制数据集特定坐标捷径。
- **③ 双向转移学习**：同时建模前向 $Z^G_f=E_G(X_s,X_g,\ell)$ 与反向 $Z^G_b=E_G(X_g,X_s,\ell)$，共享编码器/码本/解码器，不强制两方向潜码间的显式关系，仅增加转移监督。

### 2.4 训练目标（阶段一）

- 前向损失：$\mathcal{L}_{forward}=\mathcal{L}_{I\text{-}rec}+\mathcal{L}_{I\text{-}codebook}+\beta\mathcal{L}_{I\text{-}commit}+\lambda_G\mathcal{L}_{G\text{-}rec}+\beta\lambda_G\mathcal{L}_{G\text{-}commit}$（视觉分支常规 VQ 监督，几何分支 CD 重建 + EMA-VQ 承诺项）。
- 总损失：$\mathcal{L}_{LAM}=\mathcal{L}_{forward}+\mathcal{L}_{backward}$。

### 2.5 阶段二：几何感知 VLA 联合训练

- **骨干**：GR00T 架构（视觉-语言骨干 + flow-matching 动作专家），预测长度为 $H$ 的动作块。
- **潜动作预测**：向 VLM 输入序列追加两组可学习 bridge token $q^{img},q^{geo}$，其隐状态分别投影到视觉/几何潜码词表，自回归预测 $\hat k^{img}_t,\hat k^{geo}_t$，损失为交叉熵 $\mathcal{L}_{latent}=\mathcal{L}_{img}+\lambda_{geo}\mathcal{L}_{geo}$。
- **保留原生动作空间**：不人为统一动作空间。人手动作为相机系下双腕 3D 位置与旋转 + 各自腕系下手指关键点位置（分解为全局手运动与局部手指关节）；机器人直接沿用各数据集原始动作空间。
- **共享 DiT + 具身特定动作头**：共享 DiT 处理 VLM 上下文、本体状态、加噪动作块与 flow 时间步，各具身轻量头 $h_e$ 映射到原生动作空间：$V_{\theta,e}=h_e(f_{DiT}(\cdot))$；每个样本只激活并优化对应头，损失为 flow-matching 回归 $\|\cdot-(A_t-\epsilon)\|_2^2$。
- **总目标**：$\mathcal{L}_{VLA}=\mathcal{L}_{action}+\lambda_{latent}\mathcal{L}_{latent}$。

## 六、主要结论与发现

- **细粒度运动建模**：GALA 在位置（5.359 cm）、旋转（7.898°）、手指（7.585°）三项误差上均最优；去掉点云后手指误差从 7.585° 恶化到 15.113°，说明**图像 LAM 确实丢失手指级信息**，几何分支是必要补充。
- **跨具身共享语义**：检索上 GALA 最优（full track R@1 45.67%、mAP 49.49%；robot-only R@1 46.91%），优于 METIS、OPFA、Native Kinematics 及两个消融版本，表明 UEMR 能提升潜动作的跨具身可迁移性。
- **仿真下游**：仅 GR-1 数据的受控设置下 GALA 达 55.7%，高于 OPFA(53.5)、Native Kinematics(51.8)、w/o UEMR(54.4)、w/o PC(50.9)、UniVLA(48.0)、METIS(43.8)；多具身联合训练下达 **68.3%**，超过 UniT(66.8)、JoyAI-RA(63.2) 等，且相对 GR-1-only 提升 **+12.6%**，显著大于 UniVLA(+5.6%) 与 w/o UEMR(+4.2%)，说明**增益主要来自 UEMR 带来的跨具身知识迁移**。
- **真实世界**：平均成功率 **75.5%**，超过 HARP-VLA(71.5)、π0.5(68.0)、OpenVLA-OFT(55.0)；去掉 UEMR 下降 7.0 点，进一步验证 UEMR 的价值。
- **总体结论**：几何感知潜动作在无需关节/点/语义关键点对应、且保留各具身原生动作空间的前提下，为多具身（含无动作第一人称人类视频）VLA 预训练提供了有效的细粒度监督。

## 七、优点

- **问题定位精准**：明确指出图像 LAM 的盲区是"how it manipulates"而非"where it moves"，并用探针实验量化（手指误差翻倍）加以证实。
- **表示设计巧妙**：用**无序点云**作为跨具身通用几何接口，天然规避拓扑/关节数/运动学结构不一致；用"以初始几何为条件的重建"把潜码从静态形态中解耦。
- **UEMR 三项设计针对性强**：统一双臂潜码解决左右手/单双臂数据混合；成对一致增广消除坐标系捷径；双向学习增强相对时序动态——每一项都有对应消融支撑。
- **工程兼容性好**：不强制统一动作空间，共享 DiT + 具身特定头，既共享高层动力学又保留原生控制语义，便于接入现有数据集与机器人。
- **监督信号互补**：视觉潜码（语义/场景）+ 几何潜码（物理/关节）双 bridge token，兼顾任务意图与几何动力学。
- **评测层次完整**：表示探针 → 跨具身检索 → 仿真受控/联合训练 → 真实世界，且受控实验严格控制变量，消融与增益分解清晰。

## 八、不足与局限

- **算力与可复现性信息缺失**：未报告 GPU 型号/数量/训练时长、模型规模与数据量级，难以评估方法门槛与复现成本。
- **对上游几何估计的依赖**：人手点云依赖 WiLoR/MANO 单目重建，遮挡、视角、快速运动下的重建误差会直接污染几何潜码；机器人点云依赖精确 URDF/MJCF 与关节状态，模型误差或标定偏差同样会传导。
- **"无需对应"的边界**：虽不要求点/关节对应，但仍需**统一轴系约定、腕/根中心局部系、共享归一化尺度**等人工约定，跨数据集迁移时这些约定本身可能引入偏置。
- **单臂夹爪处理较粗糙**：将同一份点云复制到左右两个分支，属于工程性权宜，未验证其对双臂/单臂混合数据分布的影响。
- **实验覆盖有限**：
  - 探针只在 XHand 留出集评测，未覆盖人手、Fourier 手、夹爪；
  - 检索仅 3 类粗粒度运动标签；
  - 真实世界仅 1 个平台、4 个任务、50 次试验，缺少方差、置信区间与失败案例分析；
  - 未报告新具身零样本/少样本迁移、长时序任务、多物体杂乱场景的表现。
- **基线公平性风险**：Table IV 的 FLARE/DiT4DiT/JoyAI-RA/UniT 为公开报告数值，训练数据与调参预算不可控，横向比较应谨慎解读。
- **缺少敏感性与效率分析**：码本大小 $K_G$、点云数 $N$、$\lambda_{geo}/\lambda_{latent}$、bridge token 数量的影响未在正文给出；推理时的额外点云编码与双分支预测开销未评估，可能限制实时部署。
- **应用限制**：需要末端几何模型（URDF/MJCF）或手部重建管线，对无模型、软体手、工具使用等场景适用性未知；同时几何监督对"非接触式/纯视觉语义"任务的增益可能有限。
