## 摘要
将人形机器人全身控制扩展到通用部署，需要大规模人体运动语料库以及跨机器人本体共享的训练经验。现有方法通常为每个机器人训练一个策略，导致运动经验在不同具身之间相互隔离。我们提出 X-WBC，一个跨具身基础框架，将相对共享的人体运动语义与特定具身的物理执行分离。以人为中心的命令 token 对齐完整人体运动、机器人参考运动和稀疏 VR 观测。因果 Transformer 从混合多机器人轨迹中学习可复用的时序结构，而轻量级机器人特定模块将共享表示映射到每个机器人的本体感知和动作空间。在九个仿真具身、外部运动和四台真实机器人上的实验表明，联合训练提升了跟踪性能，对齐后的表示支持跨命令源的一致控制，且学习到的策略在训练语料之外仍具有竞争力。这些结果支持将异构人形机器人作为联合数据源，并确立跨具身联合训练作为通向全身控制基础模型的实用路径。

## Abstract
Scaling humanoid whole-body control toward general-purpose deployment requires large human motion corpora and training experience shared across robot bodies. Existing methods usually train one policy per robot, leaving motion experience isolated across embodiments. We introduce X-WBC, a cross-embodiment foundation framework that separates relatively shared human motion semantics from embodiment-specific physical execution. Human-centered command tokens align full human motion, robot reference motion, and sparse VR observations. A causal Transformer learns reusable temporal structure from mixed multi-robot rollouts, while lightweight robot-specific modules map the shared representation to each robot's proprioception and action space. Across nine simulated embodiments, external motions, and four real robots, experiments show that joint training improves tracking, the aligned representation supports consistent control across command sources, and the learned policy remains competitive beyond the training corpus. These results support heterogeneous humanoids as joint data sources and establish cross-embodiment joint training as a practical route toward whole-body control foundation models.

# X-WBC 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：当前人形机器人全身控制（WBC）已普遍采用“人体运动数据 + 运动跟踪”范式，支撑遥操作、技能学习与自主性（H2O、OmniH2O、HumanPlus、BeyondMimic、SONIC 等）。
- **核心痛点**：这些系统的**训练单元仍是单一机器人**——每个平台各自做运动重定向（retargeting）、各自训练策略、各自调参部署。结果是 AMASS、LAFAN1、BONES-SEED 等大规模人体运动语料的多样性，被切割成互不相通的“机器人专属运动数据”，运动经验无法跨具身积累。
- **领域空白**：机器人基础模型（RT-2、OpenVLA、π0、GR00T、Open X-Embodiment、HPT、CrossFormer、X-VLA 等）已在操作/VLA 场景探索跨具身数据共享，但**能否迁移到闭环人形全身控制（需满足平衡、动力学、关节空间控制约束）尚属未探索**。
- **核心洞见**：人体运动数据承载**相对具身无关的运动语义**（走、踢、蹲、伸手的时序结构与几何意图），而执行这些语义的机器人运动是**具身特定**的。同一个人体动作经重定向到不同机器人，即同一意图的多种“实现”，因此**机器人多样性可以补充运动多样性**，共同监督一个共享骨干。
- **整体含义**：把 WBC 从“为每个本体训练一个策略”重构为“跨具身联合训练一个共享运动表示”，为全身控制基础模型提供可积累而非隔离经验的路径。

## 2. 方法论

### 2.1 问题形式化

- 将训练表述为**多机器人运动跟踪**：每个机器人 $i$ 定义独立 MDP $M_i=(S_i,A_i,T_i,R,\gamma)$，其中状态空间、动作空间、转移动力学具身特定，而**奖励族 $R$ 与折扣因子 $\gamma$ 跨机器人共享**。
- 用 PPO 在所有机器人的 rollout 上优化共享跟踪目标。

### 2.2 观测、动作与奖励

- **非对称 Actor-Critic**：Actor 观测 = 本体感知 $s^{p,i}_t=(q_t,\dot q_t,\omega_t,g_t,a_{t-1})$（关节位置/速度、基座角速度、体坐标系重力投影、上一动作）+ **单一路由的运动命令** $s^c_t$；Critic 额外获得特权信息（体坐标系下各连杆位置/朝向、基座线速度）。
- **动作**：输出关节动作，经低层 PD 控制器转力矩；训练时不同机器人动作/观测维度**填充（padding）到机器人集合最大维度**以便混批，执行时机器人专用解码器只保留有效维度。
- **奖励**：所有机器人共用同一奖励族 $r^i_t=R_{track}+P$，跟踪项含根位置/朝向、相对体姿、体线速度/角速度，惩罚项含动作变化率、关节限位、非允许接触（附录 A1 给出权重）。

### 2.3 以人为中心的命令编码（三条路由）

| 路由 | 共享性 | 输入 | 作用 |
|---|---|---|---|
| 人体运动命令编码器 | 跨机器人共享 | 全身人体运动（22 关节 × 12 维） | 提供与机器人关节定义无关的**语义锚点** |
| 机器人运动命令编码器 | 机器人专用 | 机器人本体空间参考运动（14 体 × 12 维） | 来自重定向/录制/生成，处理关节顺序与可执行约束 |
| 稀疏 VR 命令编码器 | 跨机器人共享 | 5 个关键点（头 + 四末端，60 维） | 可部署的低带宽人机接口 |

- 命令统一用**位置 + 6D 朝向 + 速度**表示（而非仅关节角），并在根/机器人中心坐标系归一化，使 token 聚焦相对运动结构、对全局坐标偏移与操作者体型差异鲁棒。
- 训练时对同一运动片段的三类 token 施加**对齐约束**，使共享骨干对同一底层意图的不同视图“一致使用”。

### 2.4 共享骨干与机器人专用模块

- 共享骨干为**因果 Transformer**：每步将命令 token 与本体感知 token 拼接为观测 token，在长度 $L=32$ 的因果历史窗口内聚合：
  $$h^i_t = B_\theta\big(\{[z_{c,\tau};\,z^i_{p,\tau}]\}_{\tau=t-L+1}^{t}\big)$$
- 在线 rollout 使用 **KV cache**，每步只处理新 token，避免重算历史窗口，保证实时性。
- **机器人专用模块**（由 robot ID 路由，轻量 MLP，每层 [256,256,64]）：本体感知编码器 + 动作解码器；共享 Transformer 学可复用运动语义，专用模块负责“翻译”为可执行关节动作。

### 2.5 训练流程

- **多机器人联合训练**：Isaac Lab 中多机器人同时 rollout，各自保留状态/动作/接触/终止逻辑；每仿真步后把各机器人 transition 混入**同一 PPO batch**，联合更新共享模块与当前激活的专用模块。
- **损失**：$\mathcal{L}=\mathcal{L}_{PPO}+\lambda_{align}\mathcal{L}_{align}$，$\lambda_{align}=1.0$；$\mathcal{L}_{align}$ 为同一片段三个归一化命令 token 的**两两 MSE**（在进入骨干前计算）。
- **命令路由采样**：每个 episode 按 **1:1:1** 采样一条命令路由并全程使用。
- **终止条件**：根垂直位置误差 > 0.25 m、根朝向误差 > 0.8 rad、末端垂直位置误差 > 0.25 m。
- **自适应运动采样**：按失败率提升困难时间 bin（1.0 s）的采样概率；工作集 1024 条运动，保留 0.1 均匀混合；对持续失败（失败率 0.98）片段做硬剔除（主要过滤重定向伪影与物理不可行片段）。
- **域随机化**：摩擦系数、恢复系数、默认关节位置、基座质心偏移、周期性根速度扰动。

## 6. 主要结论与发现

- **联合训练有效**：G1 SR 98.60%（vs MLP 97.70%、单机器人 97.69%）；H2 93.22%（vs 91.33%、92.22%）；两种机器人上体速度误差均最低。G1 位置误差相近但成功率与速度跟踪更好，说明**闭环稳定性提升**；H2 上差距更大，说明**共享监督对更难具身价值更高**。
- **命令源一致性成立**：VR / 机器人 / 人体三种输入在 G1、H2 上成功率接近（G1：98.60/98.21/98.66；H2：93.22/92.08/93.02）。人体命令在若干体指标上略优；机器人命令因已在目标参考空间内，根旋转误差更低。
- **组件均有用**：去掉任一条稠密路由、对齐损失或专用模块都会降低成功率；H2 上降幅最大来自去除稠密命令路由；**去掉机器人专用模块仍相对较强**（G1 96.54%、H2 88.65%），说明本体感知本身携带具身信息。
- **外部运动仍具竞争力**：100STYLE 全网格上 X-WBC（VR5）SR 91.13%、完成度 91.66%，接近 SONIC（93.00%/93.35%），远超 TWIST（75.62%/78.18%）；SONIC 速度误差更低，TWIST 位置误差更低但完成度差约 15.5 点。
- **token 空间兼具共享性与具身性**：跨源检索 86.0%（同相位）/94.2%（同运动），跨机器人 61.3%/76.1%，均远高于随机；**跨源高于跨机器人**说明 token 中仍保留具身执行信息；**同运动高于同相位**说明运动身份比精确时序相位更稳定。
- **真机可行**：同一人类中心接口 + 共享骨干可驱动 4 台尺寸、自由度差异显著的人形机器人。

## 7. 优点

- **问题重构有价值**：把“每机器人一策略”转为“多机器人联合跟踪”，并给出清晰的“共享语义 / 具身执行”解耦论证（人类学徒类比、重定向即同一意图的多实现）。
- **架构设计克制且工程可行**：共享因果 Transformer + 极轻量机器人专用 MLP + padding 混批 + KV cache，兼顾跨具身共享与实时控制；用机器人 ID 路由而非重型具身条件网络，参数效率高。
- **三路由命令对齐是核心创新**：把稠密人体运动、稠密机器人参考、稀疏 VR 观测统一到同一 token 空间，既保证训练监督质量，又保留低成本可部署接口（仅 5 关键点）；1:1:1 采样 + 对齐损失使三者可直接互换推理。
- **实验维度互补**：分布内拟合、冻结外部泛化、token 检索表示分析、真机部署四条线互相支撑，而非仅报成功率。
- **诚实性较好**：明确区分“分布内拟合”与“泛化”，主动指出 TWIST 的 MPKPE 受截断偏差影响，局限性章节坦承专用模块/重定向仍是部署管线一部分。
- **可扩展性叙事清晰**：9 个具身、跨厂商（Unitree / Fourier / Booster / PND）验证了“异构人形作为联合数据源”的可行性。

## 8. 不足与局限

- **并非真正零样本跨具身**：仍需机器人专用命令编码器、本体感知编码器、动作解码器、控制逻辑与逐机器人重定向；新机器人上线仍需训练专用模块。作者将“零样本 X-WBC / 形态条件化接口”列为未来工作。
- **形态覆盖受限**：仅人形（且以 Unitree 为主，真机 4 台全为 Unitree），向更异构形态、体型比例、关节布局的迁移未知；无法排除“共享收益主要来自相似人形之间”的解释。
- **真机验证薄弱**：仅定性展示有限的上/下肢行为，缺跨方法定量对比、长任务序列、复杂接触与地形、跨厂商部署。
- **评测统计性不足**：单 seed、单次确定性 rollout、无置信区间；关键结论（如联合训练相对单机器人的增益）幅度小，易受随机性影响。
- **基线公平性存疑**：SONIC/TWIST 保留原生输入与低层控制器，未在同一数据/同一控制栈下重训；100STYLE 仅单演员，风格与体型多样性有限；外部评测仅 G1，无法验证跨具身泛化。
- **指标偏差风险**：MPKPE/速度误差在失败后截断，成功率与精度指标存在耦合，跨系统比较需谨慎；SR 与 MPKPE 排序不一致（图 3）也说明单一指标易误导。
- **训练与部署成本未量化**：缺 GPU-hours、推理延迟、通信/状态估计噪声下的鲁棒性测试；稀疏 VR 虽低带宽，但训练仍依赖稠密机器人参考，部署仍需逐机器人标定。
- **潜在混淆因素**：重定向质量（GMR 管线 + 机器人专用参数）直接影响跟踪上限，论文未做重定向质量的消融隔离；自适应采样中的硬剔除可能掩盖数据/重定向问题而非解决问题。
- **缺负迁移与 scaling 分析**：未报告“增加某机器人是否损害另一机器人”，也未给出性能随机器人数/数据量的变化趋势，难以判断该范式的扩展边界。
