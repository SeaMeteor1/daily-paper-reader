## 摘要
机器人模仿学习常被视为复现演示动作，但动作本质上具有具身特异性。当演示来自形态、运动学或动作空间不同的人类或机器人时，这种以动作为中心的观点需要共享动作空间、启发式重定向或大规模多具身联合训练。我们转而将演示视为对未来目标的隐式规范：目标智能体应推断演示者试图实现何种状态，而非演示者如何执行。我们提出 Demo-JEPA，一种跨具身模仿框架，将演示意图与具身特定执行解耦。Demo-JEPA 构建于基于 JEPA 的世界模型之上，在共享预测表示空间中将源视觉演示转换为目标兼容的未来潜在轨迹。目标智能体随后将这些潜在轨迹用作子目标，并在其自身学习的前向动力学下通过规划实现它们。由于 Demo-JEPA 避免动作级对应，且仅需视觉演示以及目标智能体自身的交互经验，它支持跨异构具身的灵活模仿。在 RLBench 和真实世界操作任务上的实验表明，Demo-JEPA 与专门的域内规划器相当，并能泛化到先前方法失败的未见任务和具身配置。

## Abstract
Robotic imitation learning is often treated as reproducing demonstrated actions, but actions are inherently embodiment-specific. When demonstrations come from humans or robots with different morphology, kinematics, or action spaces, this action-centric view requires shared action spaces, heuristic retargeting, or large-scale multi-embodiment co-training. We instead view demonstrations as implicit specifications of future goals: the target agent should infer what state the demonstrator is trying to realize, rather than how the demonstrator executes it. We propose Demo-JEPA, a cross-embodiment imitation framework that decouples demonstration intent from embodiment-specific execution. Built on a JEPA-based world model, Demo-JEPA translates source visual demonstrations into target-compatible future latent trajectories in a shared predictive representation space. The target agent then uses these latent trajectories as subgoals and realizes them through planning under its own learned forward dynamics. Because Demo-JEPA avoids action-level correspondence and requires only visual demonstrations plus the target agent's own interaction experience, it supports flexible imitation across heterogeneous embodiments. Experiments on RLBench and real-world manipulation tasks show that Demo-JEPA matches specialized in-domain planners and generalizes to unseen tasks and embodiment configurations where prior methods fail.

- **核心问题**：跨具身模仿学习中的“具身鸿沟”。演示者与学习者可能在形态、运动学、自由度、动作空间和视觉外观上不同，同一语义行为对应的底层动作可能完全不同。
- **现有范式局限**：主流方法多采用“动作级对齐”，如共享动作空间、动作重定向、跨具身动作对应学习、大规模多具身联合训练或 VLA 模型。这些方法依赖动作监督或大量联合数据，在异构具身之间泛化仍困难。
- **论文的整体主张**：不应要求目标机器人复现“演示者如何做”，而应推断“演示者想实现什么未来状态”。论文将跨具身模仿重新表述为**共享预测表示空间中的潜在目标条件规划**。
- **意义**：把演示意图与具身特定执行解耦，理论上可绕开动作空间对齐瓶颈；仅需源具身的视觉演示和目标智能体自身交互经验，为异构机器人之间的技能迁移提供新思路。

### 2. 方法论

- **核心思想**：基于 JEPA（Joint-Embedding Predictive Architecture）世界模型，在潜在空间中把源具身视觉演示转换为目标具身兼容的未来潜在目标，再由目标机器人用自己的动作条件世界模型规划实现该目标。
- **问题设定**：
  - 源具身提供仅含观测的演示轨迹 \(\tau^s=\{o^s_k\}\)。
  - 目标具身拥有观测 \(o^t_k\)、状态 \(s^t_k\) 和动作 \(a^t_k\)。
  - 每个时刻输入当前目标观测与源演示帧对 \((o^s_k,o^s_{k+n})\)，输出目标动作序列。
- **动作条件世界模型**：
  - 使用 V-JEPA 2.1 作为目标具身世界模型。
  - JEPA 编码器 \(E(\cdot)\) 将观测映射为潜在状态 \(z_k=E(o^t_k)\)。
  - 动力学预测器 \(F_{wm}\) 建模 \(\hat z_{k+1}=F_{wm}(z_k,s^t_k,a^t_k)\)。
  - 给定潜在目标 \(z^t_{goal}\)，通过优化动作序列使世界模型预测的潜在 rollout 接近目标，使用 Cross-Entropy Method（CEM）求解。
- **Dreamer Predictor（核心模块）**：
  - 输入当前目标观测和源演示帧对，在共享 JEPA 潜在空间中做跨具身未来状态翻译。
  - 两个交叉注意力模块分别建模：
    - 跨具身对应关系：\(f_{emb}=\mathrm{Attn}(Q=z^t_k,K=z^s_k,V=z^s_k)\)。
    - 演示运动演化：\(f_{mot}=\mathrm{Attn}(Q=z^s_{k+n},K=z^s_k,V=z^s_k)\)。
  - 将 \(z^t_k\)、\(f_{emb}\)、\(f_{mot}\) 拼接后经 3D 卷积融合，再由 Transformer 解码为潜在目标 \(\hat z^t_{goal}\)。
- **三阶段训练**：
  - **Stage 0**：预训练目标具身的动作条件世界模型。
  - **Stage 1**：训练 Dreamer Predictor，损失为潜在重构损失  
    \[
    L_{pred}=\|\hat z^t_{goal}-z^t_{k+n}\|_2^2
    \]
    并引入时间扰动 \(\delta\sim U(-r,r)\)，增强对执行误差和规划偏移的鲁棒性。
  - **Stage 2**：冻结 Dreamer Predictor，解冻世界模型动力学部分，用规划损失  
    \[
    L_{plan}=\|F_{wm}(z^t_k,s^t_k,a^t_{k:k+n-1})-\hat z^t_{goal}\|_2^2
    \]
    使世界模型 rollout 适配 Dreamer Predictor 输出的目标分布。
- **推理与自适应目标更新**：
  - 用 CEM 在世界模型中优化动作，使预测潜在状态逼近 \(\hat z^t_{goal}\)。
  - 执行后计算新观测潜在状态与目标的距离 \(D_k=d(z^t_{k+1},\hat z^t_{goal})\)。
  - 仅当 \(D_k<\epsilon\) 时推进到下一个源演示参考帧；否则保持当前目标并继续规划，避免因跨具身运动学差异导致过早推进和误差累积。
- **关键特点**：不需要动作级对应、共享动作空间或人工重定向规则；训练使用源视觉演示与目标自身交互数据。

### 3. 实验设计

  - 使用 **RLBench**。
  - 源具身为 Sawyer 机械臂，目标具身为 Franka 机械臂。
  - 通过源演示视频提示目标策略执行任务。
- **真实世界环境**：
  - 源具身为 UR5e，目标具身为真实 Franka 机械臂。

- **评测基准与三档分布偏移**：

  - **Cross-Embodiment Bridging**：未见动作/技能条件下的跨具身桥接。

  - 指标为任务成功率；仿真每个场景 30 次 rollout，真实世界每个场景 20 次 rollout。
- **对比方法**：
  - 主要基线：**VPP**（视频预测策略）和 **XSkill**（跨具身技能发现）。

### 6. 主要结论与发现

- 在分布偏移较小时，VPP 在 Behavior Grounding 上表现更好，说明其域内轨迹学习有优势。
- 随着分布偏移增大，Demo-JEPA 优势明显：
  - 仿真 Cross-Embodiment Bridging 平均成功率 **0.45**，高于 VPP 的 0.28 和 XSkill 的 0.17。
  - 仿真 Zero-Shot Generalization 平均成功率 **0.36**，远高于 VPP 的 0.04 和 XSkill 的 0.03。
  - 真实世界 Cross-Embodiment Bridging 平均 **0.55**，略高于 VPP 的 0.53、明显高于 XSkill 的 0.40。
  - 真实世界 Zero-Shot Generalization 平均 **0.25**，高于 VPP 的 0.00 和 XSkill 的 0.05。
- V-JEPA 2.1 Naive 直接使用源演示未来潜在状态作为目标时全部失败，说明原始 JEPA 潜在空间并不天然跨具身兼容；Dreamer Predictor 的目标翻译是必要的。
- Demo-JEPA 在仅使用源演示和当前目标观测的情况下，接近使用目标真实未来轨迹的 Oracle 规划器。
- Conv3D 融合对复杂、结构化运动任务更重要；简单任务中均值池化也可用。
- Demo-DP 表明预测潜在目标可作为 Diffusion Policy 的有效条件信号，在 Behavior Grounding 上表现强；但零样本泛化下，基于规划的 Demo-JEPA 更稳健。
- 缩放实验表明，**任务多样性比单任务轨迹数量更重要**：增加任务语义多样性对跨具身迁移更关键。

### 7. 优点

- **问题重构有新意**：从“复现动作”转向“推断未来目标”，直接绕开动作级对应和共享动作空间难题。
- **JEPA 潜在空间选择合理**：相比像素重建，潜在预测空间更可能抑制背景、光照、硬件外观等任务无关细节，保留预测性世界结构。
- **Dreamer Predictor 设计针对性强**：分别用交叉注意力建模跨具身对应和演示运动，再用 Conv3D 保留时空结构。
- **训练流程清晰**：世界模型预训练、目标预测器训练、动作协同训练三阶段分工明确；Stage 2 使世界模型适配目标分布。
- **自适应目标更新机制实用**：通过潜在距离阈值控制源演示推进，缓解跨具身速度/运动学差异造成的误差累积。
- **实验覆盖较全面**：仿真与真实世界、主实验、Oracle 对照、消融、Demo-DP 扩展和缩放研究均有涉及。
- **真实世界验证有价值**：在 UR5e→Franka 的真实跨具身设置下验证，增强了方法的实践意义。

### 8. 不足与局限

- **世界模型保真度瓶颈**：作者承认当前动作条件世界模型的建模能力限制复杂、高精度任务表现。
- **并非完全“无对齐”**：训练阶段仍需要时间对齐或进度感知对齐；仿真使用重定向回放生成配对，真实世界使用 GTCC 做帧级对应，尚未实现完全无对齐学习。
- **“单样本”表述需谨慎**：推理时使用一个源演示提示，但训练仍依赖大量配对视觉轨迹和目标具身交互数据，并非从单个演示直接学习。
- **具身多样性有限**：仅验证 Sawyer→Franka 仿真和 UR5e→Franka 真实两种源-目标组合，未覆盖人→机器人、多机器人形态、不同自由度等更广泛异构场景。
- **真实世界样本量偏小**：每场景 20 次 rollout，且缺少误差棒和显著性检验；Cross-Embodiment Bridging 中相对 VPP 的优势较小。
- **Behavior Grounding 不占优**：在已见任务上低于 VPP，说明方法优势主要体现在分布偏移场景，而非所有设定下全面领先。
- **基线覆盖有限**：未与更多大规模 VLA、跨具身动作对齐、技能重定向方法比较；VPP/XSkill 的调优公平性难以完全判断。
- **规划计算开销**：CEM 在线优化带来额外计算成本，论文未报告推理时延和实时性。
- **应用限制**：仅在受控仿真和实验室环境验证，真实安全关键部署仍需额外验证与保护机制。
