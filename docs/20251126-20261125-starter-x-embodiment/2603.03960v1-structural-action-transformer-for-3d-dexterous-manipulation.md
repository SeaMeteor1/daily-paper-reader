## 摘要
通过从异构数据集中进行模仿学习来使机器人达到类人灵巧性，受到跨具身技能迁移挑战的阻碍，尤其是对于高自由度机械手而言。现有方法通常依赖二维观测和以时间为中心的动作表示，难以捕捉三维空间关系，也无法处理具身异构性。本文提出结构化动作Transformer（SAT），一种新的三维灵巧操作策略，通过引入以结构为中心的视角来挑战这一范式。我们将每个动作块重新表述为可变长度、无序的逐关节轨迹序列，而非时间序列。这种结构化表述使Transformer能够原生处理异构具身，将关节数量视为可变序列长度。为了编码结构先验并消除歧义，我们引入具身关节码本（Embodied Joint Codebook），用于嵌入每个关节的功能角色和运动学属性。我们的模型通过连续时间流匹配目标，学习从三维点云生成这些轨迹。我们通过在大规模异构数据集上预训练，并在仿真和真实世界灵巧操作任务上微调来验证该方法。我们的方法始终优于所有基线，展现出更优的样本效率和有效的跨具身技能迁移。这种以结构为中心的表示为扩展高自由度、异构操作器的策略提供了一条新路径。

## Abstract
Achieving human-level dexterity in robots via imitation learning from heterogeneous datasets is hindered by the challenge of cross-embodiment skill transfer, particularly for high-DoF robotic hands. Existing methods, often relying on 2D observations and temporal-centric action representation, struggle to capture 3D spatial relations and fail to handle embodiment heterogeneity. This paper proposes the Structural Action Transformer (SAT), a new 3D dexterous manipulation policy that challenges this paradigm by introducing a structural-centric perspective. We reframe each action chunk not as a temporal sequence, but as a variable-length, unordered sequence of joint-wise trajectories. This structural formulation allows a Transformer to natively handle heterogeneous embodiments, treating the joint count as a variable sequence length. To encode structural priors and resolve ambiguity, we introduce an Embodied Joint Codebook that embeds each joint's functional role and kinematic properties. Our model learns to generate these trajectories from 3D point clouds via a continuous-time flow matching objective. We validate our approach by pre-training on large-scale heterogeneous datasets and fine-tuning on simulation and real-world dexterous manipulation tasks. Our method consistently outperforms all baselines, demonstrating superior sample efficiency and effective cross-embodiment skill transfer. This structural-centric representation offers a new path toward scaling policies for high-DoF, heterogeneous manipulators.

## 二、方法论

- **核心思想：结构中心动作表示**
  - 传统动作块：\(A_t \in \mathbb{R}^{T \times D_a}\)，每个 token 是某一时刻的 \(D_a\) 维动作。
  - 本文动作块：\(A_t \in \mathbb{R}^{D_a \times T}\)，每一行表示某个关节在未来 \(T\) 步的完整轨迹。
  - 该表示是**变长、无序的关节轨迹序列**：不同机械手的 \(D_a\) 可变，Transformer 可直接处理；时间成为每个 token 的特征维度，有利于学习压缩的运动基元。
  - 控制时采用滚动时域方式：预测动作块，执行其中一部分，再根据新观测重新查询策略。

- **策略建模：条件连续时间归一化流 / 流匹配**
  - 学习条件速度场 \(v(A_t^\tau, \tau, o_t)\)，将高斯噪声传输到真实动作分布。
  - 训练目标为流匹配损失：
    \[
    L(\theta)=\mathbb{E}_{\tau\sim U(0,1), A_t^0\sim N(0,I), A_t^1\sim D}
    \left[\left\|\epsilon_\theta(A_t^\tau,\tau,o_t)-(A_t^1-A_t^0)\right\|^2\right]
    \]
    其中 \(A_t^\tau=(1-\tau)A_t^0+\tau A_t^1\)。
  - 推理时从噪声出发，用 ODE 求解器积分速度场得到动作块；论文提到单步 Euler 可实现 1-NFE，但实现细节中使用固定 10 步 Euler 积分。

- **观测 tokenizer**
  - 输入为最近 \(T_o\) 帧原始 3D 点云和自然语言指令。
  - 对每帧点云：
    - 用 FPS 选 \(M\) 个局部中心，每个中心取 \(K\) 近邻形成局部组；
    - 共享 PointNet 提取局部几何特征，中心坐标经 MLP 生成位置嵌入，相加得到局部 token；
    - 训练时对局部 token 随机打乱作为数据增强；
    - 另用 PointNet 编码整帧点云，得到单个全局场景 token。
  - 将历史各帧的全局 token 与局部 token 拼接，再与 T5 编码的语言 token 拼接，形成条件观测序列。

- **结构动作 tokenizer**
  - 对 \(D_a\) 个关节轨迹分别用共享 MLP 从 \(T\) 维压缩到 \(d_{\text{feat}}\) 维，得到动作 token 序列。
  - 引入**具身关节码本（Embodied Joint Codebook）**，每个关节由三元组定义：
    - \(e\)：具身 ID，如 ShadowHand、XHand；
    - \(f\)：功能类别，如 CMC、MCP、PIP、DIP；
    - \(r\)：旋转轴，如屈伸、外展/内收、旋前/旋后。
  - 三个分量分别索引可学习嵌入表，求和得到关节码本嵌入 \(C_j\)，加到压缩后的动作 token 上。该设计使不同机械手中功能与旋转轴相同的关节获得相似先验，促进迁移，并解决无序关节序列的对应歧义。

- **Structural Action Transformer**
  - 将动作 token 与观测 token 拼接后输入 DiT。
  - 修改自注意力掩码为因果掩码：观测 token 只关注观测 token；动作 token 可关注所有观测 token 和其他动作 token。
  - 动作对应输出经 MLP 预测速度场，用于流匹配积分生成动作块。

## 六、主要结论与发现

- **结构中心表示有效**：SAT 在 11 个仿真任务上平均成功率 **0.71**，优于 3D ManiFlow 0.66、3DDP 0.63、UniAct 0.50、HPT 0.47、Diffusion Policy 0.42。
- **参数高效**：SAT 仅 19.36M 参数（不含 T5），显著小于 2D 基线和其他 3D 基线，却取得更高成功率。
- **真实世界有效**：6 个真实双臂任务中 SAT 全部优于 HPT 和 3DDP，例如取笔帽 0.30 vs 0.25/0.10，递 Baymax 0.85 vs 0.75/0.50，推后抓盒 0.35 vs 0.15/0.05，抓篮球 0.95 vs 0.80/0.65。
- **时间压缩鲁棒**：token 维度从 64 降至 32 性能基本不变，降至 16 才略降，说明关节轨迹存在较大冗余。
- **预训练数据组成**：全混合最佳；仅人类数据预训练优于仅机器人数据，说明码本可将人类功能运动迁移到机器人；仅仿真数据优于仅人类或仅机器人，因为与下游任务模态和动力学更接近。
- **组件必要性**：去掉关节嵌入导致灾难性失败（0.01），说明无序动作序列必须依赖码本消歧；改为时间中心表示降至 0.64，验证结构中心表示优势。
- **码本功能类别最关键**：去掉功能类别后成功率仅 0.02，去掉具身 ID 为 0.57，去掉旋转轴为 0.62；说明功能对应是跨具身桥接的核心。
- **少样本适应更优**：相比 UniAct，SAT 在低数据 regime 下学习更快、最终成功率更高。
- **码本嵌入空间**：t-SNE 显示按具身和旋转轴聚类明显，功能类别聚类较弱；作者解释为模型学习关节特异嵌入以消歧，泛化来自组合式结构而非简单嵌入相似。

## 七、优点

- **表示层面的创新明确**：将动作块从 \((T,D_a)\) 转为 \((D_a,T)\)，把具身差异转化为序列长度差异，思路简洁且与 Transformer 的变长序列能力天然契合。
- **码本设计具有可解释性**：用具身 ID、功能类别、旋转轴三元组编码关节先验，既解决无序序列对应问题，又为跨具身迁移提供结构化归纳偏置。
- **多模态 3D 策略完整**：点云局部/全局层次 tokenizer、语言条件、DiT、流匹配和滚动控制形成较完整系统。
- **模型参数效率高**：19.36M 参数取得优于大模型基线的结果，显示结构先验可降低对参数规模的依赖。
- **实验较系统**：主实验、真实实验、表示消融、码本消融、数据组成消融和少样本曲线相互支撑，核心假设有直接验证。
- **真实任务有挑战性**：包含双臂协调、长时程多阶段和接触丰富任务，且给出定性 rollout，增强说服力。
- **失败分析坦诚**：明确指出单相机遮挡、运动学/接触几何不匹配等限制，为后续引入触觉或力约束提供方向。

## 八、不足与局限

- **真实世界覆盖有限**：仅 6 个任务、单一双臂 xArm+xHand 平台、单个固定 L515 相机；未验证更多机械手、更多场景和更大规模真实数据。
- **遮挡与感知限制**：复杂接触丰富双臂任务中，一只手可能严重遮挡另一只手或目标物体；单固定相机无法消歧，策略缺乏关键几何信息。
- **缺乏力/触觉闭环**：运动学或接触几何不匹配会导致动作分配错误，论文指出需要显式动力学/力约束或触觉闭环校正，但当前未实现。
- **预训练与基线适配不完全对等**：真实实验中 SAT 使用预训练模型，3DDP 从零训练；不同方法的预训练数据、stem/head 适配策略不同，可能影响公平性解释。
- **算力与复现信息不足**：未披露 GPU 型号/数量/训练时长、预训练总规模，难以评估训练成本与可复现性。
- **真实实验统计信息不足**：真实结果表未给出标准差、试验次数或多次运行方差，成功率估计的稳定性不明确。
- **仅验证模仿学习**：结论主要限于离线模仿学习与流匹配策略；作者也提出未来才探索将其用于强化学习。
- **码本依赖人工定义**：功能类别和旋转轴分类参考人类手部解剖与 10 种灵巧手调研，面对新形态机械手时可能需要人工扩展或映射，自动化程度有限。
- **潜在偏差风险**：预训练数据中人类、机器人、仿真数据比例与筛选策略可能影响结论；仅仿真数据预训练表现很强，说明下游仿真任务与预训练仿真域接近，真实跨域泛化仍需更多验证。
