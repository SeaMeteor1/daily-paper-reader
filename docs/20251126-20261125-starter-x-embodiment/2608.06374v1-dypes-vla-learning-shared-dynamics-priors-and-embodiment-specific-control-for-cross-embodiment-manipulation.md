## 摘要
视觉-语言-动作（VLA）模型已成为机器人操作的一种强大范式，但为异构机器人具身训练单一通用策略仍是一个尚待解决的问题。现有方法主要有两个局限。首先，它们未能充分利用跨多样视觉与交互数据共享的动力学先验，限制了跨具身迁移。其次，它们需要大量人工预处理，以将具身特定动作转换为统一格式。为克服这些局限，我们提出 DyPES-VLA，一种学习共享动力学先验与具身特定控制的跨具身 VLA。首先，我们通过在跨具身数据上以未来预测目标训练视觉-语言模型（VLM）来学习共享动力学先验，促使共享查询表示捕捉物体运动、接触以及交互引起的场景变化。其次，具身特定的混合专家（MoE）动作头将这些共享动力学先验直接转换为各具身原生动作空间中的可执行控制，而无需人工将异构动作预对齐为统一格式。该动作头共享注意力层以捕捉常见的时间动作结构，而其具身特定的前馈专家则解决不同具身独有的运动学约束与控制语义。作为一种通用策略，我们的方法在仿真和真实世界评估中取得最先进性能，在 LIBERO 上达到 98.0% 成功率，在 RoboCasa-GR1 上达到 59.25%，在 RoboTwin 2.0 上达到 89.02%。

## Abstract
Vision-Language-Action (VLA) models have become a powerful paradigm for robot manipulation, but training a single generalist policy for heterogeneous robot embodiments remains an open problem. Existing methods have two main limitations. First, they underuse dynamics priors shared across diverse visual and interaction data, limiting cross-embodiment transfer. Second, they require extensive manual preprocessing to convert embodiment-specific actions into a common format. To overcome these limitations, we propose DyPES-VLA, a cross-embodiment VLA that learns shared Dynamics Priors and Embodiment-Specific control. First, we learn shared dynamics priors by training the vision-language model (VLM) with a future-prediction objective on cross-embodiment data, driving the shared query representation to capture object motion, contact, and interaction-induced scene changes. Second, an embodiment-specific Mixture-of-Experts (MoE) action head translates these shared dynamics priors into executable controls directly in each embodiment's native action space, without manually pre-aligning heterogeneous actions into a common format. This head shares attention layers to capture common temporal action structures, while its embodiment-specific feed-forward experts resolve the unique kinematic constraints and control semantics of distinct embodiments. As a generalist policy, our \ourmethod achieves state-of-the-art performance across simulation and real-world evaluations, reaching 98.0% success on LIBERO, 59.25% on RoboCasa-GR1, and 89.02% on RoboTwin~2.0.

- **背景**：视觉-语言-动作（VLA）模型在机器人操作上表现强劲，但多数策略仍绑定单一机器人；用异构跨具身数据训练**单一通用策略**是开放难题。核心问题是：**哪些知识应跨具身共享，哪些必须保持具身特定**。

  - **动力学先验利用不足**：多数方法仅以动作预测为监督信号，浪费了大量人类/机器人操作视频中反复出现的物体运动、接触与场景演化规律。

- **整体含义**：论文提出一种新的跨具身学习范式——**共享动力学先验（shared dynamics priors）+ 具身特定控制（embodiment-specific control）**，并实例化为 DyPES-VLA，主张把"共享接口"上移到未来预测监督下的 query states，再由具身特定专家解码到各自**原生动作空间**，原则上可接纳任意具身数据联合训练而无需额外动作空间对齐。

## 2. 方法论

### 2.1 核心思想
用一条"共享查询接口"解耦两件事：未来预测负责学**跨具身共享的动力学先验**，MoE 动作头负责**具身特定的动作实现**。与把未来预测与动作生成耦合的世界-动作模型（WAM）不同，本文的未来预测**只用于塑造表示**，推理时被丢弃。

### 2.2 三个组件
- **共享查询接口**：预训练 VLM（Qwen3-VL-2B）接收视觉观测、语言指令、**文本化的具身元数据**（data_source、robot_type、robot_model、camera_views、control_freq、action_dim、action_horizon、action_space 等）以及 N=96 个可学习 query token，一次前向得到 query states $Z$。策略**不使用本体感知状态**。
- **未来生成头**：SANA-600M 图像生成器，仅以投影后的 query states 为条件（**不接收当前观测或其潜变量**），迫使合成未来帧所需信息必须经过这 N 个 query token。
- **具身特定 MoE 动作头**：16 层 flow-matching DiT，从零训练，K=3 个专家。

### 2.3 关键公式与流程（文字说明）
- **Query 状态**：$Z=f_\theta([\phi_v(o_t),\phi_\ell(\ell),\phi_\ell(m_e),Q])$，取 query token 的末层隐状态。
- **未来预测损失**：冻结自编码器把未来帧 $x_{t+\Delta_e}$ 编码为潜变量 $z$，加噪得 $z_\tau=\tau z+(1-\tau)\epsilon$，用 rectified flow 回归直线速度：$\mathcal{L}_{future}=\mathbb{E}\|g_\psi(z_\tau,\tau,p_\omega(Z))-(z-\epsilon)\|_2^2$。时间偏移 $\Delta_e$ 按具身设定以匹配其动作时域 $H_e$。
- **动作头结构**：元数据确定性映射到路由索引 $r(e)$；每个具身有轻量 encoder/decoder 适配原生动作空间与 DiT 宽度；每个 block 内**注意力层全具身共享**（对 $Z$ 交叉注意力 + 动作序列自注意力，均用 AdaLN 以 flow 时间步调制），**FFN 为 K 专家库按路由选择**：$\bar X=X+\mathrm{Attn}(\mathrm{AdaLN}(X,\tau);Z)$，$X'=\bar X+\mathrm{FFN}^{(r(e))}(\mathrm{AdaLN}(\bar X,\tau))$。
- **动作损失**：时间步采 Beta 调度 $\tau=s(1-u)$（$u\sim\mathrm{Beta}(1.5,1.0)$，$s=0.999$，偏向高噪声端），$\hat V=\mathrm{Dec}_{r(e)}(\mathrm{MoEDiT}(\mathrm{Enc}_{r(e)}(A^e_\tau,\tau),Z,\tau,r(e)))$，损失 $\mathcal{L}_{action}=\mathbb{E}\|\hat V-(A^e-\epsilon)\|_2^2$，**在各自原生动作空间内回归**。
- **两阶段训练**：
  - Stage 1：在**无动作标签**视频（EgoDex 人类自我中心操作视频 + 三个仿真基准视频）上预训练 VLM、query token 与 SANA 头，只优化 $\mathcal{L}_{future}$。
  - Stage 2：在带动作标签的多具身示教上联合优化 $\mathcal{L}=\mathcal{L}_{action}+\lambda_w\mathcal{L}_{future}$（$\lambda_w=0.05$），未来预测起正则作用。
  - **推理**：一次 VLM 前向得 $Z$，动作头用 4 步 Euler 积分输出原生动作块，未来生成头跳过。

### 2.4 具身覆盖
实例化三个具身家族，每个含仿真与真机：单臂（Franka Emika Panda / Franka Research 3）、双臂（ALOHA-AgileX / AgileX COBOT Magic）、人形（Fourier GR-1 / Unitree G1 + Inspire RH56DFQ 手）。

### 3.3 消融与探针
- 四个消融变体：去未来预测、去 Stage-1 预训练、共享稠密头替代 MoE、去具身元数据，均单 checkpoint 在三基准评测。
- **未来接触线性探针**：在冻结 $Z$ 上训练单层线性探针，预测 LIBERO 接触起始（onset）/释放（release）事件，报告 AUROC、AUPRC 与类加权 BCE；设计上通过固定当前接触状态子集，排除"回声当前状态"的平凡解。

## 4. 资源与算力

- 文中明确给出：Stage 1 训练 **100,000 步**，Stage 2 训练 **200,000 步**，有效 batch size **512**，使用 **16 张 H100 GPU**，优化器 AdamW；真实世界联合微调额外 **5,000 步**。
- **未明确说明**：总 GPU 小时/墙钟训练时长、单次消融实验的算力开销、推理延迟与吞吐、模型总参数量与显存占用。文中也未给出各消融变体的训练成本对比。

## 5. 实验数量与充分性

- **规模概览**：
  - 3 个仿真基准（含 50 + 24 + 4 个任务套件/任务组）+ 3 个真机平台 × 3 任务 × 25 rollouts（共 225 次真机评测）。
  - 4 组核心消融（覆盖 Q2/Q3/Q4 三个研究问题）+ 1 组表示层线性探针（2 个事件 × 3 指标）。
  - 附录提供 RoboCasa-GR1 全部 24 任务、RoboTwin 2.0 全部 50 任务在两种设置下的逐任务成功率，以及额外真机定性 rollout。
- **充分性评价**：
  - **较充分**：三基准覆盖单臂/双臂/人形三类形态与不同自由度（7/14/29-DoF）和不同动作时域，是较有说服力的异构性覆盖；逐任务明细公开，便于复核；行为消融与表示探针互补，避免仅凭成功率下结论。
  - **公平性考量**：作者显式按"per-benchmark specialist vs. single-checkpoint generalist"分组，避免用单 checkpoint 直接对比按基准微调的方法，这一点较规范；但 LIBERO 上"仅落后最佳微调 X-VLA 0.1 分"的表述仍属跨组比较，需谨慎解读。真机上 ACT 是 9 个专用 checkpoint、GR00T-N1.6 与本文均为单 checkpoint 联合微调，比较相对公平。
  - **不足**：所有结果均为单次训练/单组随机种子报告，**无方差、置信区间或多种子重复**；真机每任务仅 25 rollouts，统计功效有限；消融只做"删除式"，未做 query token 数、专家数 K、$\lambda_w$、Euler 步数等超参敏感性分析；未报告失败模式分类统计。

## 6. 主要结论与发现

- **单 checkpoint 跨具身可行且达 SOTA**：LIBERO 98.0%（Spatial 98.8 / Object 99.4 / Goal 97.0 / Long 96.8）、RoboCasa-GR1 59.25%、RoboTwin 2.0 89.02%（Clean 88.78 / Randomized 89.26）。
- **相对强基线**：RoboTwin 2.0 平均超 Qwen-VLA 2.37 分；RoboCasa-GR1 超最强专用方法 ABot-M0（58.3%）0.95 分、超 WAM 基线 LDA-1B（55.4%）3.85 分、超 Qwen-VLA（56.7%）2.55 分；LIBERO 超 Fast-WAM（97.6%）0.4 分、OpenVLA-OFT（97.1%）0.9 分，落后最佳微调 X-VLA 0.1 分。
- **真机跨形态迁移有效**：单一联合微调 checkpoint 平均 75.6%，超联合微调 GR00T-N1.6（59.6%）16.0 分、超 ACT 的 9 个专用策略均值（32.4%）43.2 分；形态越难（人形）绝对成功率越低但相对优势仍存。
- **消融结论**：未来预测贡献最大（RoboTwin −2.4、RoboCasa −2.5 分）；仅去掉 Stage-1 预训练也全面下降；MoE 头替换为共享稠密头损失 1.2 / 2.1 分；去掉具身元数据损失最多 0.5 分（小而一致）。
- **表示层证据**：未来预测使接触 onset AUROC 95.2→97.3、AUPRC 70.8→86.3，release AUROC 92.3→94.4、AUPRC 64.8→72.8，加权 BCE 0.227→0.142，说明共享 query 表示确实编码了前瞻性的接触动力学，而非仅当前视觉特征。
- **RoboCasa-GR1 分族表现**：6 个"放入铰接容器"类任务 55.3%，18 个"容器到容器"类任务 60.6%，两类较均衡。

## 7. 优点

- **问题拆解清晰**：明确区分"共享交互规律"与"具身控制语义"，并用架构（共享注意力 + 路由 FFN 专家）而非人工动作对齐来实现这一分离，从原理上避免了 IK/坐标变换的预处理负担与跨形态扩展瓶颈。
- **共享接口位置上移**：把共享接口放在未来监督的 query states 上，而非动作空间或提示层，使无动作标签视频（EgoDex 等）可直接参与联合训练，数据利用率高。
- **训练/推理非对称设计合理**：未来生成头只在训练期作为表示正则，推理丢弃，避免 WAM 类方法的测试时生成开销；推理仅需一次 VLM 前向 + 4 步 Euler 积分。
- **MoE 设计克制且有依据**：只让 FFN 具身特定、注意力共享，符合"时序动作结构共通、运动学约束各异"的直觉；静态路由由元数据确定性决定，避免路由器塌缩与训练不稳定。
- **元数据文本化**：用自然语言描述数据源、机器人型号、控制频率、动作维度/空间，复用 VLM 的语言理解能力，实现轻量条件化。
- **评测设计较规范**：按 checkpoint 范围分组对比；逐任务明细进附录；行为消融与线性探针双证据链；探针任务刻意排除平凡解；真机上采用单 checkpoint 对单 checkpoint 的公平设定。
- **异构性覆盖广**：三形态 × 仿真/真机配对（Panda↔FR3、ALOHA-AgileX↔COBOT Magic、GR-1↔G1），并说明真机复用了对应仿真具身的专家，为"仿真预训练→真机微调"路径提供了实证。

## 8. 不足与局限

- **具身数量与扩展性**：仅实例化 K=3 个专家、3 个具身家族，未验证 K 增大（数十种机器人）时的路由、专家容量与参数效率；静态路由需为每个新具身新增 encoder/decoder/FFN 专家，**并非真正的零样本新具身泛化**。
- **本体感知缺失**：策略完全不输入 proprioception，对需要精确关节状态反馈的任务（高精度装配、接触力控制、双臂闭链协调）可能构成上限；论文未讨论该设计选择的代价。
- **动作空间对齐的"免除"是有条件的**：动作仍需**逐维 min-max 归一化**，且每个具身需各自的 encoder/decoder 与路由索引，本质上仍需少量具身特定工程，只是不再需要统一动作格式。
- **真机实验规模有限**：仅 3 个较简单的桌面拾放/倒水任务，每任务 25 rollouts，任务同构性强、物体与场景多样性低；人形 G1 绝对成功率偏低（平均 36–72%），失败案例未做分析。
- **统计严谨性不足**：所有结果单次运行、无种子方差或置信区间，消融间 0.5–2.5 分的差距在无方差报告的情况下难以判断显著性（尤其"去元数据"仅 0.3–0.5 分）。
- **超参与设计敏感性缺失**：未分析 query token 数 N、专家数 K、$\lambda_w$、未来时间偏移 $\Delta_e$、Euler 步数、Beta 调度等的影响；也未与"动作头也用未来预测耦合"的 WAM 变体做直接对照以支撑"解耦更优"的论断。
- **潜在数据重叠隐忧**：Stage 1 与 Stage 2 均使用三个评测基准自身的视频/示教数据（含 LIBERO 视频进入无动作预训练），虽然这是常规做法，但未讨论预训练视频与评测任务分布重合对结果的可能贡献；也未在完全 held-out 的第四基准上验证。
- **基线覆盖有缺口**：未与 X-VLA、π0.5、UniVLA、HIMOE-VLA 等跨具身方法在**同等单 checkpoint 设置**下直接比较；部分对比数值引自原论文的不同评测协议（rollout 数、随机化程度未必一致）。
- **效率与部署信息缺失**：未报告参数量、推理频率、显存、训练总时长，也未讨论 4 步 Euler 积分在双臂 50 步动作时域下的实时性；无边缘部署可行性分析。
- **元数据依赖风险**：推理时需正确提供具身元数据文本，元数据错误或缺失（消融显示 −0.5 分）在真实部署中的鲁棒性未评估。
