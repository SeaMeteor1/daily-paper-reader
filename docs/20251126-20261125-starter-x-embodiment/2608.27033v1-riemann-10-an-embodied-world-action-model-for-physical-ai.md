## 摘要
我们提出 Riemann-1.0，一个面向具身智能的全因果自回归世界动作模型。Riemann-1.0 在统一的因果自回归序列中联合建模多视角视觉观测、机器人状态以及特定具身本体的动作，将机器人动作与世界演化表示为因果状态转移。与基于联合生成、视频优先预测或解耦建模范式的现有 WAM 不同，Riemann-1.0 在单一模型中统一了在线机器人策略执行与动作条件世界模拟，使其既能作为可执行的机器人策略，也能作为多具身本体的视觉世界模拟器。为了跨异构数据源扩展具身经验，我们进一步开发了一个渐进式具身预训练框架，在共享的世界动作建模目标下，统一从第一人称人类视频、手持夹爪演示和异构机器人轨迹中学习。基于超过 20 万小时的交互数据，Riemann-1.0 将大规模具身经验逐步迁移为可执行的机器人操作能力。Riemann-1.0 在仿真基准和真实世界操作任务上均取得了最先进的性能。它在 RoboTwin2.0 上达到 94.3% 的成功率，在 LIBERO 上达到 99.0%，在长时程组合基准 RoboCasa-365 上达到 62.6%，相比此前最佳方法提升 8.4%。在长时程真实世界操作任务中，Riemann-1.0 的成功率（SR）为 85.0%，进度成功率（PSR）为 94.4%，在 SR 上超过最强的开源基线 15%。这些结果表明，统一的世界动作建模与渐进式具身预训练相结合，能够有效地将大规模具身经验转化为可泛化的机器人操作能力。

## Abstract
We introduce Riemann-1.0, a fully causal autoregressive World Action Model for embodied intelligence. Riemann-1.0 jointly models multi-view visual observations, robot states, and embodiment-specific actions within a unified causal autoregressive sequence, representing robot actions and world evolution as causal state transitions. Unlike existing WAMs based on joint generation, video-first prediction, or decoupled modeling paradigms, Riemann-1.0 unifies online robot policy execution and action-conditioned world simulation within a single model, enabling it to function as both an executable robot policy and a multi-embodiment visual world simulator. To scale embodied experience across heterogeneous data sources, we further develop a progressive embodied pretraining framework that unifies learning from egocentric human videos, handheld-gripper demonstrations, and heterogeneous robot trajectories under a shared World Action Modeling objective. Built upon 200K+ hours of interaction data, Riemann-1.0 progressively transfers large-scale embodied experience into executable robot manipulation capabilities. Riemann-1.0 achieves state-of-the-art performance across both simulation benchmarks and real-world manipulation tasks. It achieves success rates of 94.3% on RoboTwin2.0, 99.0% on LIBERO, and 62.6% on the long-horizon compositional benchmark RoboCasa-365, outperforming the previous best method by 8.4% On long-horizon real-world manipulation tasks, Riemann-1.0 achieves a Success Rate (SR) of 85.0% and a Progress Success Rate (PSR) of 94.4%, exceeding the strongest open-source baseline by 15% in SR. These results demonstrate that unified World Action Modeling together with progressive embodied pretraining effectively transforms large-scale embodied experience into generalizable robot manipulation capabilities.

## 2. 方法论

### 2.1 核心思想：全因果动作-视频自回归分解
- 将交互过程写成统一因果序列，按“**先动作、后视觉后果**”排序（与真实机器人执行顺序一致）：

  $$p(a_{1:T}, z_{1:T}\mid z_0,s_0,c)=\prod_{t=1}^{T}p(a_t\mid z_{<t},s_{<t},a_{<t},c)\,p(z_t\mid z_{<t},s_{<t},a_{\le t},c)$$

- **动作块既是策略输出，也是视觉动力学模型的条件输入**——这是模型能充当“世界模拟器”的关键接口。
- 机器人状态 $s_t$ **不由模型生成**，而是从环境观测或回放轨迹注入，作为下一步条件。
- 双模式复用同一公式：
  - **策略部署**：预测动作 → 执行 → 用环境返回的真实观测替换预测 latent，作为下一步上下文（闭环）。
  - **世界模拟**：把预测 latent 递归回灌，生成动作条件下的未来观测（开环 rollout）。

### 2.2 架构与关键实现细节
- **视觉侧**：多视角观测按具身本体拼成统一画布 → 调整分辨率 → Wan VAE 编码为 latent → 3D patch embedding 转成 token；$z_0$ 为初始上下文，$z_{1:T}$ 自回归生成。
- **语言条件**：模板化 prompt（`Video recorded from embodiment {embodiment_type}, showing the {num_views} camera views, while performing the task: {task}`），T5 编码后经 cross-attention 注入。
- **具身接口**：数值 embodiment ID 映射到紧凑类别槽，索引**类别专属的 state/action 线性投影与动作预测头**；动作/状态先转为该具身的规范顺序、按具身统计量归一化，再 padding 到固定维度 $D_a, D_s$，并用有效性掩码处理变维动作（不强行共享物理动作空间）。→ 共享主干 + 保留各本体数值动作空间。
- **位置编码**：CaPE（坐标感知位置编码）+ TimePE + AdaLN 调制；token 标注为 visual `(frame,h,w)`、state `(F+1,1,1)`、action `(F, apf, 1)`，context/state 时间步为 0。
- **训练目标**：对两个头均用 flow matching（$x_\sigma=(1-\sigma)x+\sigma\epsilon$，目标速度 $v^\star=\epsilon-x$）：
  - $\mathcal{L}_z=\mathbb{E}\|v^z_\theta(z_\sigma,\sigma,z_{<t},s_{<t},a_{\le t},c)-(\epsilon_z-z)\|_2^2$
  - $\mathcal{L}_a=\mathbb{E}\|v^a_\theta(a_\sigma,\sigma,z_{<t},s_{<t},a_{<t},c)-(\epsilon_a-a)\|_2^2$
  - 总损失 $\mathcal{L}=(1-\lambda)\mathcal{L}_z+\lambda\mathcal{L}_a$，$\lambda$ 为动作权重（课程式递增）。
- **Teacher-forcing 注意力掩码**：由 frame ID、time ID、clean/noisy 标志三属性构造；clean token 只看当前/历史 clean token，noisy token 看历史 clean + 同帧 noisy，**不看未来 clean token**（防泄漏），块内可双向注意力；padding（含文本 padding）被掩掉。
- **损失掩码与噪声注入一致**：latent 掩码排除 padding 帧与 episode 边界无效 latent；action 掩码排除 padding 通道/帧/无效低层步，损失只在有效通道-步上归一化；padding 区域在 clean 样本、噪声、noisy 样本、速度目标中均保持为 0，避免“训练有噪声、部署为 0”的 train-test mismatch。
- **在线自回归推理**：初始化 KV cache（$z_0$、$s_0$、文本）→ 每步采样高斯噪声动作张量并按 flow scheduler 去噪（读 cache）→ 动作块入 cache 并执行 $a_{pf}$ 个低层控制步 → 环境返回新观测与末状态 → 编码为 $z_t$ 连同 $s_t$ 入 cache；长时程 rollout 时 cache 维护固定窗口，满则重置并以最近观测为新 context 帧。

### 2.3 统一数据基础设施（6 阶段数据引擎）
- **语料规模**：230K+ 小时（摘要处写 200K+），其中第一人称人类视频 200K+ h、手持夹爪/可穿戴演示 12K+ h、异构机器人轨迹 20K+ h；图 1 标注比例约 86% / 5% / 9%，覆盖家庭、办公、工业场景与数千种交互技能。
- **三类数据的互补监督**：人类视频→可扩展交互知识；UMI/夹爪→跨具身动作对齐桥梁；机器人轨迹→具身特定可执行控制。
- **流程**：① 视觉预处理（去鱼眼/朝向校正、遮挡处理）→ ② 层级式 VLM 指令标注与动作分段（任务级/动作级 clip，含任务、动作、场景、被操作物体、时间边界，并做任务/动作一致性校验）→ ③ 质量过滤（静态剔除、无意义/未完成动作、非第一人称、多人、动作一致性）→ ④ 3D 手部运动标注（检测跟踪 → MANO 重建手关键点/腕姿/参数；VGGT-Ω 估计相机内参与逐帧位姿以统一坐标系；时序平滑去抖与漂移）→ ⑤ 几何过滤（手部可见性、手速、相机运动与抖动）→ ⑥ 语义感知数据平衡（统一语义分类体系，多维语义采样，而非按原始数据量配平）。
- **UMI/机器人扩展**：动作边界用夹爪状态跃变校准、动作归一化、机器人专用滤波（相机抖动、静止末端剔除、异常控制、sharp motion、idle clip）。
- **统一表示**：语言指令 + 具身 ID + 视觉观测 + 状态 + 动作 + 语义元数据，按具身规范定义对齐归一化，用有效性掩码处理变维动作。
- **渐进监督层级**：LAM 伪动作（弱监督）→ 3D 手部/UMI/机器人轨迹（真实动作对齐）→ 高质量机器人轨迹（具身专精），与三阶段课程自然对应。

### 2.4 渐进式具身预训练（三阶段课程）
| 阶段 | 名称 | 数据 | $\lambda$ | 作用 |
|---|---|---|---|---|
| I | LAM-Action Bootstrap | 无标注第一人称人类视频 | 0.1 | 用冻结 LAM 产生伪动作，初始化视觉动力学主干 |
| II | Trajectory-Grounded Alignment | UMI + 机器人轨迹 + 3D 手部标注人类视频 | 0.5 | 用真实轨迹把自回归动作-视频接口“落地”，对齐跨相机布局/动作空间/本体 |
| III | Robot-Policy Enhancement | 仅高质量机器人演示 | 0.9 | 锐化可执行动作分布，偏向真实执行器约定与接触丰富执行 |
- **LAM 细节**：作为相邻帧对上的 latent-action VAE 训练；16×16 patch 化，每帧前置可学习 action-prompt token，时空 Transformer 让未来帧的 prompt token 同时看到当前状态与视觉变化；隐状态投影为高斯 $(\mu,\log\sigma^2)$，**32 维**隐动作空间，重参数化采样后注入解码器（解码器只看当前帧 patch，重建下一帧），从而迫使瓶颈编码“转移信息”；损失为重建 + **弱 KL** 正则：$\mathcal{L}_{LAM}=\|\hat{x}_{t+1}-x_{t+1}\|_2^2+\beta D_{KL}(q_\phi(z_t|x_t,x_{t+1})\|\mathcal{N}(0,I))$；推理时用**后验均值 $\mu$** 作为确定性伪动作以消除采样噪声。
- **阶段 I 的数据组织**：LAM 在视频窗口上稠密预测逐帧对伪转移码，再按 WAM 时间接口分组成动作块（一个视觉 latent 对应一小段低层动作），使无标注视频也呈现与真实机器人数据同构的输入结构（视觉 latent + 类状态 token + 稠密类动作块）。
- **后训练**：聚合四个真实任务数据**联合微调单个通用模型**（非任务专用模型），$\lambda$ 提升到 **0.95**。

## 3. 实验设计

### 3.1 真实世界实验
- **平台**：Tianji Marvin 双臂机器人。
- **四个任务**：有序方块堆叠（按颜色顺序四层，考验精确对齐与指令遵循）、衣物折叠（可变形物体、双臂协调、细粒度接触控制）、桌面整理（细长物体如笔插入笔筒，需借助笔筒边缘调整姿态）、厨房整理（勺叉入篮、红黄盘子竖直插入沥水架、碗堆叠到上层，长时程 + 杂乱场景）。
- **数据**：每任务 15 条人类遥操作演示（正文另称每任务采集 3 小时遥操作数据，两处表述不完全一致）。
- **指标**：SR（最终目标完成）+ PSR（按任务特定中间里程碑的进度成功率，针对长时程任务）。
- **对比基线**：DreamZero*（用官方开源实现、以自建大规模操作数据训练的 5B 复现版）、$\tau_0$-WM、LingBot-VLA、$\pi_{0.5}$、LingBot-VA、G0.5。

### 3.2 组合泛化与 OOD（真实机器人）
- **组合泛化**（见过的物体类别、未见任务目标）：① 指定方块放入指定容器（碗/盘）；② 进一步指定物体颜色、容器颜色、容器类型与执行顺序（多步序列）。每任务 10 次试验，对比 $\pi_{0.5}$、LingBot-VA。
- **OOD**（未见场景/物体/目标，无额外演示、无参数更新）：魔方放入收纳箱、毛巾放入水盆，各 10 次试验。

### 3.3 仿真 Benchmark
- **RoboCasa-365**：先在 300 个任务上预训练，再在 Target-50 划分上微调；评估分 Atomic-Seen / Composite-Seen / Composite-Unseen。对比 GR00T-N1.5、Fast-WAM、LingBot-VA、ABot-M0.5。
- **RoboTwin 2.0**：50 个双臂任务，训练集为每任务 50 条干净演示 + 25,000 条强随机化演示（每任务 500 条）；Clean / Randomized 两种评测。对比 $\pi_{0.5}$、ABot-M0、LingBot-VLA、Qwen-VLA、Motus、Fast-WAM、LingBot-VA、G0.5、ABot-M0.5。
- **LIBERO**：四个官方套件（Spatial/Object/Goal/Long），每套 10 任务、每任务 50 演示。对比 $\pi_0$-Fast、GR00T-N1/N1.6、$\pi_0$、InternVLA-M1、$\pi_{0.5}$、OpenVLA-OFT、Fast-WAM、Motus、LingBot-VA、ABot-M0、Being-H0.5、G0.5。
- **世界模拟器评估**：仅**定性**展示多具身动作条件 rollout（人形、双臂、单臂、灵巧手、RoboTwin、RoboCasa-GR1），说明场景结构与动作一致性得以保持；无定量仿真指标（如 FVD/PSNR/动作-视频一致性打分）。

### 3.4 主要结果数字
- 真实世界：平均 SR 85.00%、PSR 94.43%（最强基线 G0.5 为 70.00% / 80.18%）；厨房整理 90.0% SR（次优 G0.5 仅 35.0%）。
- 组合泛化平均 65.0%（$\pi_{0.5}$ 45.0%，LingBot-VA 15.0%）；OOD 平均 85.0%（$\pi_{0.5}$ 50.0%，LingBot-VA 30.0%）；四类 held-out 任务总体 75.0%。
- RoboCasa-365：平均 62.6%（ABot-M0.5 54.2%），Composite-Seen/Unseen 分别 +11.7/+10.7 点。
- RoboTwin 2.0：平均 94.3%（Clean 94.6 / Randomized 94.0），ABot-M0.5 94.1%。
- LIBERO：平均 99.0%（Spatial 99.6、Object 100.0、Goal 97.6、Long 98.6）。

## 5. 实验数量与充分性评估

**覆盖面（较广）**
- 3 个仿真 benchmark（共约 50 + 50 + 40 个任务）+ 4 个真实长时程任务 + 2 个组合泛化任务 + 2 个 OOD 任务。
- 真实世界对比 6 个基线（含自复现的 5B DreamZero*），仿真每榜 4–12 个基线，横跨 VLA 与 WAM 两类范式。
- 额外提供多具身动作条件 rollout 的定性展示。

**充分性上的不足**
- **无消融实验**：三阶段课程各自的贡献、$\lambda$ 取值（0.1/0.5/0.9/0.95）、全因果分解 vs 联合生成/视频优先/解耦、LAM 伪动作 vs 直接用 3D 手部动作、数据引擎各过滤阶段、数据规模 scaling 曲线，均未做定量消融；“统一世界动作建模 + 渐进预训练有效”的核心因果归因因此偏弱。
- **统计强度有限**：真实任务 SR 以 5% 为步长（约 20 次试验/任务），组合泛化与 OOD 仅 10 次/任务，**未报告置信区间、方差或多次随机种子**；单机器人平台、单实验室环境。
- **公平性存疑之处**：
  - 仅 DreamZero 被在同一自建数据上复现，其余基线引用的是各自原论文/官方权重结果，**预训练数据规模与配方不对等**（本文用 200K+ 小时语料）。
  - RoboCasa-365 采用“300 任务预训练 + Target-50 微调”的设定，需确认与各基线协议一致（文中未逐一说明基线是否同样预训练 300 任务）。
  - 真实世界对比中，部分基线（如 LingBot-VLA、LingBot-VA）在某些任务上表现异常低（如厨房整理 20%），可能受适配程度影响，存在“基线未被充分调优”的风险。
  - 真实任务演示数（15 条/任务或 3 小时/任务）与基线是否使用同样后训练数据未完全交代。
- **世界模拟器缺少定量评估**：与“可作多具身仿真器”这一核心卖点对应的定量指标（视频质量、动作条件敏感性、物理合理性、长时程漂移）缺失。
- **效率主张未验证**：论文批评视频优先范式有额外推理延迟，但未报告自身推理时延/控制频率，也未与基线做效率对比。

## 6. 主要结论与发现

- 全因果自回归的“动作先行、视觉后果随后”分解，能在**单一模型**内同时实现在线策略执行与动作条件视觉世界模拟，且训练/后训练/部署使用同一公式，减小监督与在线执行的建模错配。
- 渐进式具身预训练（LAM 伪动作 → 混合轨迹对齐 → 机器人专精，$\lambda$ 0.1→0.5→0.9，后训练 0.95）可有效把弱监督人类视频中的交互知识迁移为可执行操作能力。
- 在仿真与真实长时程任务上均取得 SOTA：RoboTwin2.0 94.3%、LIBERO 99.0%、RoboCasa-365 62.6%（+8.4 点）、真实世界平均 SR 85.0% / PSR 94.4%（SR 超最强开源基线 15 点）。
- 组合泛化（65.0%）与 OOD（85.0%）显著优于对比方法，说明提升并非仅拟合后训练任务，而是具备一定技能复用与场景外推能力。
- 多具身 rollout 定性表明模型学到了跨本体的共享动作条件视觉动力学先验。

## 7. 优点

- **建模范式清晰且有原则**：把“动作先于其视觉后果”的物理因果顺序写进分解与注意力掩码，天然统一策略与世界模型两种用法，避免了联合去噪的模态耦合难题与视频优先的两阶段延迟。
- **工程细节扎实**：teacher-forcing 结构化掩码（frame/time/clean-noisy 三属性）、padding 在噪声注入与损失中的一致性处理、按具身类别专属投影 + 归一化 + 有效性掩码，都是多具身训练中真实存在的坑，论文给出了可复用方案。
- **数据基础设施完整**：6 阶段引擎覆盖从原始视频到动作级轨迹的全链路，尤其用 MANO + VGGT-Ω 从纯视频重建 3D 手部轨迹并统一到相机坐标系，是把 200K 小时人类视频变成“可训练动作监督”的关键。
- **LAM 设计合理**：解码器不可见未来帧 + 弱 KL + 用后验均值作确定性伪动作，避免后验坍缩与标注噪声，且把伪动作组织成与真实数据同构的时间接口（一个 latent 对应一段低层动作），利于阶段间平滑过渡。
- **实验矩阵宽**：三个仿真榜 + 真实四任务 + 组合泛化 + OOD，兼顾 nominal 性能、鲁棒性（RoboTwin Randomized）、长时程（RoboCasa-365 Composite、PSR 指标）与分布外迁移；用 PSR 衡量长时程部分完成度是较有信息量的指标设计。
- **单一通用模型多任务**：后训练聚合四任务联合微调而非任务专用模型，符合“通才策略”方向。

## 8. 不足与局限

- **可复现性信息缺失**：无参数量、无算力/训练时长、无推理延迟与频率、无超参细节（VAE stride、帧采样率、$a_{pf}$、cache 窗口长度、$\beta$ 等仅有符号无数值），代码/数据未提及开源计划。
- **缺少消融，归因不清**：无法判断性能提升来自全因果分解、三阶段课程、LAM 伪动作、数据引擎质量，还是 200K+ 小时数据规模本身；也无法判断各阶段/各数据源的边际贡献。
- **统计效力弱**：真实任务试验次数少（10–20 次）、无方差/置信区间/多 seed；单机器人本体、单场景集合，结论的普适性受限。
- **基线公平性风险**：仅 DreamZero 在同数据下复现；其余基线数据配方不对等，个别基线成绩异常低，存在对比偏乐观的可能；RoboCasa 的“300 任务预训练”协议与基线是否一致未说明。
- **世界模拟器仅定性**：核心卖点之一“多具身视觉仿真器”没有定量评测（无视频保真度、动作条件敏感性、物理合理性、长时

程漂移、动作-视频对齐误差等指标），也未与基线（如 DreamZero、LingBot-VA 的生成分支）做生成质量对比；“世界模拟器”这一身份目前更接近概念演示，而非可验证的能力主张。
- **长时程闭环稳定性缺少压力测试**：论文给出 cache 固定窗口、满则重置并以最近观测为新 context 的工程方案，但未报告窗口长度、重置频率对长时程任务成功率的影响，也未分析自回归误差累积、动作块边界不连续、执行失败后的恢复行为；PSR 虽刻画了中间进度，但没有失败类型分类（感知失败 / 抓取失败 / 规划失败 / 执行漂移）。
- **具身覆盖偏窄**：动作接口以手臂 + 夹爪/灵巧手为主（UMI、双臂、RoboTwin、RoboCasa-GR1），对移动底盘、全身人形 locomotion、多机器人协同、以及带力/触觉反馈的本体均未涉及；而 MANO 手部模型本身无法表达非手形态执行器（吸盘、多指夹爪开合模式、工具末端），因此“跨具身”的范围实际上小于标题所暗示的广度。
- **人类视频监督的假设较强**：3D 手部伪动作依赖单目相机内参与逐帧位姿估计（VGGT-Ω）的精度，遮挡、快速运动、镜头切换下误差会直接进入动作监督；MANO 无法刻画接触力、形变与工具使用，因此伪动作与真实机器人动作之间更接近“统计/运动学对齐”而非“物理对齐”，论文未量化这一 gap 对下游策略的影响。
- **LAM 伪动作缺乏物理语义校验**：32 维隐动作空间无单位、无方向约定，论文未验证其是否学到单调、可插值、可跨本体迁移的结构（如线性探针、隐动作可视化、跨具身隐动作相似度），因此 Stage I 的“知识迁移”机制仍偏黑箱。
- **语言条件过于模板化**：prompt 为固定模板，未评估细粒度空间关系、否定约束、条件分支、多语言指令，也未评估对话式纠错或人类中途干预；这与“具身大脑”应有的指令理解能力之间存在明显落差。
- **超参与训练配方不透明**：帧率/帧采样策略、VAE 时空压缩率、每块动作步数 $a_{pf}$、cache 窗口长度、flow matching 噪声调度、$\lambda$ 课程的具体切换点、LAM 的 $\beta$ 与隐维度选择依据等均只给符号或定性描述，外部难以复现或做敏感性分析。
- **缺少失败案例与定性错误分析**：未展示失败 rollout、未讨论模型在哪些物理交互（可变形物体、透明/反光物体、精密插入）上更易出错，也未与基线做错误类型对比，削弱了结论的诊断价值。
- **部署与安全考量缺失**：真机实验未报告控制频率、端到端延迟、急停/力矩限制/碰撞保护等安全机制，也未讨论人机共存场景下的风险；对“可执行策略”的工程可用性证据不足。
- **数据伦理与合规未提及**：200K+ 小时第一人称人类视频的来源、授权、人脸与家庭场景脱敏、以及数据许可对模型发布的影响均未说明。
- **时效性与基线版本**：对比的多个基线为同期或近期的快速迭代工作（G0.5、ABot-M0.5、LingBot-VA 等），论文未说明各自版本号与提交日期，排行榜式对比的可复现性与时效稳定性存疑。

## 9. 对领域的启示与可改进方向

- **范式层面**：把“动作先于其视觉后果”的物理因果顺序编码进序列分解与注意力掩码，是统一策略与世界模型的一种干净做法；它把“世界模型是否需要独立模块”这一问题转化为“序列顺序与条件结构如何设计”，对后续 WAM 工作有直接参考价值。
- **数据层面**：论文最有复用价值的贡献可能不是模型本身，而是“人类视频 → 3D 手部轨迹 → 与机器人数据同构的动作块”这条管线；它给出了在动作空间不共享的前提下利用弱监督视频的一条可行路径，但需要后续工作量化其精度上限。
- **可补强的实验**（按优先级）：
  1. **消融矩阵**：全因果 vs 联合去噪 vs 视频优先 vs 解耦双 DiT；Stage I/II/III 逐级去除；LAM 伪动作 vs 直接 3D 手部动作 vs 无动作监督；$\lambda$ 扫描；数据规模 scaling（如 10K/50K/200K 小时）。
  2. **世界模型定量评测**：FVD/PSNR/LPIPS、动作条件敏感性（同一初始帧不同动作的生成差异度）、物理合理性（物体恒存、接触一致性）、长时程漂移曲线，并与视频生成基线对比。
  3. **效率报告**：参数量、训练 GPU 时、推理延迟与控制频率、显存占用，验证“相比视频优先范式更高效”的主张。
  4. **统计严谨性**：多随机种子、置信区间、每任务试验数提升到统计可分辨的量级，并在第二台机器人/第二实验室复现。
  5. **公平基线协议**：统一各基线的预训练数据与后训练演示数，或明确标注差异并做“同数据复现”对照（目前仅 DreamZero 做到）。
- **方法层面的潜在改进**：为隐动作引入物理正则（如末端位姿、夹爪开合、时序平滑约束）；引入失败检测与在线重规划；将 cache 重置策略与不确定性估计结合；探索动作块的变长自适应以匹配不同任务的接触节奏。

## 10. 总体评价

Riemann-1.0 是一篇**工程完成度高、范式表述清晰、实验矩阵宽**的具身基础模型工作：它以“全因果动作-视频自回归”为核心，把策略学习与世界模拟统一到同一分解与同一套训练/推理流程中，并用三阶段渐进预训练把 200K+ 小时异构具身经验（尤其是弱监督人类视频）转化为可执行的长时程操作能力；在 RoboCasa-365、RoboTwin 2.0、LIBERO 与真实双臂四任务上均取得有竞争力的数字，组合泛化与 OOD 结果也支持“技能复用而非单纯拟合”的解读。

但其**证据结构存在明显不对称**：性能主张强，机制归因弱——缺少消融、缺少统计效力、缺少世界模拟器的定量评测、缺少算力与超参透明度，基线公平性也只在 DreamZero 一处得到控制。因此更准确的定位是：**它提出并验证了一个有原则的统一建模方案与一套可复用的数据/训练基础设施，但尚未证明性能提升具体来自哪一设计选择，也未兑现“多具身世界模拟器”的可验证承诺**。对读者而言，最值得借鉴的是其因果序列分解、注意力掩码与 padding 一致性处理、以及人类视频到动作监督的管线；最需要警惕的是把“宽实验矩阵”误读为“强因果证据”。
