## 摘要
联邦学习为多个机器人共同改进操作策略提供了一种自然方式，无需集中访问训练示范。然而，非独立同分布（Non-IID）的任务和环境分布会导致表示漂移以及彼此不兼容的机器人策略更新，从而使朴素的参数聚合具有破坏性。我们提出 FedDRMan，一种面向异构机器人操作的联邦子空间引导蒸馏框架。在每轮通信中，服务器模型提供一个冻结的教师模型用于本地行为克隆，同时低秩多模态子空间与动作分布蒸馏保留全局有用的表示几何结构和策略行为。为解决异构聚合问题，FedDRMan 根据更新兼容性对客户端进行分组，并为每个簇维护一个持久模型。随后，服务器对每个兼容聚合结果进行谱重平衡，以缓解较弱但任务相关的机器人策略更新方向的衰减。在 LIBERO 上跨多种非独立同分布设置、异构程度、客户端参与变化开展的大量实验，以及消融实验和聚合分析表明，FedDRMan 显著提升了知识迁移，并持续优于强联邦基线，达到 80.7% 的峰值平均成功率，比所评估的最强联邦基线高出 11.6 个百分点。

## Abstract
Federated learning offers a natural way for multiple robots to jointly improve manipulation policies without requiring centralized access to training demonstrations. However, non-IID task and environment distributions can induce representation drift and mutually incompatible robot-policy updates, making naive parameter aggregation destructive. We present FedDRMan, a federated subspace-guided distillation framework for heterogeneous robot manipulation. At each communication round, the server model provides a frozen teacher for local behavior cloning, while low-rank multimodal subspace and action-distribution distillation preserve globally useful representation geometry and policy behavior. To address heterogeneous aggregation, FedDRMan groups clients by update compatibility and maintains a persistent model for each cluster. The server then spectrally rebalances each compatible aggregate to mitigate attenuation of weaker task-relevant robot-policy update directions. Extensive experiments on LIBERO across diverse non-IID settings, heterogeneity levels, client participation variation, together with ablations and aggregation analyses, show that FedDRMan substantially improves knowledge transfer and consistently outperforms strong federated baselines achieving a peak mean success rate of 80.7%, 11.6 percentage points above the strongest evaluated federated baseline.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）策略在语言条件机器人操作上进展显著（RT-2、OpenVLA-OFT 等），但依赖大规模、多样化的机器人示范数据（如 Open X-Embodiment）。现有训练范式仍假设不同机器人的示范可被集中汇聚，这对多机器人系统构成通信开销与隐私泄露（用户信息、机器人位置、部署环境）的双重限制。
- **联邦学习（FL）的引入**：各机器人仅交换模型更新而非原始轨迹，是协同训练共享策略的自然框架。但**非独立同分布（Non-IID）**的任务与环境分布会引发两个耦合问题：
  - **表示漂移（representation drift）**：本地行为克隆（BC）会把视觉、语言、本体感知表示推向客户端特有的特征分布；
  - **更新不兼容（incompatible updates）**：不同机器人的策略更新方向相互冲突，朴素参数平均会抑制任务相关知识，甚至产生破坏性聚合。
- **现有工作的空白**：
  - 多数异构 FL 研究聚焦单模态或非机器人场景；
  - 子空间蒸馏（SPREAD）与谱模型合并方法主要面向顺序学习或一次性集中式合并，未处理联邦 VLA 中反复本地适配导致的多模态表示重塑与周期性异构整合；
  - FLAME 是基准而非异构专用方法；FedVLA 的异构处理依赖 MoE 专家路由架构，与本文路线不同。
- **整体含义**：FedDRMan 首次将"多模态子空间蒸馏"与"兼容性感知的谱聚合"统一到联邦 VLA 训练中，同时控制本地适配期的表示漂移与服务器聚合期的破坏性干扰，且不增加额外通信负载。

## 2. 方法论

### 2.1 问题形式化
- 联邦系统含 K 个机器人在共享的语言条件操作 MDP $M=(S,A,T,H,\mu_0,\phi)$ 下运行；每个客户端 k 拥有私有示范集 $D_k$，服从非 IID 分布。
- 全局目标为加权最小化各客户端 BC 损失：$\min_\theta \sum_k p_k \mathbb{E}_{D_k}[L_k]$，$p_k = n_k/\sum_j n_j$。
- 策略采用 LIBERO 的 **ResNet-T**：ResNet 视觉编码器 + FiLM 语言条件 + 预训练 BERT 嵌入 + 时序 Transformer + **GMM 动作头**（建模连续动作的多峰分布）。

### 2.2 联邦子空间引导的全局→本地蒸馏
- **冻结教师-可训练学生**：每轮由服务器模型复制出冻结教师 $\bar\theta_g^r$ 与学生 $\theta_k^{r,0}$，教师梯度置零，仅在服务器聚合后刷新。
- **本地 BC 损失**：$L_{BC}(\theta_k) = -\mathbb{E}[\log \pi_{\theta_k}(a|o,D)]$。
- **多模态子空间蒸馏**：
  - 对每个模态 $m \in \{text, agent, wrist, joint, gripper\}$，将 batch-time 编码器特征堆叠为 $F_m^x \in \mathbb{R}^{d_m \times N}$（$N=BT$，$x$ 表示教师 g 或学生 k）；
  - 做截断 SVD 得 $F_m^x = U_m^x \Sigma_m^x (V_m^x)^\top$，取秩 $r_m$ 的正交投影 $P_{r_m}^x = U_{m,r_m}^x (U_{m,r_m}^x)^\top$；
  - **对称子空间损失**：
    $$L_{sub}^m = \|P_{r_m}^g F_m^g - P_{r_m}^k F_m^k\|_F^2 + \|P_{r_m}^g F_m^k - P_{r_m}^k F_m^g\|_F^2$$
    第一项对齐教师/学生子空间保留的特征内容，第二项强制对称交叉投影一致性；不要求坐标级特征对应。
  - 特征矩阵接近退化时加入小幅预 SVD 扰动以保证数值稳定。
- **动作分布蒸馏**：从教师策略采样 $\hat a \sim \pi_{\bar\theta_g^r}$，最小化对数概率差
  $$L_{act} = \mathbb{E}_{\hat a}\big[\log \pi_{\bar\theta_g^r}(\hat a|o,D) - \log \pi_{\theta_k}(\hat a|o,D)\big]$$
  仅约束行为分布、不直接传递特征几何，与子空间项互补。
- **总损失**：$L_k = L_{BC} + \sum_{m\in M}\lambda_m L_{sub}^m + \lambda_{act} L_{act}$，梯度只经本地学生回传。

### 2.3 兼容性感知的谱联邦聚合（服务器端）
- **兼容更新聚合（CUA）**：
  - 服务器维护 C 个持久簇模型 $\{\theta_s^r\}_{s=1}^C$，所有客户端共享同一初始 $\theta^0$；
  - 用**自初始化的累计更新** $\Delta_k^r = \theta_k^r - \theta^0$ 在共享子模块 Ω（本文取**时序 Transformer**）上的向量化表示计算两两余弦相似度 $S_{ij}^r$；
  - 选择累计更新而非逐轮增量，因为其兼容性信号更稳定；
  - 通过最大化簇内平均相似度、最小化簇间平均相似度，将客户端划分为 C 个非空组（式 11）；
  - 簇内按样本量重新归一化权重 $\tilde p_k = n_k / \sum_{j\in G_s^r} n_j$，聚合完整本地模型得 $\theta_{avg,s}^{r+1}$ 与簇更新 $\Delta_s^r$。
- **谱重平衡（SRB）**：
  - 对簇更新中**符合条件的一维/二维权重矩阵块**做 SVD：$\Delta_{s,b}^r = U_{s,b}\Sigma_{s,b}V_{s,b}^\top$；
  - 按累计奇异值阈值 $\beta$ 确定 $c^\star = \min\{i : \sum_{j\le i}\sigma_j / \sum_j \sigma_j \ge \beta\}$，把小于 $\sigma_{c^\star}$ 的奇异值抬升至 $\tilde\sigma_i = \max(\sigma_i, \sigma_{c^\star})$，重建 $\tilde\Delta_{s,b}^r$；
  - 作用范围：图像空间投影器、语言与本体编码器、时序 Transformer、策略头中的线性权重矩阵，其余参数保留簇内平均结果；
  - 下一轮簇模型 $\theta_s^{r+1} = \theta_s^r + \tilde\Delta_s^r$，客户端按簇分配下载对应模型；
  - **不增加客户端-服务器模型载荷**（与 FedAvg 相同）。
- **理论解释**：将 $\delta_k^r = C_s^r + U_k^r$ 分解为簇内共享分量与机器人特有分量；若 $U_k^r$ 两两正交且 $\|U_k^r\|_F \le B$，则聚合后的特有分量平方幅值 $\le B^2/K_{eff,s}$，即 Frobenius 范数以 $O(K_{eff,s}^{-1/2})$ 衰减；存在正对齐时交叉项可保留相干更新能量。CUA 促进兼容性以增强交叉项，SRB 则补强被衰减的弱方向。

## 3. 实验设计

- **数据集/场景**：LIBERO 三个标准套件——LIBERO-Spatial、LIBERO-Object、LIBERO-Goal；每套件 10 个语言条件操作任务、每任务 50 条专家示范；构建序列后训练样本量分别约为 62,250 / 74,507 / 63,728。每个样本含两路 RGB 观测、语言指令、本体状态与 7 维连续动作序列。
- **Benchmark**：LIBERO 闭环 MuJoCo rollout，250 步时域，主指标为**任务成功率（SR）**。
- **非 IID 设置**：

  - **跨套件任务与环境非 IID**：成对设置 Object-Goal / Object-Spatial / Goal-Spatial 用 K=4（每套件 2 客户端）；三套件 Object-Goal-Spatial 用 K=6（每套件 2 客户端）。客户端在套件内非 IID，跨套件还额外在任务族、物体、环境、状态-动作分布上不同。
- **对比方法**：

  - Local BC（本地独立训练，无共享，下界参考）
