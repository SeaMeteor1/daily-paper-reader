## 摘要
视觉-语言模型（VLMs）和视觉-语言-动作模型（VLAs）最近推动了通用机器人的快速发展，但大多数进展仍集中在单机器人场景中。将这些能力扩展到多机器人系统仍然具有挑战性，因为机器人必须在保持可靠、细粒度执行的同时协调长时程行为。我们提出 DuoMind，一个通过语义通信实现多机器人协同的分布式分层框架。每个机器人使用基于 VLA 的动作模型进行底层执行，并使用基于 VLM 的协调器进行高层推理和智能体间协同。在每个规划步骤，每个机器人的协调器都会对任务指令、局部观测以及从其他机器人接收到的消息进行推理。然后，它为该动作模型生成底层指令，并为对等机器人生成语义消息。该架构通过将 VLM 的语义推理能力与 VLA 的精确动作生成能力相结合，利用了预训练模型的互补优势。为解决多机器人协同基准稀缺的问题，我们进一步开发了 RoboPoly，一个包含长时程操作任务的基准，这些任务需要在分布式控制下进行协同的闭环执行。在 RoboPoly 和 RoboTwin 上的实验表明，DuoMind 提升了多机器人任务性能，消融研究则证实了分层编排和语义通信的贡献。更多细节请见我们的项目主页。

## Abstract
Vision-language models (VLMs) and vision-language-action models (VLAs) have recently driven rapid progress in general-purpose robots, yet most progress has focused on single-robot settings. Extending these capabilities to multi-robot systems remains challenging because robots must coordinate long-horizon behaviors while maintaining reliable, fine-grained execution. We introduce DuoMind, a distributed hierarchical framework for multi-robot coordination through semantic communication. Each robot uses a VLA-based action model for low-level execution and a VLM-based orchestrator for high-level reasoning and inter-agent coordination. At each planning step, the orchestrator at each robot reasons over the task instruction, local observations, and messages received from other robots. It then generates low-level instructions for the action model and semantic messages for peer robots. This architecture exploits the complementary strengths of pretrained models by combining the semantic reasoning capabilities of VLMs with the precise action-generation capabilities of VLAs. To address the scarcity of benchmarks for multi-robot coordination, we further develop RoboPoly, a benchmark comprising long-horizon manipulation tasks that require coordinated, closed-loop execution under distributed control. Experiments on RoboPoly and RoboTwin demonstrate that DuoMind improves multi-robot task performance, while ablation studies confirm the contributions of hierarchical orchestration and semantic communication. More details are available on our project page.

## 1. 核心问题与研究背景

- **研究动机**：VLM（视觉-语言模型）与 VLA（视觉-语言-动作模型）已显著推动通用机器人能力，但绝大多数进展集中在**单机器人**场景。
- **关键挑战**：将上述能力扩展到多机器人系统时，机器人既要协调**长时程行为**，又要保持**可靠、细粒度的底层执行**，二者难以兼顾。
- **现有方法的空白**：
  - 传统多智能体学习/规划多在物理交互有限、任务时程较短的简单环境中验证，且需针对任务联合训练，协调被编码在难以解释的隐表示中。
  - 基于 LLM 的多机器人系统多聚焦高层规划，底层控制依赖**预定义动作原语或规则技能**，在"高层多智能体推理"与"端到端机器人控制"之间存在明显断层。
  - 多机器人协同的**评测基准稀缺**，缺乏可系统衡量协同能力的测试平台。
- **论文整体含义**：提出分布式分层框架 DuoMind 与长时程协同基准 RoboPoly，试图用"VLM 编排器 + VLA 动作模型 + 自然语言语义通信"打通高层协同与底层执行，并复用现成预训练模型（少改架构、轻量适配）。

## 2. 方法论

### 2.1 核心思想
- 将多机器人协同解耦为**两个层级**：
  - **高层多智能体推理**：每台机器人用 VLM 作为 *orchestrator*（编排器），负责理解任务、分解子任务、智能体间协调。
  - **底层执行**：用 VLA 作为 *action model*，依据低层指令与局部观测输出细粒度动作。
- 好处：避免让动作模型直接解释包含多机器人联合行为的复杂多智能体状态（VLA 通常仅用单智能体示教训练）；两个模块可**各自独立替换升级**，无需为多机器人场景重新设计接口。

### 2.2 关键技术细节
- **每个规划步的输入**：高层任务指令 + 本地观测（全局相机 + 自身腕部相机）+ 来自其他机器人的消息。
- **每个规划步的输出**（两路互补）：
  1. 给动作模型的**低层指令**（自然语言，单智能体、短时程）；
  2. 给同伴的**结构化语义消息**。
- **以自然语言为统一接口**：相比轨迹/视觉子目标/学习隐表示，自然语言具备可解释性、与语言条件模型兼容、支持异构机器人与人类介入；缺点（论文未强调）是信息密度较低。
- **结构化消息的四个字段**：
  - *Intention*：与发给动作模型的低层指令一致，告知同伴自己的下一步动作；
  - *Subgoals*：完成当前子任务后预期的任务状态；
  - *Belief of task*：自身观测/推断出的任务相关信息（如关键物体位置、某子任务是否完成）；
  - *Uncertainty of belief*（可选）：对自身信念的不确定性，供同伴在信念冲突或信息模糊时加权。
- **面向部分可观测与非平稳性**：显式消息共享把局部知识在智能体间传播，缓解各智能体只掌握全局任务状态局部信息、且环境随他者动作持续变化的问题。
- **工程实现要点**：
  - 每个生成的低层指令被限制在**预定义的可采纳指令集合**内，以防超出 VLA 的指令跟随能力或训练分布；
  - 引入**进度机制**：当推理停滞（子目标已完成却仍重复）时强制推进阶段，防止系统无限停留在中间阶段；
  - 采用 **VLM interval** 控制调用频率：编排器低频调用（每若干动作块调用一次），动作模型高频执行；
  - 仅验证**双机器人**设定，更大规模团队留待未来工作。

## 3. 实验设计

### 3.1 数据集与场景
- **RoboPoly（本文提出的新基准）**：
  - 基于 **ManiSkill3** 构建，含 **7 个双机器人长时程操作任务**：Food Serve、Prepare Snack、Clean Table、Cook Pot、Put Object Cabinet、Hang Bag、Exchange Bread。
  - 两台 7-DoF Franka Emika Panda 分列桌面两侧；观测为 1 个全局相机（512×384）+ 各自腕部相机（128×128），**分布式观测**：每台机器人看不到对方的腕部相机；**分布式控制**：每个策略只控制一台机器人。
  - 任务对单机器人不可行或低效，必须协商"何时协作、何时动作"。
  - 数据生成：用 ManiSkill3 的运动规划轨迹生成流水线，先分解为关键状态（抓取、释放、移动到目标等），再规划平滑轨迹并回放渲染 RGB；每条操纵阶段配低层指令，另有高层任务指令；数据集开源。
- **RoboTwin 2.0**：选 **8 个双臂任务**（Hanging Mug、Pick Diverse Bottles、Stack Bowls Two、Put Bottle Dustbin、Lift Pot、Handover Mic、Blocks Ranking RGB、Put Object Cabinet）。原为集中式双臂控制，本文改为把双臂视为两台独立机器人分别控制。

### 3.2 数据与训练设置
- RoboPoly：每任务采集 50 条双机器人示教，拆解为**统一的单机器人数据集共 100 条轨迹**用于微调。
- RoboTwin：每任务 50 条官方双臂示教，拆成左右臂轨迹（各配对应腕部相机 + 共享头部相机），合并为 100 条单臂轨迹。
- 低层控制器：**π0.5**，LoRA 微调；RoboPoly 批大小 256–1024、2k–10k 步；RoboTwin 批大小 32、20k 步。
- 高层推理：**Qwen3-VL-4B-Instruct**。
- 注意：RoboTwin 官方数据无低层指令，微调时用高层指令，评测时却提供分解后的低层指令（论文承认两者不完全匹配，靠 VLA 泛化弥补）。

### 3.3 对比方法与评测
- 对比基线：**π0.5 only**、**π0 only**（均以高层指令微调，其余配置与 DuoMind 一致）。
- 每任务 **400 次 rollout** 统计成功率；所有方法接收相同的高层指令与观测。

## 6. 主要结论与发现

- **整体性能**：DuoMind 在多数任务上**持平或优于** π0.5-only 与 π0-only 基线，提升来自高层推理与智能体间通信。
- **任务时程越长、协同越复杂，收益越大**：RoboPoly 上提升幅度明显大于 RoboTwin（RoboPoly 任务更长、协调要求更高，但绝对成功率整体偏低）。
- **通信至关重要**：关闭通信后冲突与不同步行为显著增多（如 Cook Pot 中一方先抬锅而另一方尚未抓稳手柄；Prepare Snack 中两机器人同时选同一盘子导致机械臂碰撞），验证显式共享意图/子目标/信念能缓解部分可观测性。
- **分层设计可纠错恢复**：当执行偏离计划（多机器人场景中对方改变了自己的工作空间）时，编排器能识别变化并重新下发指令；而仅跟随固定高层指令的 π0/π0.5 容易在意外交互后不知所措。
- **动作模型可替换**：DuoMind+π0 虽弱于 DuoMind+π0.5，但显著优于 π0-only，说明收益不只来自更强动作模型，编排层本身有独立贡献；更强的 VLA 可进一步提升整体成功率。
- **个别任务上的例外**：RoboTwin 的 Put Object Cabinet 上 DuoMind（43.25）略低于 π0.5-only（46.50）；Blocks Ranking RGB 上所有方法成功率都极低（DuoMind 2.00），说明仍有明显失败模式。

## 7. 优点（方法 / 实验设计亮点）

- **架构解耦清晰**：VLM 负责"想"，VLA 负责"做"，接口用自然语言统一，使现成基础模型可**近乎开箱即用**（仅轻量适配），组件可独立升级替换。
- **通信设计有结构性**：消息含 Intention / Subgoals / Belief / Uncertainty 四字段，兼顾意图对齐、主动配合、部分可观测补偿与信念加权，比单纯共享隐向量更具可解释性。
- **自然语言接口的额外红利**：天然支持异构机器人（不同推理模型也能互读消息）与人类介入（可直接查看/修改指令）。
- **基准贡献**：RoboPoly 强调**分布式观测 + 分布式控制 + 闭环物理执行 + 显式协作需求**，区别于 RoboTwin 的集中式双臂设定，填补了长时程多机器人协同评测的空白，并开源数据集。
- **工程稳健性设计**：候选指令约束 + 进度强制推进机制，有效抑制 VLM 幻觉式指令与阶段停滞。
- **实验规模较大**：15 个任务 × 400 rollouts，且给出两个基准上的跨任务结果与可视化示例。

## 8. 不足与局限

- **规模限制**：论文明确只验证**双机器人**场景，未验证更多机器人时的可扩展性（作者归因于计算成本）。
- **仅仿真、无真机**：全部实验在 ManiSkill3 与 RoboTwin 仿真中完成，未涉及真实硬件、真实通信延迟/丢包、标定误差等实际部署问题。
- **绝对性能偏低**：RoboPoly 上多个任务成功率很低（如 Prepare Snack 18.00、Clean Table 24.75、Cook Pot 39.25），RoboTwin 的 Blocks Ranking RGB 仅 2.00，说明框架对困难任务仍不可靠。
- **并非全面占优**：个别任务（RoboTwin Put Object Cabinet）DuoMind 低于 π0.5-only，论文未深入分析该反例。
- **评测公平性细节**：RoboTwin 微调使用高层指令而评测使用低层指令，指令分布不一致，可能对不同方法产生非对称影响；基线仅为本工作内部的 π0/π0.5 变体，缺乏与集中式控制、其他 LLM 多机器人规划框架的横向对比。
- **超参敏感性未系统研究**：VLM interval（2/3/4）、候选指令集合的构造方式、进度机制的阈值等对性能的影响缺少敏感性分析或消融。
- **不确定性字段的实际作用未量化**：Uncertainty of belief 为可选字段，论文未给出其被使用/被忽略的频率及其对成功率的具体贡献。
- **潜在偏差风险**：RoboPoly 由作者自行设计任务与数据生成流程，任务与指令集合较为结构化，可能存在对自家框架有利的定制性；成功率指标单一，缺少效率、碰撞率、通信开销等辅助度量。
- **应用限制**：依赖 VLM 推理，通信与推理频率受算力约束；自然语言接口虽可解释，但信息带宽低于隐表示，在高度动态、需要毫秒级协同的场景可能不足。
