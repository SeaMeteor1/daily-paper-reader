## 摘要
扩大机器人操作规模的主要瓶颈在于真实世界机器人数据的稀缺。尽管近期方法利用人类视频演示来缓解这一短缺，但它们计算开销仍然很高，并且仍依赖成对的人-机器人数据来进行域对齐。虽然当前最先进方法擅长长时程任务，但它们在复杂工具操作所需的精细且精确的控制上仍表现不佳。为克服这些局限，我们提出了 P2P-T，即 from Pixel to Poses for Tool Manipulation（从像素到位姿的工具操作），一个数据高效、以物体为中心的框架，可直接从人类演示中学习工具使用。P2P-T 通过两阶段方法弥合认知与物理执行之间的差距。首先，预训练一个以物体为中心的世界模型以提取稳定的位姿先验；其次，将这些先验集成到一个高效、位姿感知的底层策略中。通过利用由现代基础模型驱动的稳健自动化数据处理流水线，P2P-T 完全绕过了对人类-机器人对齐数据的需求。这大幅降低了整体训练开销。仅需最少的逐任务微调，我们的框架在复杂真实世界工具操作任务上的执行性能较此前最先进方法提升了 73%，而这些任务目前仍超出标准大规模预训练模型的能力范围。

## Abstract
Scaling up robotic manipulation is primarily bottlenecked by the scarcity of real-world robot data. While recent approaches leverage human video demonstrations to mitigate this shortage, they remain computationally expensive and still rely on paired human-robot data for domain alignment. Although current state-of-the-arts excel at long-horizon tasks, they struggle with the delicate and precise control required for complex tool manipulation. To overcome these limitations, we introduce P2P-T, from Pixel to Poses for Tool Manipulation, a data-efficient, object-centric framework that learns tool use directly from human demonstrations. P2P-T bridges the cognitive and physical execution gap through a two-stage approach. First, pretraining an object-centric world model to extract stable pose priors; second, integrating these priors into an efficient, pose-aware low-level policy. By utilizing a robust automated data processing pipeline powered by modern foundation models, P2P-T completely bypasses the need for human-robot aligned data. This reduces overall training overhead drastically. With minimal per-task fine-tuning, our framework achieves a 73% improvement over the previous state of the art in execution performance on complex, real-world tool manipulation tasks that currently remain out of reach for standard large-scale pretrained models.

- **根本瓶颈**：机器人操作能力的规模化受限于真实机器人数据的稀缺——遥操作配对数据的采集成本高、劳动密集。

  - 从原始人类视频提取运动先验的**计算开销极大**（论文称某些全流程训练需数百块 GB200 级别的 GPU）。

- **研究含义**：家庭等动态场景中，机器人不可能按任务频繁更换末端执行器，因此必须学会使用为人手设计的工具。论文主张以"物体为中心"的表示替代形态相关的人手运动建模，从而在不依赖配对数据的前提下同时获得高层功能认知与低层执行精度。

## 2. 方法论

### 2.1 核心思想
- 人手与机器人手形态迥异，但**操作特定工具所需的空间轨迹是一致的**。因此 P2P-T 剥离人手动作，直接以工具的 6D 位姿轨迹作为形态无关的中间表示。
- 两阶段框架：**Stage 1 预训练以物体为中心的世界模型提取稳定位姿先验；Stage 2 将先验注入位姿感知的低层扩散策略**。

### 2.2 数据预处理流水线（自动化）
- 三步走，全部基于基础模型、零样本：
  1. **2D 掩码提取**：Grounded-SAM 分离目标工具，得到二值掩码；
  2. **3D 网格重建**：SAM 3D 将多视角 RGB + 掩码提升为高保真工具网格 M=(V,F)；
  3. **6D 位姿跟踪**：FoundationPose 将网格的几何与纹理先验与原始帧对齐，输出逐帧位姿。
- 之后经**人工校验**过滤不可靠轨迹（整体丢弃率 27%，杯子最低 19%，螺丝刀最高约 37.9%，因其绕 z 轴近似对称导致旋转难以跟踪）。

### 2.3 位姿表示
- 工具状态表示为相机坐标系下的齐次变换矩阵 **P_t ∈ SE(3)**，含平移 T_t∈R³ 与旋转 R_t∈SO(3)。
- 训练时将 4×4 矩阵**按行展平为 16 维向量** p_t=vec(P_t)，评估时再还原为矩阵。
- **刻意采用过参数化表示**：四元数存在 q 与 −q 的符号歧义，欧拉角存在绕回与奇异点，而矩阵元素随旋转连续变化，可提供无歧义、连续的回归目标，避免震荡训练行为。

### 2.4 Stage 1：以物体为中心的世界模型预训练
- 输入：RGB 观测 I_t、语言指令 c、当前工具位姿 p_t；**自回归预测未来 H−1 步的位姿隐变量与视觉隐变量**：
  {Z^pose_{t+k}, Z^vis_{t+k}} = F_θ(I_t, c, p_t)。
- 两个解码头分别将隐变量解码为未来位姿与未来帧：p̂_{t+k}=D_pose(Z^pose_{t+k})，Î_{t+k}=D_frame(Z^vis_{t+k})。
- 架构：视觉用**冻结的 DINOv2 + SigLIP**，语言用**冻结的 T5**；特征与当前位姿投影到共享隐空间，加可学习模态嵌入，与可学习融合 token 拼接后送入自回归 Transformer。
- 损失：位姿回归 L_pose 为 H−1 步预测位姿与真值的均方误差；辅助帧预测 L_frame 同理；总目标 **L_stage1 = L_pose + λ·L_frame，取 λ=0.01**，即以位姿学习为主、视觉预测仅作正则。

### 2.5 Stage 2：位姿感知后训练与部署
- 低层动作专家由**预训练的 RDT backbone 初始化**。
- **冻结的 Stage-1 世界模型**输出未来位姿隐变量序列 Z^pose_{t+k}（k=1..H−1）；共享的可训练 MLP 将其投影到 RDT 嵌入空间，得到 U^pose_{t+k}，按时间顺序拼接为 U^pose_t，并**插入到机器人本体感知状态 token s_t 之前**。
- 策略为条件扩散模型，预测动作块 a_{t:t+H−1}，条件包括位姿隐变量序列、本体状态、多视角 RGB 历史与语言指令。训练时用 DDPM 调度器加高斯噪声，采用 **sample prediction（直接回归干净动作块）** 的 MSE 损失 L_act。
- 训练中冻结 Stage-1 模型及 T5/SigLIP 编码器，仅优化 RDT 动作专家与位姿适配器。
- 推理：Stage-1 先生成未来位姿隐变量，动作专家以其投影 token 为条件，用**快速 DPM-Solver** 采样动作块，以**滚动时域（receding-horizon）**方式执行并随新观测更新。

    - **基线公平性存疑**：论文自述 FastWAM 在部分任务 0% 成功率"主要因为 100 条演示不足以完成任务适配"，但并未为基线提供其惯常所需的更大数据量或更长微调预算，基线处于明显不利的数据条件。
    - **参数量不对等**：LingBot-VA 约 5.1B、FastWAM 基于 5B 级视频模型，而 P2P-T-Base 为 1.92B，比较未在等规模下进行。
    - 缺少与 FUNCTO、SPOT 等同类物体中心方法的直接对比（作者解释为未开源），削弱了与最相关工作可比性的论证力度。
    - 无仿真实验、无多本体泛化实验、无失败模式的定量统计分析（仅定性描述"偶尔抓取不稳"）。

## 6. 主要结论与发现

- P2P-T 平均成功率达 **0.57**，显著超过最强基线 π0.5（0.33），**平均提升约 73%**，推理速率 30 Hz（远高于 FastWAM 的 10 Hz 与 LingBot-VA 的 8 Hz）。
- **无需人-机器人配对数据**，且大幅降低训练开销，仅需少量逐任务微调。
- 失败模式分析：π0.5 等通用 VLA 具备较强初始抓取能力，但**缺乏功能几何知识**，在交互阶段（如对齐锤头）的 SE(3) 空间操作上持续失败；世界动作模型虽在抓放/装配上有泛化性，但在工具使用场景数据效率低、表现次优（0.02 与 0.21）。
- **消融结论**：仅接世界模型 + 标准 DP2 策略最差（Hammer 0.12 / Cup 0.14），说明缺少位姿感知架构时无法利用几何先验；仅用当前位姿条件化的微调 RDT 中等（0.32 / 0.36），说明隐式 2D 特征与当前位姿不足；**两阶段协同最优（0.59 / 0.60）**，证明位姿先验对细粒度工具对准不可或缺。
- **规模结论**：性能随容量单调提升（0.41 → 0.60 → 0.66），大模型对几何变化（手柄长度、重量）与动态扰动泛化更好、动作更平滑。

## 7. 优点

- **表示层面的关键洞见**：以工具 6D 位姿替代人手动作作为形态无关中间表示，从根本上绕开人-机器人形态对齐与配对数据需求，思路简洁且具有可迁移性。
- **过参数化的位姿回归设计**：用展平的 4×4 齐次矩阵而非四元数/欧拉角，规避符号歧义与奇异性，提供连续无歧义回归目标，是工程细节上的合理选择。
- **全自动数据流水线**：Grounded-SAM + SAM 3D + FoundationPose 的零样本组合，把三维标注瓶颈转化为可规模化的自动流程，并保留人工校验环节控制数据质量。
- **两级隐变量接口设计**：Stage-1 位姿隐变量直接作为 token 插入 RDT 输入序列（而非解码为位姿矩阵再输入），实现"世界模型冻结 + 轻量适配器 + 动作专家"的解耦式后训练，训练经济性好。
- **任务选择有针对性**：六个任务覆盖高速冲击、旋转对准、朝向保持、力控下切、持续接触、俯仰协调，明确超出抓放基准，能真正检验精细 SE(3) 控制能力。
- **辅助视觉预测正则**：以 λ=0.01 的小权重辅助帧预测帮助学习场景动力学，同时不干扰位姿主目标。

## 8. 不足与局限

- **作者自述局限**：受人力与算力约束，仅验证单一机器人本体（UR10e + 二指夹爪），**未涉及多指灵巧手**；**大规模参数下的扩展行为未探索**。
- **算力信息缺失**：未报告自身预训练/微调的 GPU 型号、数量与时长，难以评估其"大幅降低训练开销"论断的量化依据。
- **评测覆盖面窄**：消融与规模实验仅两个任务；仅 50 次试验/任务的统计量未报告置信区间或方差。
- **基线公平性风险**：基线在 100 条演示条件下可能数据不足（FastWAM 出现 0% 成功率），且参数量不对等，可能夸大相对提升幅度。
- **数据偏差风险**：预训练数据高度长尾（肥皂仅 2 条、胶水 9 条），头部工具（勺、刀）主导监督；数据处理丢弃率高达 27%，且类别间差异大（螺丝刀 37.9%），说明位姿跟踪对对称/快速旋转物体不可靠，这类工具的先验质量可能系统性偏弱。
- **缺少同类方法对比**：FUNCTO、SPOT 等物体中心方法未在统一协议下比较，削弱了"优于物体中心相关工作"的说服力。
- **应用限制**：仍依赖人工校验环节，并非完全无监督；性能依赖 FoundationPose 的跟踪精度，在遮挡、动态背景与对称物体上存在天花板；未验证跨场景/跨房间的泛化。
- **失败模式未量化**：论文承认 P2P-T 存在抓取不稳定的问题，但未给出失败案例的定量归因分析。
