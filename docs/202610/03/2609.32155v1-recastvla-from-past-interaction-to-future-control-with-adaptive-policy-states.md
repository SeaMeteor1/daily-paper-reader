## 摘要
顺序操作要求机器人跟踪已经发生的事情，即使当前场景不再体现这些信息。具有显式历史表示的策略可将过往交互作为当前决策的上下文。我们探究动作生成本身如何形成用于后续控制的持久状态。基于动作侧测试时训练，RecastVLA 在流匹配视觉-语言-动作策略中维护一个自适应策略状态。该状态由共享快速权重表示，并在整个动作生成过程中保持固定。深度特定接口读取同一状态，而跨深度和流评估的特征共同为下一次策略调用定义一个更新。后续动作损失通过对早期状态转移进行微分来训练初始化、接口和更新规则。在部署时，更新使用策略自身的动作生成特征，无需专家动作标签。在 LIBERO、RoboTwin、RoboDojo 和十二个真实机器人任务上，RecastVLA 相较未经过测试时训练的匹配策略提升了平均成功率，包括在 RoboTwin Clean-to-Clean 上提升 10.68 个百分点。在受控 RoboTwin 对比中，保留状态可提升成功率，且共享设计比独立训练的层局部 TTT 高出 2.58 个百分点。

## Abstract
Sequential manipulation requires a robot to track what has already happened, even when the current scene no longer reveals it. Policies with explicit history representations make past interactions available as context for current decisions. We ask how action generation itself can form a persistent state for subsequent control. Building on action-side test-time training, RecastVLA maintains an adaptive policy state within a flow-matching vision-language-action policy. The state is represented by shared fast weights and remains fixed throughout action generation. Depth-specific interfaces read the same state, while features across depths and flow evaluations jointly define one update for the next policy call. Subsequent action losses train the initialization, interfaces, and update rule by differentiating through earlier state transitions. At deployment, updates use the policy's own action-generation features without expert action labels. Across LIBERO, RoboTwin, RoboDojo, and twelve real-robot tasks, RecastVLA improves mean success over a matched policy trained without test-time training, including 10.68 percentage points on RoboTwin Clean-to-Clean. In controlled RoboTwin comparisons, retaining state improves success, and the shared design exceeds independently trained layer-local TTT by 2.58 points.

## 1. 核心问题与整体含义

- **研究动机**：顺序操作中，机器人必须记住已经发生过的交互，即使当前画面无法体现。例如按钮按下前后外观几乎相同，但下一步动作取决于“是否已经按过”、按了几次、顺序如何。遮挡、部分完成指令等也要求把当前观察与更早事件联系起来。
- **问题定位**：作者将“继续任务所需的信息”称为**执行记忆**。已有工作多通过检索观察、压缩上下文或循环表示来决定“哪些历史信息可用”；本文进一步追问：**动作生成过程本身能否形成用于后续控制的持久状态**。
- **整体含义**：RecastVLA 把动作生成内部的流匹配特征转化为跨策略调用的自适应状态，使策略在不依赖专家动作标签的部署阶段，仍能通过自身生成特征更新状态。这属于动作侧测试时训练与 VLA 策略结合的探索。

## 2. 方法论

- **核心思想**：
  - 在流匹配视觉-语言-动作策略中维护一个**自适应策略状态**，用共享快速权重表示。
  - 状态由一个小型两层 MLP 承载，在整个动作生成调用内保持固定；下一次策略调用前更新一次。
  - 不同网络深度通过各自的接口读取同一状态；所有深度和流评估的特征共同形成一次联合更新。
  - 后续动作损失通过状态转移反向传播，训练状态初始化、读取接口和更新规则。
  - 部署时只更新快速权重，不更新慢参数，且不需要专家动作标签。

- **关键技术细节**：
  - 策略调用形式可概括为：读取当前状态 \(W_t\)，生成动作块并收集内部特征 \(Z_t\)；随后 \(W_{t+1}=U_\psi(W_t,Z_t)\)。同一调用内所有动作计算都使用固定的 \(W_t\)。
  - 动作专家采用交叉注意力、自注意力与潜在槽位交替结构。实验中使用 DiT-B 专家，16 个交叉/自注意力块，宽度 768，设置 \(J=8\) 个访问点，32 个槽位，快速 MLP 为 256→512→256，GELU 激活。
  - **状态读取**：在交叉注意力后的槽特征上加入门控残差。每个深度 \(j\) 有投影 \(P^Q_j\)、\(P^O_j\) 和标量门 \(\gamma_j\)，让不同深度在各自特征坐标中查询同一状态。
  - **状态写入**：在后续自注意力块后的槽特征上构造学习到的键和值，并用 stop-gradient 阻断写入分支对源特征的梯度。写入目标为加权最小二乘：对不同流评估 \(c\)、不同深度 \(j\) 的键值拟合误差加权求和；权重包括流时间门 \(g_\psi(\tau)\) 和访问点权重 \(\alpha_j\)。
  - **状态更新**：在传入状态处对写入损失取单步梯度，\(W_{t+1}=W_t-\eta\nabla_W L^{\text{write}}_t(W)\)，步长由学习标量 \(\rho\) 控制，\(\eta=\eta_0\exp(\rho)\)，\(\eta_0=0.1\)。
  - **训练流程**：从同一演示中采样长度 \(T=4\) 的有序窗口，每帧从 \(W_0\) 开始；对每帧采样 \(R\) 个独立噪声和时间，构造流匹配输入与速度目标；速度预测器读取同一 \(W_t\)；除最后一帧外，用停止梯度的特征更新状态并保留元梯度；最终用后续动作损失更新慢参数、接口和更新规则。
  - **部署流程**：每次调用从高斯噪声出发，用 \(K=4\) 次 Euler 评估积分速度场，所有评估共享当前 \(W_t\)；生成后仅用策略自身动作生成特征更新状态。部署不需要跨调用保留计算图，也不需要专家动作标签。
