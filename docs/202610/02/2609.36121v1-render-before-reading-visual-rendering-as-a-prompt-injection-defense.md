## 摘要
大语言模型易受提示注入攻击，第三方对抗内容可劫持模型行为。本文研究对抗数据的输入模态所起的作用，并发现一种系统性不对称：多模态LLM在对抗指令以文本形式出现时，比同一指令通过非文本通道（例如图像）传递时更可能遵循该指令。我们假设这种模态差距源于以文本为中心的指令微调，它教导模型服从文本指令，而将其他模态主要视为需要解析或描述的内容。然后，我们展示如何将这一差距转化为免训练防御：在不可信载荷到达模型之前，将其全部渲染为排版图像（或音频）。在十个模型和两个提示注入基准（DirectInject 和 AgentDojo）上，我们表明我们的防御方法 Pictionary 能持续降低攻击成功率，即使面对最强的自适应攻击和人工红队测试者也是如此，同时基本保持良性效用。我们进一步表明，在图像渲染的指令上进行良性微调会侵蚀这种模态差距，并将其追溯到以文本为中心的指令微调分布。

## Abstract
Large language models are vulnerable to prompt injection attacks, where third-party adversarial content can hijack the model's behavior. In this paper, we study the role played by the adversarial data's input modality, and identify a systematic asymmetry: multimodal LLMs are more likely to follow adversarial instruction when they appear as text than when the same instruction is delivered through a non-textual channel (e.g., as an image). We hypothesize that this modality gap arises from text-centric instruction tuning, which teaches models to obey textual instructions while treating other modalities mainly as content to parse or describe. We then demonstrate how this gap can be turned into a training-free defense, by rendering all untrusted payloads as typographic images (or audio) before they reach the model. Across ten models and two prompt injection benchmarks (DirectInject and AgentDojo) we show that our defense Pictionary consistently reduces attack success rates even against the strongest adaptive attacks and human red teamers, while largely preserving benign utility. We further show that benign fine-tuning on image-rendered instructions erodes the modality gap, tracing it to the text-centric instruction-tuning distribution.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心安全问题**：提示注入（Prompt Injection）是已部署语言模型应用的定义性安全问题。模型作为智能体需要读取网页、文档、工具输出并据此行动，但这也意味着第三方内容可以携带隐藏指令，将模型重定向至攻击者的目标（Perez & Ribeiro, 2022; Greshake et al., 2023）。
- **现有认知的盲点**：以往研究将多模态视为**额外的弱点**——攻击者可在图像通道中植入恶意内容，利用该模态对齐较弱的特点实施越狱（Liu et al., 2024; Gong et al., 2025; Ma et al., 2024），嵌入网页、截图中的排版指令可劫持多模态模型与计算机使用智能体（Li et al., 2025; Cao et al., 2025）。
- **本文的反转视角**：作者提出多模态性同样是**防御机会**。核心观察是——多模态 LLM 的指令遵循能力几乎完全通过**文本**习得：预训练产生流畅的文本生成能力，后训练（指令微调）在文本指令-响应对上加入服从性；而图像在训练中作为"待描述或查询的内容"出现，语音作为"待转写的内容"出现，而非"需要服从的命令通道"。
- **模态鸿沟（Modality Gap）**：由此产生系统性不对称——同一对抗指令，以文本形式呈现时被遵循的概率是以图像形式呈现时的 2× 到 300×（图 2）。模型仍能完美读取图像内容，只是不再把它当作命令。
- **整体含义**：该不对称可将不可信内容移出文本通道，形成**通道级指令层级（channel-level instruction hierarchy）**，无需辅助分类器、无需修改模型权重、无需改变宿主应用。

## 2. 方法论：Pictionary 防御

- **核心思想**：将**所有不可信文本内容**（用户上传文档、工具返回结果）在到达模型前渲染为**排版图像**（黑字白底），不进行过滤、改写、摘要或重写。可信指令（系统提示、用户查询、工具 schema）仍以文本形式传递，保留完整命令权威。
- **威胁模型**：
  - 智能体 = VLM M + 工具库 T；多轮循环中产生工具调用或用户消息。
  - 不可信通道有两类：①用户提供文档（直接注入）；②来自开放世界的工具输出（间接注入）。
  - 攻击者能力：控制单一不可信通道的全部内容；不控制系统提示或用户提示（部分情况知道 p）；无白盒访问、不知工具库与渲染方法，但可做任意黑盒查询。
  - **图像原生攻击不在防御范围内**。
- **关键技术细节**：
  - **直接注入**：用户文档作为图像附件传递。
  - **间接注入**：工具返回的文本内容被替换为图像块（`{"type": "image", "source": <render(raw text)>}`），因 harness 无法判断哪个工具返回被攻击者控制，故**保守地渲染每一个工具输出**。
  - **默认渲染器**：DejaVu Sans 黑字、白色 900 像素宽 RGB 画布、30 像素内边距、30 像素行距、约 65 字符换行；最小高度 200 像素；base64 编码传递。
  - **长输出分页**：Anthropic API 拒绝超过 8000 像素的图像（约 260 行），故采用 1024×1024 像素分页、每页 40 行，多页作为同一消息内多个图像块传递；字号扫描选定 16pt。
  - **代码渲染**：等宽字体、固定列换行、保留缩进、添加行号与页眉（如 "page 1/3 · lines 1--44 of 104"），用于 SWE-bench。
  - **替代视觉风格**：搜索页风格、黑板风格可进一步降低 ASR（6–8 个百分点）。
  - **音频泛化**：用 TTS 将不可信文本合成为 WAV 音频，验证防御来自"模态切换"而非视觉特有属性。
- **算法流程（文字说明）**：
  1. 接收用户任务与系统提示（保持文本）；
  2. 识别不可信内容来源（用户文档 / 全部工具输出）；
  3. 调用渲染器将不可信文本转为排版图像（必要时分页）；
  4. 以图像块替换对应消息中的文本载荷；
  5. 模型读取图像内容（OCR 恢复语义）用于下游推理，但注入指令经由模型未被训练服从的通道到达，权威性下降。

## 6. 主要结论与发现

- **模态不对称确实存在**：单模态下文本与图像指令遵循率均接近上限；冲突时文本指令被遵循的概率是图像的 2×（Claude Haiku 4.5）到 300×（Kimi-K2.6）。
- **Pictionary 有效**：静态攻击下图像渲染从不增加 ASR，几乎每个模型-基准组合都降低 ASR。DirectInject 上 GPT-5.4 mini 从 75.0% 降至 0.0%；AgentDojo 上 Gemini 3.1 Pro 从 83.1% 降至 41.5%。
- **自适应攻击下仍具鲁棒性**：并集评估中，Claude Haiku 4.5 从 97.6% 降至 9.5%，GPT-5.4 mini 从 83.3% 降至 31.0%，Kimi-K2.6 从 77.8% 降至 40.0%；但 Gemini 3.1 Flash Lite 几乎完全沦陷（100.0% → 97.8%），说明**防御效果依赖模型**。
- **优于现有防御**：DirectInject 上 Pictionary 达 3.6% ASR / 99–100% 效用，显著优于 PromptLocate（≈未防御）、DataSentinel（58.9–69.6%）、DataFilter（12.5–32.1%）。
- **效用基本保持**：τ2-Bench 任务成功率在文本基线 0.9–2.1 个百分点内；SWE-bench 上 Kimi-K2.6 不变，Claude Haiku 4.5 与 GPT-5.4 mini 下降 9–10 个百分点（因代码编辑需字符级精确）。
- **音频同样有效**：GPT-Audio-Mini ASR 从 27.3% 降至 1.3%，Qwen3.5-Omni-Plus 从 50.5% 降至 15.8%，证明防御来自模态切换本身。
- **机理归因**：指令微调使文本 ASR 增幅远大于图像 ASR（如 Qwen3.5-9B：+66.6 vs +4.8 点）；在完全良性的图像渲染指令上微调，会使图像 ASR 上升 13–19 个百分点，证明模态鸿沟是当前训练分布的真实产物，而非模态切换的偶然。

## 7. 优点

- **视角新颖且反直觉**：将"多模态是弱点"反转为"多模态是防御资源"，从模型训练方式出发定位漏洞根源，而非机械套用其他安全领域的机制（如 SQL 注入防御的定界符、面向人类的"三明治"提醒）。
- **免训练、模型无关、即插即用**：仅需在 agent harness 与模型之间插入一个渲染器，无需权重修改、无需辅助分类器，可立即部署于闭源与开源模型。
- **通道级指令层级**：由输入模态本身强制分离，而非依赖攻击者可模仿的定界符或标记，比文本级指令层级更难绕过。
- **评估严谨**：同时采用固定模板、RL 后缀优化、LLM 自动红队、144 小时人工红队，并用并集最坏情况聚合；使用基准官方严格判据，附加宽松判据诊断。
- **兼顾安全与效用**：不仅在单一文档阅读理解上评估，还在 τ2-Bench 多轮客服与 SWE-bench 代码修复等复杂智能体任务上压力测试。
- **提供机理解释**：通过基座 vs 指令微调对比、良性图像指令微调干预，将防御有效性追溯到训练分布，而非仅停留在经验现象。
- **实用工程细节丰富**：给出分页、字号选择、代码渲染、成本测量、OCR 保真度诊断等可直接复用的实现经验。

## 8. 不足与局限

- **依赖模型 OCR 能力**：若模型视觉文本识别能力弱，渲染会连同良性内容一起抑制；对标识符、代码、结构化数据等依赖精确字符序列的内容，错误可能表现为自信的错误答案而非显式失败。
- **服务成本增加**：主流 API 按固定 token 数计费图像，通常比其替代的文本高一个数量级；实测整通道渲染成本增加 25.6%–55.1%（虽因系统提示与工具 schema 占主导而未翻倍）。作者援引光学上下文压缩研究（可压缩至 1/10 视觉 token）作为缓解方向，但未在本工作中验证。
- **无法防御图像原生攻击**：若不可信内容本身已是图像（截图、扫描 PDF、GUI 智能体视口），注入已处于防御本应放置的位置，Pictionary 不提供保护。
- **防御效果模型依赖强**：Gemini 3.1 Flash Lite 在自适应攻击下几乎无改善（97.8% ASR）；Gemini 3.1 Pro、Grok 4.3、Qwen3.6-plus 的图像 ASR 仍较高（静态下达 41.5%–64.3%）。
- **效用存在模型依赖代价**：SWE-bench 上两个模型下降 9–10 个百分点；AgentDojo 效用变化范围 −14.4 到 +9.7 个百分点；转写错误导致 patch anchor 失败率显著上升（Claude Haiku 4.5 从 0.8% 升至 37.4%）。
- **机理结论的相关性限制**：基座 vs 指令微调的对比是相关性证据（发布检查点的后训练管线不同），部分基座模型已显示较大通道差距，因此支持"放大"而非"指令微调是必要原因"。
- **防御对比的公平性有限**：表 3 仅用 3 个指定 ART 模板，而非针对每种防御独立优化的自适应攻击；作者亦承认足够强的自适应攻击者可能绕过几乎所有现有防御（Nasr et al., 2025）。
- **红队与音频实验的定位**：音频实验为概念验证，作者明确不推荐作为部署方案（语音合成带来延迟、成本、长度约束）；红队样本量与任务子集有限。
- **未来方向**：作者建议将 Pictionary 与现有防御叠加使用，并探索更强自适应攻击下的鲁棒性。
