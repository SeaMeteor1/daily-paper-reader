## 摘要
视觉-语言-动作（VLA）模型具备较强的局部控制与指令跟随能力，但在需要持久记忆和规划的长时程任务中往往表现不佳。任务执行框架通过保留任务历史并跟踪各执行阶段的进展，为智能体推理提供持久上下文。为将这两种互补能力结合起来，我们提出 AdaHVLA，一种自适应执行框架，它通过机器人经验改进基于代码的协调策略，从而更好地使智能体推理和记忆与 VLA 执行对齐。其解耦的多智能体自适应过程将证据分析、执行框架修订和行为评估分离到不同的工作上下文中，利用可检验的协调假设来指导修订，并通过后续 rollout 评估其预期效果。一个有状态的修订图连接执行证据、假设、修订和观察到的效果，保留备选执行框架和自适应记忆，以指导重复尝试中的改进以及跨任务和环境的持续自适应。在仿真中，AdaHVLA 将 NaVILA-LH 上的平均测试成功率从 22.5% 提高到高达 57.5%，并在三个 VLA 骨干模型上将操作测试成功率相较初始执行框架提升最多 30.8 个百分点。真实世界部署进一步展示了自适应策略如何支持跨任务阶段的稳定执行。

## Abstract
Vision-language-action (VLA) models offer strong local control and instruction following but often struggle with long-horizon tasks requiring persistent memory and planning. Task harnesses provide persistent context for agent reasoning by retaining task history and tracking progress across execution stages. To bring these complementary capabilities together, we introduce AdaHVLA, an adaptive harness that refines code-based coordination policies through robot experience to better align agent reasoning and memory with VLA execution. Its decoupled multiagent adaptation process separates evidence analysis, harness revision, and behavioral assessment into distinct working contexts, using testable coordination hypotheses to guide revisions and subsequent rollouts to assess their predicted effects. A stateful revision graph links execution evidence, hypotheses, revisions, and observed effects, preserving alternative harnesses and adaptation memory to guide refinement across repeated attempts and continued adaptation across tasks and environments. In simulation, AdaHVLA raises mean test success on NaVILA-LH from 22.5\% to as high as 57.5\% and improves manipulation test success across three VLA backbones by up to 30.8 percentage points over the initial harness. Real-world deployment further illustrates how the adapted policies support stable execution across task stages.

## 1. 核心问题与整体含义

- **研究动机**：VLA 模型在局部动作控制与指令跟随上表现较强，但在需要持久记忆、进度跟踪和跨阶段规划的长时程任务中仍容易失败。单个局部动作合理，并不保证整体任务持续推进。
- **背景矛盾**：任务执行框架（harness）可通过保留任务历史、维护执行状态、跟踪子目标进度，为智能体推理提供持久上下文；VLA 则负责局部视觉-动作执行。但两者如何有效协同，尤其是“何时推进阶段、保留哪些历史、何时恢复、何时判定完成”等协调规则，通常依赖人工固定设计，难以适应不同布局、执行器响应和任务状态。
- **整体含义**：论文提出 **AdaHVLA**，将智能体推理与 VLA 执行之间的代码式协调策略作为可自适应对象。它不修改 VLA 参数，而是通过机器人执行经验迭代改进协调代码，使推理、记忆与局部执行更好对齐，从而提升长时程导航与操作任务成功率。

## 2. 方法论

### 2.1 核心思想

- 将 agent reasoning 与 VLA execution 之间的接口实现为**可编辑、可执行的协调策略代码**，由 harness 决定：
  - 向 VLA 传递什么指令与观测上下文；
  - 保留哪些历史与视觉缓冲；
  - 何时提交任务进度、推进子目标；
  - 何时启动、持续和结束纠正/恢复；
  - 何时判定任务完成。
- 执行阶段与适配阶段分离：
  - **执行阶段**：固定某个 harness 源码版本，在线进行推理和运行时状态更新；
  - **适配阶段**：在多次 rollout 之间，通过多智能体流程分析证据、提出假设、修改代码并评估行为效果。

### 2.2 问题形式化

- 任务实例记为 \(\xi=(x,E,s_0)\)，其中 \(x\) 为指令，\(E\) 为环境，\(s_0\) 为初始机器人/场景状态。
- 在决策边界 \(t\)，harness \(H_c\) 根据交互历史 \(H_t=(x,o_{\le t},a_{<t})\) 和运行时状态 \(m_t\)，产生：
  - VLA 指令 \(q_t\)；
  - 观测上下文 \(\kappa_t\)；
  - 更新后的状态 \(m_{t+1}\)；
  - 终止标志 \(z_t\in\{0,1\}\)。
- VLA 策略 \(\pi_\theta\) 根据 \(q_t,\kappa_t\) 产生动作 \(a_t\)。
- 适配目标是在已有修订集合 \(C\) 中寻找使期望任务成功指标 \(R(\tau;\xi)\in\{0,1\}\) 最大的协调策略 \(c\)，同时保持机器人配置和 VLA 参数不变。

### 2.3 多智能体适配流程

- **证据分析**：将相机观测、日志、轨迹段按 request ID 对齐，并关联到 harness 源码版本；分析 agent 区分“观察到的事件”与“解释”。
- **可检验协调假设**：每个假设包含：
  - 疑似机制；
  - 支持证据；
  - 预期行为效果；
  - 可观测指标。
- **harness 修订**：修订 agent 检查源码和相关尝试，提出代码补丁 \(\Delta\)，形成候选 \(c'=c\oplus\Delta\)；在 rollout 前记录假设与预测效果，并进行源码/接口审查以确认可执行性。
- **行为评估与归因门**：
  - 用新 rollout 比较父代与修订版在相同任务实例上的表现；
  - 评估目标效果、整体行为和最终成功，但**不单独以任务成功归因**；
  - 设 \(\hat u\) 表示修改机制是否被触发，\(\hat v\) 表示轨迹是否在触发前已分歧；
  - 归因门为 \(\chi=1\{\hat u=1\land \hat v=0\}\)；
  - 只有 \(\chi=1\) 时才更新假设支持：目标改善增强支持，未改善或退化则削弱支持；否则保留支持，但所有结果仍可用于后续细化。
  - 单次成功不视为可重复，需要更多 rollout 验证。

### 2.4 修订图与适配记忆

- 维护**有状态修订图** \(G\)，连接：
  - 代码版本；
  - 假设；
  - rollout 证据；
  - 行为评估结果。
- 任务内探索：
  - 候选按任务成功优先，其次按目标行为和整体行为效果排序；
  - 设最大活跃候选叶数 \(W\) 和当前任务最大修订深度 \(D\)；
  - 若候选有目标改善或暴露新失败，且预算允许，则可继续扩展；
  - 不活跃候选及其证据仍保留，便于恢复替代路线。
- 跨任务记忆：
  - 将相关 agent 上下文压缩为长期适配记忆，保留协调问题、假设、尝试、观察效果及评估条件；
  - 选定 harness 和保留上下文跨任务持久化；
  - 运行时状态和局部探索深度重置；
  - 最终 harness 仅用适配证据选择，测试时源码固定，在线推理和运行时状态更新继续。
