## 摘要
动作表示在离散标记的视觉-语言-动作（VLA）学习中起着核心作用，但仍未得到充分研究。在传统位姿增量表示下，动作标记对执行速度和数据集特定的归一化敏感，可能掩盖不同演示和数据集之间共享的几何结构。我们提出方向-尺度分解（DSD），一种在标记化之前将平移和旋转增量分解为方向和尺度分量的动作表示。DSD 将运动方向分离出来，同时将幅度保留在单独的尺度通道中。我们在仿真和真实世界操作任务中，在单数据集和混合数据集训练下，使用均匀分箱（BIN）和 BEAST（一种基于 B 样条的标记器）评估 DSD。在 LIBERO 上，DSD 在两种标记器下均提高了平均成功率。在 SimplerEnv 上，混合数据集训练下，DSD-BIN 的总体成功率比 BIN 高出 10.3 个百分点。真实机器人实验进一步显示，在有和无机器人预训练的情况下均有提升。这些结果支持 DSD 作为离散标记 VLA 模型的有效动作表示，并表明其有潜力缓解在大型且多样化的数据集混合上训练时的性能下降。我们的项目页面及额外资源见 https://vla-dsd.github.io/

## Abstract
Action representation plays a central role in discrete-token vision-language-action (VLA) learning but remains underexamined. Under conventional pose-increment representations, action tokens are sensitive to execution speed and dataset-specific normalization, potentially obscuring geometric structure shared across demonstrations and datasets. We introduce Direction-Scale Decomposition (DSD), an action representation that decomposes translation and rotation increments into direction and scale components before tokenization. DSD isolates motion direction while retaining magnitudes in separate scale channels. We evaluate DSD with uniform binning (BIN) and BEAST, a B-spline-based tokenizer, in simulation and real-world manipulation under both single-dataset and mixed-dataset training. On LIBERO, DSD improves average success rates with both tokenizers. On SimplerEnv, DSD-BIN outperforms BIN by 10.3 percentage points in overall success rate under mixed-dataset training. Real-robot experiments further show gains both with and without robotics pretraining. These results support DSD as an effective action representation for discrete-token VLA models and suggest its potential to mitigate performance degradation when training on large and diverse dataset mixtures. Our project page with additional resources is available at https://vla-dsd.github.io/

# 论文总结：Direction-Scale Decomposition in Action Representation（DSD）

## 1. 核心问题与整体含义

- **背景**：Vision-Language-Action（VLA）模型（如 RT-2、OpenVLA、π0/π0.5）正成为通用机器人策略的主流范式。其中一支路线把动作预测建模为**离散 token 的自回归生成**，以对齐 LLM 解码架构与交叉熵目标，避免额外动作头干扰预训练的视觉-语言能力。
- **核心问题**：动作表示（action representation）是离散 token VLA 的关键环节，却长期被当作预处理步骤而缺乏研究。论文指出传统 **raw pose-increment（∆EEF，7 维：3 平移 + 3 旋转 + 1 夹爪）** 表示存在三个问题：
  1. **Problem 1（速度敏感）**：raw 表示与演示速度耦合，空间相似但速度不同的轨迹会映射到差异很大的 token 序列，使任务相关的几何模式被速度变化掩盖。
  2. **Problem 2（归一化不一致）**：数据集特定的逐坐标归一化会把**同一个物理动作映射到不同 token**，妨碍跨数据集共享模式复用（例如 RT-1-X 混合训练反而不如单数据集 RT-1）。
  3. **Problem 3（迁移中的方向失真）**：训练与部署归一化统计不一致时，反归一化可能改变各轴相对尺度甚至符号，**使原本正确的预测变成错误或不安全的命令**。
- **研究动机与核心提问**：如何设计一种动作表示，使其在速度变化与数据集归一化差异下仍能**暴露跨演示共享的几何结构**？论文受词嵌入中“方向 + 幅度”互补角色启发，提出 **Direction–Scale Decomposition（DSD）**。

## 2. 方法论

- **核心思想**：在归一化和 tokenization **之前**，将平移增量分解为“方向 + 幅度”，将相对旋转分解为“轴 + 角度”，从而把与执行速度相关的幅度变化**隔离到独立的尺度通道**，而方向分量使用**固定、与数据集无关的边界**（[-1, 1]）。
- **表示形式**（每个手臂 9 维）：
  - 2 个尺度：平移幅度 `s_pos`、旋转角 `s_ori`；
  - 6 个方向分量：平移单位向量 `n_pos ∈ S²`（3 维）、旋转单位轴 `n_ori ∈ S²`（3 维）；
  - 1 个夹爪命令 `g`（保持不变）。
  - 形式化为 `ã_t = (s_pos, s_ori, g_t, n_pos^T, n_ori^T)^T`，动作空间约束 `A_DSD ⊆ R² × B × S² × S²`。
- **关键转换公式（raw → DSD）**：
  - 平移：`p_t = (∆x, ∆y, ∆z)^T`；`s_pos = ‖p_t‖₂`；`n_pos = p_t / s_pos`（当 `s_pos = 0` 时取固定默认方向 `e3`，不影响实际动作）。
  - 旋转：由 `R_t = Rz(∆yaw)Ry(∆pitch)Rx(∆roll) = exp([ω_t]_×)` 求轴角向量 `ω_t`（`‖ω_t‖₂ ≤ π`）；`s_ori = ‖ω_t‖₂`，`n_ori = ω_t / s_ori`；近 0 与近 π 时使用数值稳定转换与固定符号约定。
- **逆转换（DSD → raw）**：`p_t = s_pos · n_pos`，`R_t = exp(s_ori · [n_ori]_×)`，再转回 roll-pitch-yaw 并保留 `g_t`，保证物理运动信息无损。
- **归一化与 tokenization**：
  - 仅对**尺度通道**（平移幅度、旋转角）做 [−1, 1] 归一化；方向分量天然位于 [−1, 1]，无需数据集特定归一化。
  - 单数据集训练用共享参数，微调时用目标特定参数。
  - DSD 是**连续表示**，可与不同 tokenizer 组合：`DSD-BIN`（256 等宽均匀分箱）与 `DSD-BEAST`（B 样条控制点量化，20 步 chunk 用 10 个基函数）。
- **稳定性技巧**：当尺度接近 0 时方向/轴对噪声敏感，论文对尺度低于阈值 τ 的步**降权方向 token 损失**，保留最小权重 `w_min = 0.1`，避免引入不可靠监督。

## 3. 实验设计

- **基础设置**：所有仓内策略基于 **Florence-2-Base（0.23B 参数）**，预测 **20 步动作 chunk**，并行解码（双向自注意力、每位置一个离散分布），每维 **256 个 bin**；DaViT 视觉骨干 + BART 编解码语言骨干，端到端微调。
- **四类实验场景**：
  1. **光点跟踪（Light-tracking）**：固定相机追踪末端光点，脚本控制器采集 **50 条演示（5 种速度 × 10 次重复）**，用弧长重采样后的点均值定义参考轨迹；每个方法 **10 次 rollout**，指标为端点约束的单调 DTW 距离与归一化 Score（0.05 截断）。
  2. **LIBERO 仿真**：Spatial / Object / Goal / Long 四个套件，**每套件 500 次试验**。
  3. **SimplerEnv**：在 bridgeV2 单数据集或 **5 数据集 OXE 混合**（bridgeV2、Berkeley-autolab-UR5、stanford-hydra、taco-play、viola，涵盖 WidowX/UR5/Franka 三种本体）上微调，Bridge 任务 **4 个任务 × 75 次配对试验**。
  4. **真实机器人**：4 个任务（方块堆叠、布料折叠、纸巾清扫、勺子替换），**每方法每任务 30 次试验**，受控初始条件。
- **对比方法**：
  - 仓内对比：**BIN、DSD-BIN、BEAST、DSD-BEAST**；真实机器人额外含预训练变体 **BIN-P、DSD-BIN-P**（由 SimplerEnv 的 mix 检查点微调而来）。
  - 外部基线：LIBERO 对比 π0、π0.5、π-FAST；SimplerEnv 对比 RT-1-X、Octo-base/small、OpenVLA、π-FAST-ft、π0-ft、π0.5-ft、SpatialVLA。
- **评估问题**：A1（DSD vs raw 表示）、A2（与不同 tokenizer 的兼容性）、A3（异构混合训练影响）、A4（微调表示匹配的预训练检查点）。

## 6. 主要结论与发现

- **光点跟踪**：DSD-BIN 相比 BIN 平均 DTW 降低 **20.5%**（1.588 vs 1.997 ×10⁻²），DSD-BEAST 相比 BEAST 降低 **10.1%**；平均 Score 分别提升 +9.23（BIN）和 +11.23（BEAST）分。
- **LIBERO**：DSD-BIN 平均成功率 **92.3%**（vs BIN 88.5%，+3.8 pp）；DSD-BEAST 平均 **91.9%**（vs BEAST 88.0%，+3.9 pp），并在 Long 套件取得最高 **88.6%**。无机器人预训练的 DSD-BIN 已超过预训练 π-FAST（85.6%），并追平 π0（92.3%）。
- **SimplerEnv**：单数据集下 DSD-BIN 比 BIN 高 0.7 pp；**混合训练下 DSD-BIN 比 BIN 高 10.3 pp**（43.3% vs 33.0%，95% CI 5.0–15.7，Holm 校正 McNemar p=0.003）。加入 4 个数据集使 DSD-BIN 提升 +2.7 pp，而 BIN 反而下降 −7.0 pp，说明 **DSD 能从异构数据中获益，BIN 则退化**。DSD-BIN-mix 的 43.3% 是所有对比方法中最高（含大规模预训练基线）。
- **真实机器人**：DSD-BIN 在全部 4 个任务上优于 BIN（Cube +23.3、Cloth +6.7、Sweep +13.3、Spoon +10.0 pp），平均 **+13.3 pp**（60.0% → 73.3%）；微调预训练检查点后 DSD-BIN-P 同样全面优于 BIN-P，平均 **+11.7 pp**（65.0% → 76.7%）。
- **总体结论**：DSD 是一种有效的离散 token VLA 动作表示，能提升平均成功率与路径保真度，并在微调表示匹配的预训练检查点后持续有效；有潜力缓解大规模异构数据混合训练的性能退化。

## 7. 优点

- **问题诊断清晰**：将 raw 动作表示的隐患明确拆为速度敏感、归一化不一致、方向失真三个可验证的问题，并用图示逐一说明，动机扎实。
- **方法简洁、无学习组件**：DSD 是纯解析变换，不引入额外量化器或可训练模块，避免了 VQ 类方法（如 VQ-BeT）分布外不可靠的问题，也便于即插即用。
- **tokenizer 无关性**：DSD 定义的是“喂给 tokenizer 的连续表示”，因此可同时兼容均匀分箱（BIN）与

BEAST（B 样条控制点量化），甚至未来其他 tokenizer；这种解耦使改进 tokenizer 与改进表示可以独立进行，降低了方法迭代的组合复杂度。

- **对归一化失配的鲁棒性有明确机制解释**：方向分量被约束在固定单位球面/固定边界内，尺度通道单独承载速度与幅度信息，因此训练与部署之间的统计差异不会通过反归一化放大为方向或符号的畸变，直接对应 Problem 3 的安全隐患。

- **可解释性与可诊断性**：分解后的每一维有明确物理含义（走了多远、朝哪个方向、转了多少度、绕哪根轴），便于可视化失败案例、定位是“方向错”还是“尺度错”，比 raw 增量更利于调试。

- **与自回归离散解码范式天然兼容**：不改变 token 数量、不增加动作头、不破坏视觉-语言预训练接口，因此可以直接替换现有离散 token VLA 的动作预处理管线，迁移成本低。

- **实验对比设计较严谨**：仓内方法共享同一骨干、同一 chunk 长度、同一 bin 数，仅改变动作表示或 tokenizer；SimplerEnv 采用配对试验、任务分层 bootstrap 与 Holm 校正，减少了“表示改进”被其他因素混淆的可能。

## 8. 局限与不足

- **分解组件的贡献未被拆解**：论文整体验证了“DSD vs raw”，但没有分别回答“只分解平移是否够”“只分解旋转是否够”“方向与尺度分开是否必要”。因此无法判断收益主要来自哪一部分，也无法为更轻量的变体提供依据。

- **尺度阈值的处理偏经验**：τ 与最小权重 `w_min = 0.1` 是人为设定，论文仅讨论其必要性，未给出敏感性曲线或自适应方案；在极慢速/高频抖动数据上，方向 token 的监督可靠性仍可能成为瓶颈。

- **混合数据实验规模有限**：仅覆盖 5 个 OXE 数据集、3 种本体，且论文自述受算力限制。虽然“DSD 获益、BIN 退化”的趋势明确，但能否推广到数十个异构数据集、以及退化是否随规模加剧，仍缺乏证据。

- **真实机器人本体单一**：真实实验仅在 Franka 上进行，未验证在不同运动学结构（如并联、双臂、移动底盘）或不同控制频率下的泛化性。

- **旋转表示的边界处理复杂度**：轴角在接近 0 与接近 π 时需要数值稳定转换与固定符号约定，虽然论文已处理，但相比 raw roll-pitch-yaw 增加了实现细节，可能影响复现的鲁棒性。

- **算力与训练细节披露不足**：未报告 GPU 型号/数量/时长与总算力，无法量化复现成本，也难判断方法在大规模预训练场景下的性价比。

- **外部基线对比存在变量不完全受控**：π0、π0.5、OpenVLA 等基线在数据、规模、训练配方上与仓内模型差异较大，跨方法比较只能作为参考，不能直接归因于动作表示。

## 9. 启示与可拓展方向

- **动作表示的“结构先验”值得系统研究**：DSD 表明，在离散 token VLA 中，把物理上互补的量（方向/幅度、轴/角）显式解耦，可以缓解数据异构与归一化差异带来的表示冲突，这一思路可能推广到力/力矩、关节速度等其他动作通道。

- **方向–幅度解耦可与学习式 tokenizer 结合**：当前 DSD 使用固定解析变换，未来可将方向分量交给学习式量化器、尺度分量保持解析归一化，兼顾表达能力与稳定性。

- **面向跨本体与跨数据集的动作表示标准化**：若方向分量真正与数据集无关，则有望成为跨本体共享动作词表的候选基础，从而改善大规模异构混合训练，这正是论文初步观察到的收益方向。

- **安全性与部署一致性**：Problem 3 揭示的反归一化失真在真实部署中可能造成危险动作，DSD 的固定边界特性提示：动作表示设计应把“部署时统计不匹配”作为一等约束，而非事后修补。

- **总体评价**：论文选题精准、动机清晰、方法轻量且即插即用，在仿真与真实机器人上均取得一致增益，尤其在异构混合训练与路径保真度上证据较强；主要短板在于消融粒度、数据规模与算力披露，但整体上为离散 token VLA 的动作表示研究提供了一个简洁而有效的基线方案。
