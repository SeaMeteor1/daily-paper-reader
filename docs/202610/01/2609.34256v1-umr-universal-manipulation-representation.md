## 摘要
通用具身操作依赖于一种统一的动作表征，它能够跨具身形态泛化并可便捷扩展。然而，现有策略依赖特定具身的动作空间，使得跨具身演示难以大规模利用，并限制了向新具身形态和空间变化的迁移。为此，我们提出通用操作表征（Universal Manipulation Representation, UMR），一种统一的动作表征，可实现从人类演示到异构机器人的零样本技能迁移。UMR 将操作分解为两个功能不同但几何关联的组件：与具身无关的世界流（World Flow），描述世界坐标系中与任务相关的物体运动；以及自我轨迹（Ego Trajectory），表示相对于当前位姿的末端执行器运动。我们将 UMR 实例化为 World--Ego Point VLA（WEPVLA），一个紧凑的 0.5B 参数策略，通过双流点动作适配器（dual-stream Point Action Adapter）和统一点动作专家（unified Point Action Expert）在统一几何动作空间中学习，并使用 SE(3) 共轭耦合这两个组件。为提高数据效率，我们为 UMR 补充了一种数据高效策略（Data-Efficient Strategy, DES），它通过阶段感知的点云编辑来多样化物体配置，同时保留演示中的接触几何。在仿真中，WEPVLA 在 LIBERO 上达到 97.5% 的平均成功率，在 10 项任务的 RLBench 基准上达到 85.7%。在真实世界实验中，一个仅在经 DES 增强的人类演示上训练得到的单一策略，可零样本迁移到多种部署条件。在每项任务仅收集约 10 分钟人类演示且没有机器人演示的情况下，它在六种评估设置中达到 91.7% 的平均成功率，而 HumanEgo 为 60.8%。代码和附加材料见 https://umr-wepvla.github.io/。

## Abstract
General-purpose embodied manipulation hinges on a unified action representation that generalizes across embodiments and scales readily. Yet existing policies rely on embodiment-specific action spaces, making cross-embodiment demonstrations difficult to leverage at scale and limiting transfer to new embodiments and spatial variations. To this end, we introduce Universal Manipulation Representation (UMR), a unified action representation that enables zero-shot skill transfer from human demonstrations to heterogeneous robots. UMR decomposes manipulation into two functionally distinct yet geometrically linked components: embodiment-agnostic World Flow, which describes task-relevant object motion in the world frame, and Ego Trajectory, which represents end-effector motion relative to the current pose. We instantiate UMR as World--Ego Point VLA (WEPVLA), a compact 0.5B-parameter policy that learns in the unified geometric action space through a dual-stream Point Action Adapter and a unified Point Action Expert, with an $SE(3)$ conjugation coupling the two components. To improve data efficiency, we complement UMR with a Data-Efficient Strategy (DES) that diversifies object configurations through stage-aware point-cloud editing while preserving demonstrated contact geometry. In simulation, WEPVLA achieves average success rates of 97.5\% on LIBERO and 85.7\% on the 10-task RLBench benchmark. In real-world experiments, a single policy trained on human demonstrations augmented by DES transfers zero-shot to diverse deployment conditions. With about 10 minutes of collected human demonstrations per task and no robot demonstrations, it achieves 91.7\% average success across six evaluation settings, compared with 60.8\% for HumanEgo. Code and additional materials are available at https://umr-wepvla.github.io/.

- **根本矛盾**：通用具身操作依赖"可跨本体泛化、可便捷扩展"的统一动作表征，但现有策略（OpenVLA、π0、SmolVLA 等）均在**特定具身的关节空间或末端执行器空间**中操作，不同数据集（Open X-Embodiment、DROID、RH20T 等）的控制语义与坐标系互不兼容。

- **已有路线的不足**：
  - 3D 感知策略（Pose-VLA、PointACT）增强了空间推理，但仍保留具身特定动作空间。
  - 第一人称/无机器人人类数据（UMI、HiFi-UMI、HUG、EgoWAM）改善了数据获取，但依赖专用接口、动作重定向或具身特定适配。

- **整体含义**：论文主张用**统一的几何动作空间**同时表示人类与异构机器人演示，使"数据扩展 → 跨任务、跨本体泛化"这一链条真正成立。

## 2. 方法论

### 2.1 核心思想：UMR 双分量分解

将同一次物理操作运动表示为两个功能不同但几何耦合的分量：

- **World Flow（世界流）**：世界坐标系 $W$ 下、与具身无关的任务相关物体运动，以紧凑的 SE(3) 变换轨迹表示（而非无约束稠密点流）。
- **Ego Trajectory（自我轨迹）**：相对当前末端执行器位姿 $E_t$ 的末端运动，去除全局坐标系与机器人基座依赖，直接对齐控制器接口。

### 2.2 关键推导

- 刚体接触假设：$^W T_{E,t} = {}^W T_{O,t} G$，其中 $G = {}^O T_E$ 在动作块内时不变。
- 时间相对变换定义为 $\Delta^A T_{B,t\to t+k} = {}^A T_{B,t+k}({}^A T_{B,t})^{-1}$。
- **抓取变换消去**：$\Delta^W T_{E,t\to t+k} = \Delta^W T_{O,t\to t+k}$，说明末端轨迹隐式编码物体运动，因此 World Flow 可跨不同抓取配置 $G_i$ 表示同一物体运动。
- **Ego 表示**：$\{{}^{E_t}T_{E,t+k}\}_{k=1}^{H} = \{(^W T_{E,t})^{-1}\,{}^W T_{E,t+k}\}$。
- **SE(3) 共轭关系**：$\Delta^{E_t}T_{E,t\to t+k} = (^W T_{E,t})^{-1}\,\Delta^W T_{O,t\to t+k}\,(^W T_{E,t})$，即两者是同一底层运动的两个坐标视角，可互相转换，从而实现"从一个演示者学到的可迁移任务运动 → 另一具身的可执行轨迹"。

### 2.3 WEPVLA 策略架构（0.5B 参数）

- **Motion-Aware Segmentation**：对每个点比较"共同运动假设"与"世界静止假设"的最近邻距离 $d^{mov}$、$d^{sta}$，用运动幅度相关权重 $w_{t,k}$ 做鲁棒时间聚合得 $g_{i,t}$；再融合 co-motion、approach、contact、tool-sweep 四类线索（概率式并集 $q_{i,t} = 1-\prod_r(1-e^r_{i,t})$）得到软前景目标，作为离线监督训练 LitePT 骨干 + 二分类分割头的 PriorSeg 学生网络，实现**单帧 XYZRGB 推理**。
- **Point Modeling**：Coarse-to-Fine 点编码器产出细粒度前景 token 与粗粒度背景 token；前景特征与流时间、chunk 位置感知的动作 token 在 **Point Action Adapter** 中经双向自注意力融合；双流动作/场景 token 与冻结 VLM 的图像、语言 token 一起送入共享 **Point Action Expert**。
- **Coupled Flow Matching**：以 $z^W = \Phi_{C_t}(z^E)$（$C_t = {}^W T_{E,t}$）保证两流先验对应同一物理运动；插值 $x^s_\tau = (1-\tau)z^s + \tau a^s$，目标速度 $u^s_\tau = a^s - z^s$；将两流姿态对齐到共同世界运动表示 $G^E_\tau = C_t B_\tau C_t^{-1}$、$G^W_\tau = W_\tau C_t^{-1}$ 以条件化去噪。
- **总损失**：$L = L_{E\text{-}FM} + \lambda_W L_{W\text{-}FM} + \lambda_{seg} L_{PriorSeg}$。
- **推理**：两流联合去噪，**仅执行 Ego 轨迹**，无需单独的"世界运动→机器人动作"转换阶段。

### 2.4 数据高效策略 DES

- 基于**阶段感知的点云编辑**：对任务相关物体独立采样刚体变换并施加到其点云，扰动物体间相对空间配置。
- 交互阶段中末端轨迹随被操作物体一致变换以保留演示接触几何：$^W T_{E',t} = H'_{obj} H_{obj}^{-1}\,{}^W T_{E,t}$。
- 非交互轨迹重新生成以连接编辑后的交互状态，产生几何上合成但多样的演示。

## 6. 主要结论与发现

- **仿真性能**：RLBench 10 任务平均成功率 **85.7%**，超过最强基线 PointACT（82.3%）3.4 个百分点；Sweep to dustpan 从 59% 提升到 99%，归因于 World Flow 显式建模工具—目标—环境相对几何。LIBERO 平均 **97.5%**，仅 0.5B 参数、单前视角、无腕部相机，在 40 任务统一训练下超过 SmolVLA（88.8%）与 MolmoAct2（97.2%），在 3D 感知阵营全面领先 PointACT（96.0%），长程套件提升最大（95.0% vs 90.6%）。
- **真实世界零样本迁移**：单一策略、每任务约 10 分钟人类演示、无机器人演示，六设置平均 **91.7%** vs HumanEgo **60.8%**；跨环境 95.0% / 跨本体 91.7% / 跨设置 90.0%，对应 HumanEgo 为 70.0% / 60.8% / 58.3%。
- **数据效率与扩展性**：DES 在低数据区间进一步提升表现；训练数据从 100 → 2000 → 14,300 回合，Long-6/Long-8 平均成功率由 82% → 90% → 96%，说明统一表征可把异构数据规模转化为能力。
- **消融结论**：原始点云几乎无增益（81.50% vs 81.65%），说明"非结构化 3D 几何本身不够"；运动感知前景分割（89.00%）与 Point Modeling

与双流表示进一步带来增益；Ego Trajectory 提供控制器可直接执行的局部接口，World Flow 则在工具使用与空间扰动场景中贡献最明显。整体呈现"几何本身无用、几何+运动语义才有用"的清晰趋势。

## 7. 局限性与批判性讨论

- **核心假设的适用边界**：$^W T_{E,t} = {}^W T_{O,t}G$ 依赖**刚体接触**且 $G$ 在动作块内**时不变**。对柔性物体（论文自身的 TowelFolding）、多点接触、接触切换或滑动抓取，该恒等式仅近似成立；论文未提供 $G$ 漂移的敏感性分析，也未说明 chunk 长度 $H=32$ 与该假设有效性的关系。
- **对分割质量的强依赖**：PriorSeg 的世界流目标由离线运动聚类监督得到，其质量取决于 $d^{mov}$/$d^{sta}$ 的可分性。在**静态或近静态演示、物体长时间被遮挡、深度噪声大**的场景下，运动线索可能退化；论文未报告分割精度指标或分割失败对下游成功率的传播影响。
- **观测与几何条件受限**：固定单目 L515、单一外中心视角、无腕部相机，点云在遮挡区依赖补全；LIBERO 使用度量点云（仿真特权信息），而真实世界使用估计深度，两者间存在**仿真—真实几何差距**，可能部分解释了仿真 97.5% 与真实 91.7% 的落差。
- **人类数据管线引入的误差链**：WiLoR 手部姿态 → 虚拟平行夹爪映射 → ORB-SLAM3 相机轨迹 → 首帧对齐，每一步都可累积误差；论文未做该链路的端到端误差分析，也未验证在非平行夹爪（如灵巧手）上的可迁移性——而"通用操作表征"的宣称恰恰指向这一方向。
- **扩展性验证的规模上限**：数据扩展仅到 14,300 回合，远未触及 Open X-Embodiment 量级；"数据量增长转化为能力增长"的论断在更大规模、更多本体、更多任务族上是否保持，尚缺乏证据。
- **评估可比性**：RLBench 基线引自 PointACT，训练/评估细节未完全对齐；消融各阶段评估回合数不一致（400 → 200）；真实世界每设置仅少数任务、未报告置信区间或多次随机种子方差，**3–4 个百分点的差距在统计上可能不显著**。
- **成本透明度**：全文未披露算力、训练时长与推理延迟。0.5B 模型 + 点云编码器的实际推理频率能否满足闭环控制（尤其 20 Hz 点云输入）未加说明，而这对真实部署是关键指标。
- **未见失败模式分析**：缺少对失败回合的归类（抓取失败 / 几何估计错误 / 分割错误 / IK 不可达），削弱了"哪一组件是瓶颈"的诊断价值。

## 8. 总体评价与启示

- **理论贡献扎实**：UMR 的价值不只是一套表示，而是给出了**可证明的坐标变换框架**（抓取变换消去、SE(3) 共轭），说明"物体运动"与"末端轨迹"是同一运动的两个视角。这使人类演示与机器人演示在同一空间中对齐成为几何上的必然，而非工程上的拼凑。
- **工程取舍合理**：仅执行 Ego 分支、World Flow 只作为训练期的结构化先验与共条件信号，避免了推理期额外的动作解码模块，保持了端到端与实时性。
- **实证说服力中等偏上**：跨仿真/真实、跨本体/视角/场景的多维评估，加上逐级消融与数据规模曲线，构成了较完整的证据链；但统计严谨性、假设敏感性、大规模扩展与成本披露方面仍有明显缺口。
- **对领域的启示**：论文实质上在主张一条路线——**用几何不变量而非具身接口来统一动作空间**。若该思路在柔性物体、灵巧手与超大规模异构数据上被验证，将直接挑战"以大参数 VLA + 具身特定动作头"为主流的技术范式；反之，其刚体接触假设的边界也将成为后续工作的明确靶点。
