## 摘要
长时程操作要求机器人在应对运动物体的同时，记住已不在视野中的线索。然而，视觉-语言-动作（VLA）策略往往依赖最新观测，而刷新其视觉上下文通常需要额外进行一次代价高昂的视觉-语言模型（VLM）前向计算。我们提出 D$^2$-VLA，在预训练 VLA 的 KV 缓存接口处结合了双记忆与双频控制。D$^2$-VLA 采用分块因果 KV 缓存来增量编码观测，并在不同的时间注意力模式引导下，为 VLM 与动作专家分别构建独立的历史 KV 读取视图。在周期性的 VLM 更新之间，一个门控适配器将新的视觉特征融入最新的历史条件 KV 块，同时一个短时快记忆队列支持动作重新规划。我们提出 DOMINO-Long，一个包含十项任务的基准，要求机器人在操作运动物体时利用先前的视觉线索。D$^2$-VLA 在 DOMINO 上取得 29.3% 的完整任务成功率，而 $π_{0.5}$ 为 9.6%、PUMA 为 17.2%；在 DOMINO-Long 上达到 60.0%，二者分别为 35.4% 和 20.6%。它在八项真实机器人任务上提升了成功率，并在 LIBERO-Long 上达到 97.5%，在 RoboTwin 2.0 上达到 74.3%。

## Abstract
Long-horizon manipulation requires robots to remember cues that are no longer in view while responding to moving objects. Yet vision-language-action (VLA) policies often rely on the latest observation, and refreshing their visual context typically requires another costly vision-language model (VLM) pass. We present D$^2$-VLA, which combines dual memory and dual-frequency control at the KV-cache interface of a pretrained VLA. D$^2$-VLA uses block-wise causal KV caching to encode observations incrementally and, guided by distinct temporal attention patterns, constructs separate historical KV read views for the VLM and action expert. Between periodic VLM updates, a gated adapter incorporates fresh visual features into the latest history-conditioned KV block, while a short fast-memory queue supports action replanning. We introduce DOMINO-Long, a ten-task benchmark requiring robots to use earlier visual cues when manipulating moving objects. D$^2$-VLA achieves complete-task success rates of 29.3\% on DOMINO, compared with 9.6\% for $π_{0.5}$ and 17.2\% for PUMA, and 60.0\% on DOMINO-Long, compared with 35.4\% and 20.6\%, respectively. It improves success rates on eight real-robot tasks and reaches 97.5\% on LIBERO-Long and 74.3\% on RoboTwin 2.0.

# D²-VLA 论文详细总结

## 一、核心问题与整体含义（研究动机与背景）

- **现实需求的双重时间挑战**：长时程操作（long-horizon manipulation）要求机器人同时具备两种能力：
  - **长时记忆**：任务线索、物体身份、任务进度可能在当前视野中消失（如"把滚动的瓶子放回原处"需要记住原始位置）。
  - **快速响应**：物体不总是静止的，需要及时跟踪和调整。
- **现有 VLA 的缺陷**：
  - 现代 flow-based VLA（如 π0.5）将计算分为大 VLM（语义理解）+ 动作专家（连续控制），但其推理循环既**无记忆**又**频率耦合**——每次动作预测主要依赖最新观测，刷新视觉上下文需完整重跑 VLM。
  - 简单保留更长 VLM 上下文会提高注意力开销，频繁刷新 VLM 则代价高昂。
- **已有工作的割裂**：
  - 记忆方向的工作（RoboFlamingo、CronusVLA、MemoryVLA、MEM、MemER、KV-based 方法）侧重历史聚合或检索，但**未区分 VLM 与动作专家所需的历史可能不同**。
  - 实时/分层方向的工作（RTC、DynamicVLA、HiRT、FAVLA、AHA-WAM）侧重响应性，但其快控制器通常仅以最新慢表征为条件。
- **核心研究问题**：能否在预训练 VLA 的**原生 KV 接口**上协同设计记忆访问与更新频率？
- **关键发现（时间不对称性）**：VLM 依赖更广的历史做语义推理，动作专家主要关注近期观测中含运动信息的 token 子集——这一发现驱动了将两者的 KV 选择与刷新频率解耦。

## 二、方法论

### 核心思想
在 π0.5 的基础上，通过**分块因果时序建模**赋予单帧 VLA 时序记忆，并在 KV 缓存接口处引入**双记忆（Dual-Memory）+ 双频（Dual-Frequency）** 机制。

### 关键技术细节

- **块级因果注意力（Block-wise Causal Attention）**：
  - 每个观测块（图像 + 指令）内部双向注意力，块间因果注意力。
  - 推理时历史 KV 无需重编码：$K_c = \Phi_{KV}(I_t, \ell; K_{<t})$，$K_t = K_{<t} \oplus K_c$。
  - 机器人状态投影为独立 token 直接送入动作专家，不进入 VLM 缓存。

- **双记忆：非对称历史选择（Dual-Memory）**：
  - 依据在线注意力统计（online attention statistics）为 VLM（`Read_VLM`）和动作专家（`Read_act`）构建**独立的历史 KV 读取视图**。
  - 使用类似 H2O 的累计重要性分数 $h_{g,l,i}$，按层取最大值 $u_{g,i} = \max_l h_{g,l,i}$ 作为选择依据，分数保留系数 $\rho = 0.2$。
  - **仅在推理时启用**，训练时使用未压缩 KV；选择只改变临时读取视图，存储块保持完整。
  - 保护指令 token 与当前块；按块、按相机分配预算（主结果保留比例 0.7）。

- **双频：多速率视觉条件（Dual-Frequency）**：
  - VLM 每 $V$ 环境步刷新一次，动作每 $E$ 步重规划，$V$ 为 $E$ 的整数倍（主配置 $V = 3E$，$H=E=25$，$V=75$）。
  - **动态特征适配器**：以慢更新锚点 $K_c(t_s)$ 为基础，将当前图像特征与归一化经过时间 $\delta_t$ 编码，经 learned-query pooler 得到紧凑查询 $Z_t$，预测全块 K/V 残差并由门控 $\tanh$ 加权：
    $\tilde{Z}_t = K_c + G_\psi \odot F_\psi(Z_t, K_c)$。
  - 残差投影零初始化、门初始化为 $\text{arctanh}(0.1)$，使适配器初始为恒等更新。
  - **快记忆队列** $Q_{fast}$（容量 2）存储精炼后的完整 KV 块；慢队列 $Q_{slow}$ 容量 4。
  - 快慢队列**从不拼接**为单一条件；快调用通过历史条件化的慢锚点继承长程上下文。

- **训练目标**：仅使用 flow-matching 损失，端到端训练所有模块；每个样本含 1 个慢锚点 + 最多 3 个历史观测 + 3 条动作分支，无辅助适配器损失，训练时不做 KV 选择。

- LIBERO-Long：CogACT、OpenVLA、π0-FAST、CronusVLA、CoT-VLA、SmolVLA、π0、GR00T-N1、π0.5、MemoryVLA。
- 真机：π0.5、MemoryVLA。

### 评价指标
- **Complete-task Success Rate (SR)**：必须完成全部任务要求才算成功。
- **Manipulation Score (MS)**：DOMINO 的操纵质量指标，惩罚不安全/不期望行为。

## 四、资源与算力

- **GPU**：8 × A100 80 GB，8 路 FSDP。
- **训练时长/步数**：DOMINO 75,000 次更新；DOMINO-Long 和真机任务各 50,000 次更新；warmup 1,000 步；余弦衰减。
- **精度**：BF16 计算 / FP32 参数；EMA 0.99；随机种子 42。
- **数据加载**：20 个 dataloader worker，prefetch factor 2，ordered loading，persistent workers。
- **检查点**：每 2,000 步保存。
- **备注**：论文未明确给出训练总墙钟时长（wall-clock time），仅给出更新步数和硬件配置。

## 五、实验数量与充分性

- **仿真实验**：4 个基准（DOMINO、DOMINO-Long、LIBERO-Long、RoboTwin 2.0），其中 RoboTwin 2.0 报告全部 50 个任务，DOMINO 报告 35 个任务，DOMINO-Long 报告 10 个任务。
- **真机实验**：8 个任务（4 静态 + 4 动态）。
- **消融实验**：
  - 组件消融（因果训练 + 双记忆 vs. 再加双频）：9.6% → 16.1% → 29.3%。
  - 更新频率消融（$V/E = 2$ vs. $3$）：27.6% vs. 29.3%。
  - 历史 KV 保留比例扫描（1.0、0.9、0.8、0.7、0.6、0.5、0.4、0.3）。
  - 效率-性能权衡对比（π0.5 vs. Full KV Cache vs. D²-VLA）。
- **充分性评价**：
  - **优点**：覆盖动态/静态仿真 + 真机、多任务细分结果、多种消融，对比基线丰富（20+ 方法），指标双维度（SR + MS）。
  - **公平性**：DOMINO 基线数值转录自原论文；RoboTwin 统一在 clean 设置下训练评估；报告了参数量。
  - **局限**：真机实验未给出完整的逐任务数值表（部分在附录），未报告多次随机种子的方差；部分消融（如保留比例）仅在 DOMINO 上进行。

## 六、主要结论与发现

- **时间不对称性**：VLM 与动作专家对历史上下文的偏好显著不同（前者更宽，后者偏近期运动 token），为解耦设计提供依据。
- **性能提升**：
  - DOMINO：**29.3% SR / 40.6 MS**，超 π0.5（9.6%/26.2）19.7 个百分点，超 PUMA（17.2%/35.0）12.1 个百分点。
  - DOMINO-Long：**60.0% SR**，超 π0.5（35.4%）和 PUMA（20.6%）24.6 / 39.4 个百分点。
  - LIBERO-Long：**97.5% SR**，超 π0.5（92.4%）和 MemoryVLA（93.4%）。
  - RoboTwin 2.0：**74.3% SR**，超 π0.5（57.0%）17.3 个百分点。
  - 真机：动态任务上全面优于 π0.5 与 MemoryVLA；静态任务平均 71.25%（π0.5 51.25%、MemoryVLA 40%）。
- **效率**：相对 Full KV Cache，延迟降低约 5.3%、峰值显存降低约 10.1%（LIBERO-Long），且成功率更高；相对单帧 π0.5，显存仅增加约 1–2%。
- **双频有效性**：加入高频路径使 SR 从 16.1% 提升到 29.3%；$V/E=3$ 优于 $V/E=2$。

## 七、优点

- **方法创新性强**：首次明确提出 VLM 与动作专家的**时序不对称性**，并在 KV 缓存接口处协同设计记忆与频率，切入点新颖且与预训练 VLA 原生结构兼容。
- **设计精巧**：双记忆选择无需额外参数、无需额外打分前向、无需离线先验；适配器零初始化 + 门控保证训练稳定；快慢队列不拼接，保持语义分工。
- **效率与性能兼得**：选择式读取不仅降低延迟和显存，还通过过滤冗余上下文提升成功率。
- **基准贡献**：DOMINO-Long 填补了"长时程语义记忆 + 动态物体交互"联合评测的空白，任务设计分离信息获取与动作执行，覆盖位置、身份、顺序、颜色、运动方向等多类记忆。
- **验证充分**：仿真 + 真机、动态 + 静态、主实验 + 多维消融，且静态基准上禁用高频路径仍取得提升，说明历史感知条件的通用价值。

## 八、不足与局限

- **绝对成功率仍偏低**：DOMINO 上 29.3% 的 SR 说明动态长时程操作仍是难题，部分子任务（如 Click Alarmclock 5%、Place Fan 2%）表现接近随机。
- **真机实验规模有限**：8 个任务、每任务未报告试验次数与方差；动态任务逐任务数值仅在图中呈现，缺少完整表格。
- **训练成本未完全透明**：未给出墙钟训练时长与总 GPU 小时数；未报告多次运行的标准差，难以评估统计显著性。
- **方法依赖与限制**：
  - 基于 π0.5 Base 全量微调，模型规模 3.5B，部署成本较高。
  - 在线 KV 选择仅用于推理，训练与推理存在分布差异（训练用未压缩 KV）。
  - 历史选择仅在保留块内进行排序，无跨块的全局 recent-frame 规则；论文也承认注意力可视化只是诊断而非先验。
  - 高频路径在 LIBERO-Long / RoboTwin 上被禁用，说明其价值主要体现在动态场景。
- **潜在偏差风险**：DOMINO 基线数值直接转录自原论文，不同训练/评估配置可能带来可比性问题；DOMINO-Long 每任务仅 50 条演示，随机化覆盖有限。
- **应用限制**：真机实验仅在 Unitree G1D + 传送带场景验证，尚未推广到更多本体与更复杂接触任务；对接触力等高频反馈未建模（与 FAVLA 等不同）。
