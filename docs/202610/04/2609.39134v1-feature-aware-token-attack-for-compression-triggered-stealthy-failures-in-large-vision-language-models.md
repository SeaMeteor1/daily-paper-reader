## 摘要
视觉令牌压缩提升大型视觉语言模型的效率，但会暴露全令牌评估遗漏的失效。我们研究这样的对抗图像：它们保持全令牌正确性，却在压缩后诱发错误，即使两条推理路径在干净图像上均成功。构造此类失效具有挑战性，因为扰动令牌重要性也可能破坏全令牌推理所需的视觉内容。我们提出特征感知令牌攻击（FATA），它将注意力抑制与基于余弦的特征保持相结合，作用于一组固定的干净图像显著令牌。在主要 LLaVA-1.5-7B 设置中，FATA 仅使用视觉编码器梯度，无需访问部署的压缩器、令牌预算或下游任务。在受控重建协议下，跨四个视觉依赖任务子集和四个压缩器，FATA 达到 SR = 96.3% 的全令牌准确率保持率和 CBR = 22.1% 的条件致盲率，而 CAA 分别为 89.8% 和 15.7%。消融实验支持两个目标在平衡压缩路径失效与全令牌保持方面的作用。在 5% 假阳性率下，FATA 在三个评估检测器上于四种攻击中具有最低的实测检测率。这些发现促使我们联合评估全令牌推理与压缩推理的对抗鲁棒性。

## Abstract
Visual-token compression improves the efficiency of large vision-language models, but can expose failures that full-token evaluation misses. We study adversarial images that preserve full-token correctness yet induce errors after compression, even when both inference paths succeed on the clean image. Creating such failures is challenging because perturbing token importance can also damage the visual content needed for full-token inference. We propose Feature-Aware Token Attack (FATA), which couples attention suppression with cosine-based feature preservation on a fixed set of salient clean-image tokens. In the primary LLaVA-1.5-7B setting, FATA uses only vision-encoder gradients, without access to the deployed compressor, token budget, or downstream task. Across four visually dependent task subsets and four compressors under a controlled reconstruction protocol, FATA achieves SR = 96.3% full-token accuracy retention and CBR = 22.1% conditional blinding, compared with 89.8% and 15.7% for CAA. Ablations support the role of both objectives in balancing compressed-path failure against full-token preservation. FATA also has the lowest measured detection rate among four attacks across three evaluated detectors at a 5% false-positive rate. These findings motivate assessing adversarial robustness jointly across full-token and compressed inference.

# 论文总结：面向大型视觉语言模型中压缩触发隐蔽失效的特征感知令牌攻击（FATA）

## 1. 核心问题与研究动机

- **背景**：视觉令牌压缩（如 VisionZIP、VisPruner、PruMerge、FlowCut）可显著降低大型视觉语言模型（LVLM）的推理成本，但随着图像分辨率和视觉上下文增长，压缩决策决定了哪些视觉证据能被语言模型使用。
- **核心问题**：存在一类对抗图像，在全令牌推理下仍能被正确理解，但经过视觉令牌压缩后却导致错误回答——即使干净图像在两条推理路径上均成功。这种"压缩触发失效"是仅靠全令牌评估无法发现的漏洞。
- **攻击的双重挑战**：
  - 必须诱导压缩路径失效，同时保持全令牌正确性；
  - 扰动令牌重要性（注意力）会同时损害全令牌推理所需的视觉特征。
- **现有方法不足**：CAGE 通过特征破坏攻击，CAA 通过令牌重要性操纵攻击，但二者难以兼顾"全令牌保持"与"压缩路径失效"的平衡。
- **核心研究问题**：如何仅利用视觉编码器梯度，在保留全令牌行为的同时，利用压缩敏感性触发失效？

## 2. 方法论：FATA

### 核心思想
- 在一组**固定的干净图像显著令牌**上，同时优化两个目标：
  - **注意力抑制（Attention Suppression）**：降低目标令牌的注意力分数，作为压缩敏感性的代理；
  - **特征保持（Feature Preservation）**：维持对抗令牌与干净令牌特征方向的余弦对齐，保护全令牌推理。
- 共享同一目标集，使攻击压力与受保护内容绑定。

### 关键技术细节
- **目标集构建**：用冻结 CLIP 编码器最后一层 CLS-to-patch 注意力（跨头平均）选出 Top-M 令牌（M=64），存储其 patch 特征作为 stop-gradient 锚点。
- **注意力损失**：`L_attn = Σ_{i∈M} s^a_i`，最小化目标令牌的对抗注意力分数。
- **语义损失**：`L_sem = 1 - (1/|M|) Σ_{i∈M} cos(h^a_i, h^c_i)`，保持对抗特征与干净锚点的余弦相似度。
- **联合目标**：`L_FATA = L_attn + λ·L_sem`（λ=1）。
- **优化流程**：
  1. 提取干净注意力 s_c 与特征 H_c，固定目标集 M 和锚点；
  2. 初始化 δ ~ U(-ε, ε)；
  3. 迭代 T 次：计算扰动图像 x^a 的注意力与特征 → 计算 L_FATA → 通过冻结编码器反向传播 → 仅更新 δ；
  4. 使用 ℓ∞ PGD 投影：δ ← Π_{||δ||∞≤ε}(δ - α·sign(∇_δ L_FATA))。
- **超参数**：ε = 2/255，α = 0.5/255，T = 100，M = 64，λ = 1。
- **访问假设**：灰盒方法，仅需视觉编码器梯度；压缩器、令牌预算、下游语言模型、问题与答案在优化时均不可见。
- **评估路径**：同一优化图像分别走全令牌路径（H 直接送 projector）与压缩路径（选择/合并 K 个代表后，用相似度查找从 H 重建 N 槽序列），两条路径共享 projector、LLM 和问题。

### 评估指标
- **SR（全令牌保持率）**：攻击后全令牌准确率 / 干净全令牌准确率。
- **CER（压缩错误率）**：1 - Acc@K_prac。
- **CBR（条件致盲率）**：在干净全令牌正确、攻击全令牌正确、干净压缩正确的条件下，攻击压缩错误的比率。
- **K_prac**：每个数据集-压缩器对分别选择的最小令牌预算，使干净准确率保留 ≥ 80%。

## 6. 主要结论与发现

- **LLaVA-1.5-7B 主结果**：FATA 达到 **SR = 96.3%**、**CBR = 22.1%**，优于 CAA（89.8%、15.7%）；相比 Base（66.7%、32.9%）和 CAGE（36.6%、43.1%），FATA 在保持全令牌性能与诱导压缩失效之间取得更优平衡。
- **失败阶段分解**：在 14,316 个干净全令牌正确样本中，FATA 仅 5.3% 在压缩前失效，23.3% 在压缩后涌现失效，71.5% 保持正确——说明其失效主要源于压缩触发。
- **消融结论**：
  - 仅注意力损失：CBR 最高（32.9%）但 SR 降至 66.7%；
  - 仅语义损失：SR 最高（98.5%）但 CBR 仅 14.5%；
  - 完整 FATA：SR 96.3%、CBR 22.1%，证明两个目标缺一不可。
- **跨模型泛化**：
  - Qwen3.5-9B：平均 SR = 99.3%，平均 CBR = 46.43%；
  - InternVL3.5-8B-HF：宏平均 SR = 93.94%，宏平均 CBR = 40.38%；
  - 均呈现"全令牌保持、压缩后精度损失更大"的一致模式。
- **检测隐蔽性**：在三种检测器、5% FPR 下，FATA 的 TPR 均为四种攻击中最低（Feature Squeezing 2.4%、Mahalanobis-Max 13.4%、ML-ATD 49.7%），表明其较难被现有检测方法发现。
- **总体结论**：视觉令牌压缩引入了一种全令牌评估无法捕捉的对抗脆弱性，应联合评估全令牌与压缩推理下的鲁棒性。

## 7. 优点

- **方法设计巧妙**：双目标耦合在共享固定目标集上，既抑制注意力（作为压缩敏感代理）又保持特征方向，有效平衡了"隐蔽性"与"杀伤力"。
- **访问假设务实**：仅需视觉编码器梯度，无需压缩器、预算、下游任务、问题或答案，具有较好的现实可行性。
- **评估协议严谨**：
  - K_prac 仅由干净结果确定并跨攻击固定；
  - CBR 条件化于干净与攻击全令牌正确、干净压缩正确，精准隔离压缩触发失效；
  - 受控重建协议使不同压缩器在统一框架下比较。
- **实验覆盖广**：跨 3 个模型、4 个压缩器、4 个数据集、多个令牌预算，并含消融、敏感性、检测与定性分析。
- **检测分析完整**：引入 ML-ATD 并对比多种检测器，揭示 FATA 的低可检测性，呼应"隐蔽失效"主题。
- **附录详实**：提供完整优化算法、超参数敏感性、模型适配细节、评分规则与数据集构建流程，可复现性较强。

## 8. 不足与局限

- **访问假设限制**：FATA 假设可获取视觉编码器梯度；Qwen3.5 与 InternVL3.5 的最强结果依赖任务感知或架构感知的扩展（使用真实答案与下游梯度），访问要求更高，且全令牌保持代价随适配方式变化。
- **隐蔽性有条件**： stealth 是基于任务的（task-based），ML-ATD 并非最优防御；面对更强的在线检测器，攻击可能被识别。
- **未验证黑盒迁移**：未系统评估黑盒场景下的可迁移性，攻击在无梯度访问时的有效性未知。
- **任务与模型覆盖有限**：仅涉及四个视觉依赖任务子集与三个 LVLM，未覆盖更广泛的推理、生成或安全敏感任务。
- **算力信息缺失**：论文未报告 GPU 型号、数量或训练时长，不利于复现成本评估。
- **潜在偏差风险**：
  - CAA 在 ScienceQA 上的评估样本数较少（FS 990、Mahalanobis-Max 496），可能影响检测对比的公平性；
