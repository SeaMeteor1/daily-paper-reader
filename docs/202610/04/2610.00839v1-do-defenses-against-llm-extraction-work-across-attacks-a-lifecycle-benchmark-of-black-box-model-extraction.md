## 摘要
通过纯文本API部署的大语言模型（LLMs）面临模型提取风险，因为对手可以收集其响应来训练替代模型，以复现其能力。尽管先前工作已开发出多种攻击与防御，但评估在访问假设、模型配置、查询预算和安全目标上仍然碎片化，限制了方法之间的可比性。为弥补这一空白，我们提出了一个统一基准，涵盖六种提取攻击、十种防御，以及两种自适应攻击——它们在替代模型训练前对受保护响应进行改写或回译。该基准在每次比较中控制模型配置、查询数据、预算和留出评估条件，同时保留特定于攻击的查询与训练流程。我们测量替代模型的能力、对受害模型的保真度、使用Rep-4的输出质量以及查询预算敏感性；防御则使用其自身的安全指标，并与替代模型性能配对评估。对于自适应攻击，我们联合测量来源检测器得分，以及基于改写响应训练的替代模型的能力和保真度。因此，该基准为在纯文本访问下比较提取方法及其与防御的交互提供了一个可复现的基础。代码与制品可在 https://github.com/sliu11-byte/MEA-Bench 获取。

## Abstract
Large language models (LLMs) deployed through text-only APIs face model extraction risks, as adversaries can collect their responses to train surrogates that reproduce their capabilities. While prior work has developed diverse attacks and defenses, evaluations remain fragmented across access assumptions, model configurations, query budgets, and security objectives, limiting comparability across methods. To address this gap, we introduce a unified benchmark covering six extraction attacks, ten defenses, and two adaptive attacks that paraphrase or back-translate protected responses before surrogate training. The benchmark controls model configurations, query data, budgets, and held-out evaluation conditions within each comparison while preserving attack-specific querying and training procedures. We measure surrogate capability, fidelity to the victim, output quality using Rep-4, and query-budget sensitivity; defenses use their own security metrics paired with surrogate performance. For the adaptive attacks, we jointly measure provenance-detector scores and the capability and fidelity of surrogates trained on rewritten responses. The benchmark thus provides a reproducible basis for comparing extraction methods and their interactions with defenses under text-only access. Code and artifacts are available at https://github.com/sliu11-byte/MEA-Bench.

## 1. 核心问题与整体含义

- **研究背景**：LLM 常通过纯文本 API 提供商业服务，参数虽不可见，但输入–输出行为可被反复查询。攻击者可收集受害者模型响应，训练更小的替代模型，从而在未获取参数或训练数据的情况下复制其功能能力，形成“模型提取”风险。
- **核心问题**：现有 LLM 提取攻击与防御研究虽多，但评估高度碎片化：访问假设、受害者–替代模型配置、查询数据、查询预算、安全目标与评价指标不一致，导致攻击强度难以归因，防御效果难以横向比较。
- **关键缺口**：
  - 攻击比较存在混杂变量，模型、数据、预算变化可能被误认为攻击方法优势。
  - 防御目标不可通约：抗蒸馏、来源溯源、血缘验证、查询检测对应不同安全目标，不能合并成单一“防御分数”。
  - 自适应攻击评估不完整：仅测量改写后的受保护响应，未训练替代模型并联合评估检测器信号、能力与保真度。
- **整体含义**：论文提出面向生命周期的黑盒 LLM 提取基准，在统一文本访问威胁模型下连接攻击、防御和自适应攻击评估，为比较提取方法与防御交互提供可复现基础。代码与工件公开于 MEA-Bench。

## 2. 方法论：核心思想、技术细节与流程

- **核心思想**：以“提取生命周期”组织评估，将过程分为四阶段：
  1. **查询获取**：攻击者选择或构造提取查询 \(q_i\)。
  2. **受害者交互**：向受害者模型 \(f_V\) 提交查询，获得响应 \(y_i=f_V(q_i)\)。
  3. **替代模型训练**：攻击者构造提取数据集并优化替代模型 \(f_S\)。
  4. **评估**：测量替代模型能力、保真度、输出质量及防御检测器输出。
- **训练响应形式**：
  - 仅攻击：直接使用原始响应 \(y_i\)。
  - 响应修改防御：使用受保护响应 \(\tilde y_i\)。
  - 自适应攻击：进一步改写为 \(\hat y_i\)。
  - 形式化：\(r_i \in \{y_i,\tilde y_i,\hat y_i\}\)，\(\mathcal D=\{(q_i,r_i)\}_{i=1}^B\)，\(f_S=\text{Train}(\mathcal D)\)。
- **六种提取攻击**：
  - **SeqKD**：固定查询池 + 教师响应序列级 SFT。
  - **Model Leeching**：模板化查询，清洗/解析教师响应，仅用答案文本 SFT。
  - **QEDKS**：种子查询、模板与追问在线扩展，教师响应 SFT。
  - **LoRD**：固定池，结合教师响应与学生候选，迭代成对优化。
  - **SODA**：固定池，构造教师–学生偏好对，使用 DPO。
  - **GAD**：固定池，联合优化替代模型与响应判别器。
- **十种防御，按干预点与目标分四类**：
  - **查询检测**：MMD、PRADA、SEAT，在受害者推理前分类查询流是否可疑。
  - **抗蒸馏**：ADS、DOGe、Trace Rewriting，修改释放响应，降低其作为提取监督的价值。
  - **来源溯源**：ADFP、GINSEW、Radioactivity，在响应中嵌入信号，期望被替代模型继承并可检测。
  - **训练后血缘验证**：DuFFin，对训练后模型使用诊断探针判断是否源自受害者。
- **两种自适应攻击**：
  - **DIPPER 改写**：对受保护响应进行 paraphrasing。
  - **回译**：英语–法语–英语 back-translation。
  - 二者均发生在受害者交互之后、替代模型训练之前，只改变监督文本，不改变查询序列。
- **评价指标**：
  - **能力**：六任务准确率宏平均 ACC。
  - **行为保真度**：替代响应与受害者响应的 baseline-rescaled BERTScore F1。
  - **输出质量/重复**：Rep-4，越低表示响应内重复越少。
  - **抗蒸馏**：\(\Delta m=m_{\text{defended}}-m_{\text{clean}}\)。
  - **来源检测**：保留原生指标，如 ADFP 的 \(-\log_{10}(p)\)、GINSEW 的 \(P_{snr}\)、Radioactivity 的 p 值。
  - **查询检测**：TPR、FPR。
  - **血缘验证**：DuFFin 探针一致性与模型级 ROC-AUC。
  - **自适应攻击**：联合报告检测器分数、替代模型能力与保真度。
- **控制原则**：在每次比较中尽量匹配受害者–替代模型配置、查询数据、预算和留出评估条件，同时保留攻击特定的查询获取与训练流程。
