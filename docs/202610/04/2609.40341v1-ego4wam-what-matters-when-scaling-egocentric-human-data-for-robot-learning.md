## 摘要
第一视角人类数据为机器人学习提供了可扩展的经验来源，但其在人机对齐、行为覆盖范围以及可用监督信号方面存在显著差异。现有工作表明，随着人类数据增加，性能呈现出良好的扩展趋势，但尚不清楚哪些数据属性驱动了下游机器人性能的提升，以及如何在整条训练流程中利用这类数据。我们在统一的世界-动作模型框架下，对不同对齐程度与监督方式的第一视角人类数据进行了系统性研究。在固定模型骨干的前提下，我们解耦了人机对齐、数据时长与任务多样性、动作监督以及数据使用策略各自的影响。我们发现：对齐后的人类演示能显著提升分布外泛化能力，并降低目标任务所需的机器人数据量；数据时长与任务多样性对下游能力的影响方式不同；仅有视频的监督在没有动作标签时仍然有效，可为后续的视频-动作训练提供坚实基础。我们通过在真实机器人和 RoboDojo 上的闭环策略评估验证了这些发现。Ego4WAM 表明，数据时长并非唯一的扩展维度，对齐程度、任务多样性、可用监督信号与使用策略共同决定了第一视角人类数据对机器人学习的价值。

## Abstract
Egocentric human data provides a scalable source of experience for robot learning, but varies substantially in human-robot alignment, behavioral coverage, and available supervision. Existing work shows favorable scaling with increasing human data, but it remains unclear which data properties drive downstream robot gains and how to use such data throughout the training pipeline. We present a systematic study of egocentric human data with different alignment and supervision under a unified world-action model framework. With the model backbone fixed, we disentangle the effects of human-robot alignment, data duration and task diversity, action supervision, and data usage strategies. We find that aligned human demonstrations substantially improve out-of-distribution generalization and reduce target-task robot data requirements; data duration and task diversity affect downstream capabilities differently; and video-only supervision remains effective without action labels, providing a strong foundation for subsequent video-action training. We validate these findings through closed-loop policy evaluation on both real robots and RoboDojo. Rather than treating data duration as the sole scaling axis, Ego4WAM shows how alignment, task diversity, available supervision, and usage strategy jointly shape the value of egocentric human data for robot learning.

- **核心研究问题**：*在扩展第一视角人类数据用于机器人学习时，哪些数据属性与使用策略最为关键？*
- **整体含义**：论文提出应在统一框架下系统解耦这些因素，并以**闭环策略性能**（而非开环动作预测指标）作为评价标准，为"采集什么数据、获取何种监督、如何在训练流程中使用"提供实证指南。

## 二、方法论：核心思想与关键技术细节

### 2.1 核心思想
- 在**统一的世界-动作模型（World-Action Model, WAM）框架**下，**固定模型骨干**，仅改变数据组成、监督方式与使用策略，从而解耦各因素的影响。
- 提出**第一视角数据金字塔**：按"每个样本能可靠支持的最强监督层级"组织数据——
  - 底层：大规模**仅视频数据**（约 12 万小时）
  - 中层：**多任务视频-动作数据**（约 1.2 万小时，经时序与几何质量过滤）
  - 顶层：**机器人对齐演示**（约 4 小时，EgoAlign 内部数据集）

### 2.2 模型框架
- 基于 Yuan et al. (2026) 的 FastWAM 设计，包含：
  - **视频分支**：世界建模（预测未来视觉表征）
  - **动作分支**：动作预测
  - 语言指令作为条件信号；本体状态仅注入动作分支；两分支通过**共享注意力**交互。
- 两种共享注意力机制：
  - **Base**：未来动作 token 仅关注当前视觉上下文
  - **Joint**：未来动作 token 额外关注预测的未来视觉表征（未来视觉 token 始终不依赖动作 token）

### 2.3 统一动作空间
- 双臂控制，每臂 16D 向量 = 6D 关节 + 1D 夹爪 + 9D 末端执行器（EEF，含 3D 平移 + 6D 旋转），拼接为 **32D 双臂动作空间**。
- 人类数据仅监督**跨具身可对应的分量**（EEF 位姿与夹爪状态）：
  - EEF 位置定义为拇指与食指指尖中点：$p_{eef} = \frac{1}{2}(p_{thumb} + p_{index})$
  - 夹爪开合度定义为两指尖欧氏距离：$g = \|p_{thumb} - p_{index}\|_2$
  - 手部朝向通过腕部、掌心和指尖构造正交坐标系，转换为 6D 连续旋转表示。
- **解析噪声路径**：对无效动作维度保持在前向噪声轨迹上，避免掩码损失导致采样时任意值累积：
  - 前向轨迹：$x_\sigma = (1-\sigma)x_0 + \sigma\epsilon$，$v^\star = \epsilon - x_0$
  - 有效维度损失：$L_{action} = \mathbb{E}[w(\sigma)\frac{\sum_{t,d} M_{t,d}\|v_\theta - v^\star\|_2^2}{\max(\sum M_{t,d},1)}]$
  - 无效维度固定：$\hat{\epsilon}_I = x_{\sigma_0}[I]/\sigma_0$，$x_{\sigma_i}[I] = \sigma_i \hat{\epsilon}_I$

### 2.4 三阶段训练协议
1. **预训练（Pre-training）**：仅优化世界建模目标，使用第一视角视频（含动作有效与仅视频样本）
2. **中训练（Mid-training）**：联合优化世界与动作预测，使用动作标注数据
3. **后训练（Post-training）**：在下游机器人演示上适配，可选加入机器人对齐人类数据

- 通用流匹配目标：$L_{FM}(y) = \mathbb{E}_{y,\epsilon,\sigma}[w(\sigma)\|v_\theta(y_\sigma,\sigma,c) - v^\star\|_2^2]$
- 总损失：$L = \lambda_{world}L_{world} + \lambda_{action}L_{action}$（无动作监督样本仅优化 $L_{world}$）

## 六、主要结论与发现

- **发现一：人类数据减少但无法完全替代机器人数据**
  - 对齐人类演示可将物体-OOD 成功率从 10% 提升至 60%，场景-OOD 从 0% 提升至 20%。
  - 机器人演示从 300 降至 100 时，加入人类数据可恢复 80% ID / 60% 物体-OOD / 80% 场景-OOD。
  - 但降至 20 条时，仅靠对齐人类数据无法恢复有效策略；需多任务中训练才能达到 80% ID / 80% 物体-OOD / 60% 场景-OOD。
- **发现二：数据时长与任务多样性是不同且依赖能力的扩展轴**
  - 固定 500 任务，时长 1K→4K 小时：Generalization 5.0→7.8，Long-Horizon 12.0→16.2。
  - 任务从 500→6K：Generalization 5.0→7.0，Long-Horizon 12.0→16.2，但 **Precision 下降**。
  - 相同数据量（2K/4K 小时）下，密集覆盖常见任务在多个指标上优于广泛长尾覆盖。
  - 结论：**总时长或任务数均不足以刻画有用数据规模**；应优先保证常见行为覆盖，再扩展长尾。
- **发现三：仅视频监督仍然有效，且是联合世界-动作学习的基础**
  - 无人类预训练/中训练：平均 RoboDojo 6.39 / 3.15%
  - 仅视频预训练：14.13 / 9.45%（无需动作标签）
  - 先视频预训练再中训练：15.04 / 10.78%
  - 无视频预训练直接中训练：仅 10.28 / 6.42%
  - 切换 Base→Joint 注意力：平均分从 14.13 提升至 **20.29**，成功率从 9.45% 提升至 **14.35%**
- **总体结论**：第一视角数据的价值不取决于规模本身，而取决于**覆盖的分布

、可提取的监督层级，以及在训练流程中的使用时机**；闭环策略性能是判断数据价值的必要标准。

### 六（续）、结论的进一步展开

- **发现四：监督层级之间存在互补而非简单替代关系**
  - 视频监督提供**世界动态与场景先验**，使动作分支在接触稀疏数据时仍能获得稳定的视觉表征基础。
  - 动作监督提供**可执行的跨具身对应关系**（EEF 位姿 + 夹爪），但若缺少视频预训练，动作分支容易在有限数据上过拟合到短时视觉线索。
  - 机器人对齐人类数据（EgoAlign）提供**具身可迁移性**，是连接人类行为分布与机器人动作空间的关键桥梁，但其规模远小于视频与多任务动作数据，无法单独支撑策略学习。

- **发现五：共享注意力中"未来视觉 token"的引入是收益放大器**
  - Base→Joint 的切换几乎不增加数据需求，却带来 RoboDojo 平均分 14.13→20.29 的提升。
  - 机制解释：未来视觉 token 为动作预测提供了**前瞻性条件**，使动作分支在长时程任务中能够"先想后做"，缓解了仅依赖当前视觉上下文时的短视行为。
  - 该设计在预训练阶段即已学习（未来视觉 token 不依赖动作 token），因此中训练/后训练阶段可零成本复用。

- **发现六：数据组成比数据总量更能预测下游性能**
  - 在相同总时长（2K/4K 小时）下，"密集覆盖常见任务"的配置在 Generalization 与 Long-Horizon 上优于"广泛长尾覆盖"。
  - 说明存在**覆盖密度阈值**：当常见行为被充分覆盖后，边际长尾数据的收益递减，甚至因分布稀释而损害 Precision。
  - 因此数据采集应遵循"**先保证常见行为的重复与多样性，再向长尾扩展**"的优先级。

## 七、论文的局限性与未来方向

- **局限一：算力匹配缺失**
  - 预训练（仅视频，12 万小时级）与中训练（动作标注，1.2 万小时级）未做算力匹配对照，因此"视频预训练优于直接中训练"的结论可能部分来自额外训练步数而非监督类型本身。
  - 未来需在固定 FLOPs 预算下重复关键消融。

- **局限二：真实机器人任务覆盖面有限**
  - 受控实验仅涵盖刚体抓放与可变形物体折叠两类任务，未覆盖接触丰富、工具使用、多阶段长时程等场景。
  - 4 个扩展任务（Fold Towel、Tighten a Bottle Cap、Stack Plates and Bowls、Heat Food with a Microwave）虽增加了多样性，但均为厨房/家务类，跨域泛化证据不足。

- **局限三：数据源单一**
  - 扩展研究在自建语义任务类别体系上构建，未跨多个公开数据源（如 EgoDex、EgoLive、EgoSuite）验证"时长 vs 多样性"结论的普适性。
  - 不同采集设备、标注管线与地理文化背景可能改变最优数据组成。

- **局限四：统计严谨性不足**
  - 未报告多随机种子方差、置信区间或显著性检验，部分提升（如 5.0→7.8）的稳健性未知。
  - 闭环成功率实验样本量（每条件通常 20–100 次试验）对细粒度差异的检出能力有限。

- **局限五：跨具身对应仅限 EEF + 夹爪**
  - 统一动作空间保留 6D 关节与 9D EEF，但人类数据仅监督 EEF 位姿与夹爪开合，关节级对应关系未被利用。
  - 对灵巧手、多指抓取等更复杂末端执行器的迁移能力未验证。

- **未来方向**：
  - 构建算力匹配的监督类型对照实验；
  - 跨数据源的"时长—多样性—对齐度"三维扩展研究；
  - 引入关节级与触觉级人类监督；
  - 将闭环评估标准化为第一视角数据价值的默认基准；
  - 探索数据选择/课程学习策略，以在有限预算下最大化常见行为覆盖密度。

## 八、对领域与实践的启示

- **对数据采集方**：不应以"小时数"作为唯一 KPI，而应报告**监督层级分布**（仅视频 / 视频-动作 / 机器人对齐）与**任务覆盖密度**。
- **对模型训练方**：三阶段协议（视频预训练 → 多任务中训练 → 机器人后训练）是可复用的默认流程；视频预训练即使在无动作标签时也应保留。
- **对评估方**：开环动作 MSE 与聚合扩展曲线不足以指导数据决策，应优先采用**闭环策略性能**与**分能力维度（Generalization / Precision / Long-Horizon）**的评估。
- **对机器人数据稀缺场景**：少量机器人演示 + 对齐人类数据可显著恢复 OOD 性能，但演示数降至极低（如 20 条）时需借助多任务中训练才能维持有效策略。
- **对系统设计**：Joint 共享注意力（动作 token 关注预测的未来视觉表征）是一种低成本、高收益的架构选择，值得在同类世界-动作模型中推广。
