## 摘要
多机器人具身系统通常通过协调动作、共享轨迹或学习联合策略来实现协作。我们提出一个互补性问题：协作能否在决策之前产生，即先建立对环境的共享理解？我们引入共享环境理解（Shared Environmental Understanding），这是一种与策略无关的表示，将多个机器人的部分自我中心观测聚合为共享的潜在世界模型。这将协作从策略空间转移到表示空间，使得在共享环境上下文下进行去中心化决策成为可能。为此，我们提出共享环境编码与检索（Shared Environment Encoding and Retrieval, SEER）框架，将多机器人观测组织为共享记忆，通过时空相似性检索相关上下文，并使用预测性潜在世界模型对其进行编码。所得表示以 token 形式注入下游导航智能体。实验结果表明，SEER 能够捕捉与动作相关的环境结构，并在专用 VLN 智能体和通用视觉语言模型智能体上持续提升导航性能，同时保持单智能体能力。

## Abstract
Multi-robot embodied systems are typically designed to collaborate by coordinating actions, sharing trajectories, or learning joint policies. We ask a complementary question: can collaboration emerge before decision-making, by first building a shared understanding of the environment? We introduce Shared Environmental Understanding, a policy-agnostic representation that aggregates partial egocentric observations from multiple robots into a shared latent world model. This shifts collaboration from the policy space to the representation space, enabling decentralized decision-making with shared environmental context. To this end, we propose Shared Environment Encoding and Retrieval (SEER), a framework that organizes multi-robot observations into a shared memory, retrieves relevant context via spatio-temporal similarity, and encodes it using a predictive latent world model. The resulting representations are injected into downstream navigation agents as tokens. Experimental results demonstrate that SEER captures action-relevant environmental structure and consistently improves navigation performance across both specialized VLN agents and general vision-language model agents, while preserving single-agent capabilities.
