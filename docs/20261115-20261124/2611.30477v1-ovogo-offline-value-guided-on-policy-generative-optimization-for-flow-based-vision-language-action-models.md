## 摘要
基于流的视觉-语言-动作模型能够从部署期间收集的机器人经验中受益，但为改进策略而反复获取新的物理交互代价高昂。离线强化学习提供了一种复用已收集经验的自然方式，而基于流的策略还提供了额外机会，因为可以在回放观测处从当前策略廉价地重采样新的生成轨迹。这促使将离线价值学习与生成过程的在策略优化分离。我们提出 OVOGO，一个面向基于流的 VLA 实现这种分离的离线强化学习框架。该表述中的一个核心挑战是学习一个评论家，使其既扎根于记录的机器人经验，又能为新生成的动作提供有用的价值信号。OVOGO 引入一个回报锚定的排序评论家（Return-Anchored Ranking Critic），它将样本内分布价值学习与受保护的局部排序相结合，在不给生成动作分配人为回报目标的情况下提升对生成动作的区分能力。随后，冻结的评论家为从当前流策略采样得到的新动作候选的选定转移优化提供组相对价值信号。在 RoboTwin 2.0、DexJoCo 和 LIBERO 以及一个真实机器人灵巧操作任务上的实验表明，OVOGO 在全部四种设置中均改进了初始 VLA，并相比所评估的离线适应和价值引导基线取得了更高的成功率。这些结果表明，离线机器人经验可以被反复复用于价值学习，而低成本的生成采样支持策略优化，从而为基于流的 VLA 的基于经验的后训练提供了一种有效方法。

## Abstract
Flow-based vision-language-action models can benefit from robot experience collected during deployment, but repeatedly acquiring new physical interactions for policy improvement is costly. Offline reinforcement learning provides a natural way to reuse collected experience, while flow-based policies offer an additional opportunity because fresh generation trajectories can be cheaply resampled from the current policy at replay observations. This motivates separating offline value learning from on-policy optimization of the generative process. We propose OVOGO, an offline reinforcement learning framework that realizes this separation for flow-based VLAs. A central challenge in this formulation is to learn a critic that remains grounded in logged robot experience while providing useful value signals for newly generated actions. OVOGO introduces a Return-Anchored Ranking Critic that combines in-sample distributional value learning with guarded local ranking, improving discrimination among generated actions without assigning them artificial return targets. The frozen critic then provides group-relative value signals for selected-transition optimization of fresh action candidates sampled from the current flow policy. Experiments on RoboTwin 2.0, DexJoCo, and LIBERO, as well as a real-robot dexterous manipulation task, show that OVOGO improves the initial VLA across all four settings and achieves higher success rates than the evaluated offline adaptation and value-guided baselines. These results suggest that offline robot experience can be repeatedly reused for value learning while inexpensive generative sampling supports policy optimization, providing an effective approach to experience-based post-training of flow-based VLAs.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作模型（VLA）借助大规模跨任务机器人数据与预训练视觉-语言表征，已展现强操作与泛化能力；但进一步提升仍高度依赖昂贵、难以规模化采集的高质量示教数据。
- **经验浪费**：机器人在部署与自主执行中会自然产生大量经验（成功、失败、次优行为）及任务结果信号，行为克隆无法充分利用这些信号；强化学习（尤其是离线 RL）可反复复用已采集的交互与奖励反馈，而无需每次策略更新都进行新的物理交互。
- **针对流式 VLA 应用离线 RL 的难点**：动作由多步流生成过程产生，核心问题是“价值信息如何转化为生成策略的更新”。
  - RECAP：把估计优势转为条件变量，用监督学习抽取改进策略——简单可扩展，但改进监督依附于**回放动作**而非当前策略新采样的动作。
  - LWD、Q-VGM：用 critic 的动作梯度构造流动力学的改进目标——更直接，但依赖 critic 在策略生成动作附近**可靠的一阶动作梯度**。
- **关键观察（论文的核心洞察）**：物理交互昂贵、应被大量复用；而生成轨迹是廉价的计算样本，可在同一回放观测处从当前策略反复重采样。二者消耗速率不必相同——这促使**把离线价值学习与生成过程的在策略优化解耦**。
- **核心挑战**：需要学习一个既扎根于日志经验、又能为新生动作提供有用价值信号的 critic。若直接把策略生成动作纳入 Bellman 更新，时序目标将依赖没有环境结果的动作价值估计，高估误差会经自举传播并在策略改进中被利用；但若把 critic 监督完全限制在回放动作上，critic 又无法区分不断演化的策略所生成的新候选。

## 2. 方法论

### 2.1 整体框架（两阶段）
- **阶段一**：在固定离线数据集上训练 **Return-Anchored Ranking Critic（RARC）**，用回报锚定的价值学习 + 受保护的局部排序；合成动作只提供相对序关系，**从不获得 Bellman 目标**。
- **阶段二**：冻结 RARC，在回放观测处从当前流策略采样新动作候选，用 critic 标量值构造组相对优势，对动作专家做**选定转移（selected-transition）流优化**，**不通过 critic 反传梯度**。
- 预训练 VLM 主干与 RARC 均冻结，仅更新动作专家。

### 2.2 RARC 设计细节
- **网络结构**：M=5 个集成成员，每成员含 2 个标量动作价值头 Q 与 1 个分类状态价值头 Z，共 10 个标量 Q 头；共享多模态状态编码器，Q 头额外以动作块为条件；另维护完整 critic 的 EMA 目标网络（η=0.005）。
- **分布价值学习（受 DIVL 启发）**：
  - 分类价值头在固定支撑 Z={z_1,…,z_C}（C=201，范围 [−0.1, 1.1]）上建模状态条件价值分布 p_m(c|s)=softmax(Z_m(s))_c。
  - 成员内对两个目标 Q 取平均（双 Q 平均而非取小，避免系统性下压成员级估计），投影到支撑上后以交叉熵监督分布。
  - **熵自适应分位数**：H_m(s) 为归一化熵，τ_m(s)=clip(τ_base−αH_m(s), τ_min, τ_max)，V_m(s)=Quantile_{τ_m}[p_m]；熵高→分位数低→自举更保守。
  - 块级 TD 目标：y_{m,t}=R_t+γ^H(1−d_t)V_m(s_{t+H})；两个 Q 头回归同一目标（MSE）。
- **受保护的局部排序（Guarded Local Ranking）**：
  - 在回放动作附近构造排序对：沿归一化动作空间高斯方向生成温和扰动 A^δ 与更强扰动 A^{2δ}，另加均匀采样合法动作 A^rand 与同任务错配动作 A^perm。
  - 成功轨迹施加较强先验：A_t≻A^δ≻A^{2δ}≻A^rand，以及 A_t≻A^perm；失败轨迹只施加 A_t≻A^rand（弱行为分布先验，不宣称失败动作高回报）。
  - 排序损失（对每个 Q 头，g=Q(A⁺)−Q(A⁻)）：
    ℓ_rank(g) = [τ_R·softplus(−g/τ_R) − τ_R·softplus(−g_max/τ_R)]_+
    - 温度 τ_R 使正间隔一旦建立即快速衰减排序压力；间隔截断 g_max 在 g≥g_max 后完全移除压力，防止合成动作的 Q 差被推离回放回报所锚定的价值尺度（任务为 0 中间奖励、成功终端奖励 1，故设 g_max=1）。截断只作用于成对排序压力，不裁剪单个 Q 值。
  - 总目标：L_RARC = L_Q + λ_V·L_V + λ_R·L_rank；合成动作只参与 L_rank，永不获得 TD 目标。

### 2.3 RARC 引导的生成策略优化
- **候选采样**：每次 actor 迭代先快照 π_old；对每个回放观测 s_b 从独立高斯噪声生成 G=8 个完整候选动作块。
- **组相对优势**：对每个 Q 头在组内中心化（减组均值，去除观测级公共偏移，状态价值头不作 baseline）；再跨 10 个 Q 头**保守聚合**——仅当所有头对中心化分数符号一致时才给非零优势（全正取最小正值，全负取最接近零的负值），符号不一致则为 0；优势 detach 后作为标量信号。
- **选定转移流优化（借鉴 Flash-GRPO）**：每个观测的候选组共享一个随机选定转移 k_b~U{1,…,K}（K=10），该步用随机 SDE 更新、其余步用确定性 ODE；每个候选仍完整生成后才由 RARC 打分；策略梯度只通过 k_b 这一步。似然比经维度归一化与对数比裁剪（c_ρ=20），并用时间梯度矫正 w(k)=1/λ(k) 消除不同时间步的梯度尺度差异，最终为 PPO 式裁剪目标（ε=0.01）。
- **成功行为保持**：对成功回放轨迹保留原生流匹配目标 L_succ；两梯度分别计算后按全局范数与余弦相似度自适应确定 λ_eff（名义 λ_0=0.005，成功梯度占比上限 ρ_BC=0.2），防止辅助目标主导 critic 引导更新；合并后再做梯度裁剪与单次优化步。

## 6. 主要结论与贡献

- **核心贡献**：论文提出将离线价值学习与生成策略的在策略优化解耦的两阶段框架。第一阶段仅在固定离线数据上学习 Return-Anchored Ranking Critic（RARC），第二阶段冻结 critic，在回放观测处从当前流策略重采样候选动作，并利用 critic 的组相对优势进行选定转移流优化。
- **方法层面的关键结论**：
  - 合成动作不应直接进入 Bellman 更新；让其只提供受保护的局部排序信号，可在利用 critic 区分新候选的同时，避免高估误差经自举传播。
  - 回报锚定与排序间隔截断共同维持价值尺度：TD 目标锚定于回放回报，排序压力在间隔达到 g_max 后消失，从而防止合成动作的 Q 值差被推离日志回报尺度。
  - 跨多个 Q 头的保守符号一致性聚合，可降低集成成员分歧带来的虚假优势；选定转移流优化则把策略梯度限制在单步随机转移上，兼顾流式生成的可处理性与 PPO 式稳定性。
  - 成功行为保持项以自适应梯度比例约束辅助目标，避免其主导 critic 引导更新。
- **实验层面的总体结论**：在 RoboTwin 2.0、DexJoCo、LIBERO 及真实机器人任务上，OVOGO 相较 Success BC、RECAP、Best-of-N、QGF、LWD 等基线取得更优或更具竞争力的成功率；Best-of-N/QGF 对比表明收益并非仅来自推理时 critic 选择或动作梯度引导，而包含策略参数更新本身；RoboTwin 迭代离线实验显示随新增 rollout 累积，性能可继续提升。

## 7. 局限性与未来方向

- **局限性**：
  - 真实机器人验证规模较小，任务单一，尚不足以证明复杂真实操作场景中的稳健泛化。
  - 方法依赖离线数据中的成功/失败标签与任务结果信号；若奖励稀疏、成功样本极少或失败模式高度异质，RARC 的排序先验与价值锚定可能受限。

  - 理论保证有限，主要依赖经验验证；critic 在策略演化后的可靠性仍以间接指标评估。
- **未来方向**：扩展到更多真实机器人任务与物体/场景分布；研究更长期、闭环的迭代离线或在策略经验复用；引入更直接的价值校准与不确定性约束；降低集成 critic 与候选重采样的计算成本；从理论上分析排序保护与回报锚定对自举偏差的控制作用。

## 8. 对后续研究的启示

- 对 VLA 与离线 RL 结合而言，应区分“物理交互样本”和“生成计算样本”的消耗速率：回放观测可反复用于策略重采样，而价值学习应扎根于有环境结果支撑的日志动作。
- 当 critic 的一阶动作梯度不可靠时，基于组内相对排序的标量优势信号是一种更保守的替代路径；但必须配合价值尺度保护与跨头一致性聚合。
- 评估此类方法时，Best-of-N 与推理时梯度引导是必要的“机制隔离”基线，可帮助判断性能提升来自 critic 选择、生成引导还是策略更新。
- 论文的“解耦”思路对大规模 VLA 后训练具有工程意义：冻结 VLM 与 critic、仅更新动作专家，可在有限算力下复用已有离线数据并持续吸收新 rollout。
